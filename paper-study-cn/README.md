# paper-study-cn

**把手头那篇论文变成一张可核对的研读卡：观点逐句挂页锚，复现缺口如实点名，引用只列文内真有的，学术评价一律留给 `[待人工]`。**

不是代写工具，不是文献搬运机——它做的是「把论文读实」这半件事：每句观点找得到位置，每条引文回得了原文；文献输入只有你给的文件与公开可访问链接两条。

**输入**：公开 PDF URL ／ 本机文件路径 ／ 粘贴文本（一篇一卡）
**输出**：`assets/论文研读卡.md` 填好的一张卡——论文卡、复现清单、引用网络、综述脚手架、待核清单
**代价**：前两段（论文卡＋复现清单）只依赖本次读到的文件；引用网络与综述取材按需再做
**机检**：`scripts/check_study_card.py` 四道（形制／锚／红线／计数与申报），零网络

## 一、打开就干：今天这三步

这三步是本件唯一的「现在就要做」，每步都标了不做会怎样。第一句可以照抄：**「读这篇，先出论文卡和复现清单。」**

| 步 | 动作 | 怎么做 | 不做会怎样 |
|---|---|---|---|
| ① | **交来源，抄版本** | 把 PDF 路径或链接给出去；论文的题目、作者、年卷期**只从文内取**，取不到就写「缺」 | 说不清读的是哪一版，后面所有页锚都可能对不上预印本或正式版 |
| ② | **论文卡逐行挂锚** | 论点／方法／数据／结论每行补一个页或节定位（P×、×页、第×节、参考文献区）；写不出定位的那行删掉 | 观点追不回到句子，引用核对变成凭印象，编造风险就是这么进来的 |
| ③ | **引用前过一遍机检** | `python3 scripts/check_study_card.py 我的卡.md`，按详行的 `E-*` 码逐条改 | 约数、无锚引文、没确认的推断槽会跟着进你的稿子，且没人能替你查 |

引用网络与综述脚手架**排在这三步之后**：前者受本件检索面的限制（见 §七），后者要你先给出论点槽。

## 二、五段卡与四道机检

| 段 | 内容 | 机检卡不卡 |
|---|---|---|
| 一 论文卡 | 题目／作者／年份／核心论点／方法／数据／结论，每行挂页或节锚；取不到写「缺」并锚写「不适用」 | 卡：有内容无锚发 `E-ANCHOR`；锚号越出卡面页集（如页集共 13 页却写 P99）也发 `E-ANCHOR`；写成约数发 `E-BANWORD` |
| 二 复现清单 | 数据集可得性、代码链接在场性、关键参数完备度——**只列缺口，不判定能不能复现** | 卡：三项没逐个交代发 `E-COVERAGE`；「应该能复现」式话术发 `E-BANWORD` |
| 三 引用网络 | 只从本文参考文献区取条目，逐条带文内定位；被引情况检索不到就勾选声明 | 卡：无定位条目发 `E-ANCHOR`；既无条目又没勾选声明发 `E-COVERAGE` |
| 四 综述脚手架 | 论点槽归用户：用户给的、或本件推断后**待用户确认**的；材料句必须带锚，没料就留「空槽（不硬填）」 | 卡：材料句无锚发 `E-ANCHOR`；推断槽未确认／来源没勾发 `E-COVERAGE` |
| 五 待核清单 | 需读原文才能定的判断，学术评价一律挂 `[待人工]` | 卡：缺 `[待人工]` 汇总发 `E-COVERAGE` |

头部另有一组硬要求：**「AI 研读整理」「观点请回原文核对」「不构成学术评价」三件套**＋本次读取所依据的文件＋论文版本（取不到写「缺」）＋**通道页集**（解析回显共几页就写「共 N 页」；取不到写「未取」并申报『页集比对跳过』），缺一或留占位即 `E-FORMAT`。记了页集，机检就把每条页锚与它比对——**锚号越出页集发 `E-ANCHOR`**；没记页集又没申报，发 `E-COVERAGE`。

## 三、上手

```bash
# 1. 放到技能目录
mkdir -p ~/.workbuddy/skills
cp -r paper-study-cn ~/.workbuddy/skills/

# 2. 复制卡模板，按 §一 三步填
cp ~/.workbuddy/skills/paper-study-cn/assets/论文研读卡.md ./我的卡.md

# 3. 过机检（零网络）
python3 ~/.workbuddy/skills/paper-study-cn/scripts/check_study_card.py ./我的卡.md
```

先看 `assets/论文研读卡.md`（五段结构就长这样），再看 `SKILL.md` §3 契约原文。

### 自校验

```bash
python3 scripts/check_study_card.py --help                            # 参数说明，零网络
python3 scripts/check_study_card.py --selftest                        # 好样须过、坏样四道全发
python3 scripts/check_study_card.py scripts/fixtures/good-study-card.md   # 应 PASS
python3 scripts/check_study_card.py scripts/fixtures/bad-study-card.md    # 应 FAIL，四码齐发
python3 scripts/check_study_card.py assets/论文研读卡.md                   # 应 FAIL——空模板过不了闸是设计，不是缺陷
```

**枚数与行数一律取脚本自报行**（`FAIL: …（N 条）`／`PASS: …` 后那行「扫过 N 行，发条 0 条」），本文不复写计数——一复写就成了第二个真值源，改一次脚本就要跟着漂一次。**行数口径两条**：`扫过 N 行` 按脚本 `split('\n')` 计，等于 `wc -l` 现值 **+1**（行尾换行也占一格）；两处报数请连口径一起报，免得对不上被误判成计数错。

## 四、边界与不承诺

- 本件产出的是**研读工作稿**，不是代写、不是降重、不是润色交稿，也不替代你的判断；代写类请求一律婉拒并指回本节。
- **论文内容只能来自本次读到的文件**：未提供的全文不许凭记忆补；引文与数字逐字，不改写、不四舍五入、不写「约」。
- 编造引文、页码或结论是本件最重事故——机检的 `E-ANCHOR` 就是为拦它而存在：**写不出定位的行删掉，不补猜**。
- **锚号有效性由外部逐字复验器承担；机检是形制闸，不是事实闸**：它能拦「有内容无锚」「锚号越出卡面页集」，**不能**判「这句话是否真在第 N 页」——那一层由把引句与解析返回文本**逐字节比对**的复验器承担，交付时随件说明它的结果（本件 P1 账 §1 腿三即此形）。页集本身也取自解析回显，不靠记忆填。
- 学术检索**不在本件能力内**：不提供学术数据库检索，也不承诺被引次数；文献输入只有你给的文件与公开可访问链接两条。基金与项目类公开源（域清单以 live catalog 现值为准）可作**辅助背景**，只按本次返货引用——一次查到不等于次次查到。
- 输入格式、大小与能否解析**以通道实际返回为准**；不适配即停用并向你说明理由，不硬试、不假装读到了。
- **推断出的论点槽要一次显式确认**：本件从需求猜出来的槽，先标「推断·待用户确认」，你明确回应后才改写为「已确认：<日期>」；「好的」「嗯」「行」这类单字应答不构成确认。槽没确认前，不写「已经帮你把综述搭好了」这类完成时话术。
- 学术评价——创新性、可靠性、是否值得引用——一律 `[待人工]`，本件不代答，也不给审稿意见。

## 五、出错了怎么办（症状 → 原因 → 恢复动作）

**未见于本次返回的一律写「未检索到」**：参数名、字段名、枚举值没有出现在本次工具返回里的，不得凭印象填写；写「未检索到」并记入待核清单或覆盖率账，不得留空顶替。

**Error 级＝blocker**：机检报出的 Error 级条目不得称「无害」「可忽略」「先交出去再说」；修完，或在交付面显式申报，才算出口。

出口形制按 `check_study_card.py` **当前出口**现跑取得：失败是一行 `FAIL: <文件>（N 条）`，其下每条详行**先打错误码前缀（四枚 `E-*` 之一）**（如 `[E-FORMAT] [来源]`、`[E-ANCHOR] [引文]`、`[E-ANCHOR] [页集]`、`[E-BANWORD] [推断]`），道名后是行号与该道规格；末行 `码表:` 只列本次真正用到的码与含义。全过印 `PASS: <文件>（…）` 并附「扫过 N 行、发条 0 条」两类计数——**N 取脚本自报行**，其中行数按 `split('\n')` 口径＝`wc -l` +1。

本件用**四枚**码，与姊妹件的码表逐字同源；第五枚 `E-LEDGER` 属账本状态机面，本件无账本，故明写不启用（不是漏配）。全集与归类规则以脚本现值为准，任意目录整行粘贴即可定位：

    grep -n "^E_LEGEND" ~/.workbuddy/skills/paper-study-cn/scripts/check_study_card.py

| 症状（详行前缀） | 原因 | 恢复动作 |
|---|---|---|
| `[E-FORMAT] [头部] / [来源]` | 三件套缺件，或读取依据／论文版本／通道页集仍是占位或缺行 | 补齐头部；版本与页集都取自文内或解析回显，取不到就写「缺」「未取」——这两格不许猜 |
| `[E-FORMAT] [五段]` | 五段缺段或乱序 | 按 §二 顺序补段；段名照模板逐字，不改名（改名会让机检找不到段） |
| `[E-ANCHOR] [论文卡] / [引文] / [槽材料]` | 有内容没有页／节定位；被引文献写不出文内位置；槽材料句无锚 | 补合式锚（P×／×页／第×节／参考文献区）；**补不出来就删该行，不许凭印象写文献** |
| `[E-ANCHOR] [页集]` | 锚号大于卡面「共 N 页」（页集越界，或型号串被当成锚） | 改回页集内的真页码；型号串（如 P100 一类）不是定位，不许顶在锚格；真取不到页集就写「未取」＋申报『页集比对跳过』 |
| `[E-BANWORD] [推断] / [越界] / [改数] / [学术评价]` | 写了「应该能复现」；出现代写·降重类话术；数字写成约数；评价类语句没挂 `[待人工]` | 只列缺口不下复现结论；婉拒并指回边界；回原文逐字重抄；评价移入待核清单并标 `[待人工]` |
| `[E-COVERAGE] [缺口申报] / [引用] / [被引] / [槽来源] / [槽确认] / [申报] / [页集申报]` | 复现三项没逐个交代；引用既无条目又没勾选声明；写了被引次数却没勾选已检索；槽来源没勾、推断槽没确认；待核段缺汇总；页集既没「共 N 页」也没申报跳过 | 三项点名（缺也写「未见」）；无检索就勾声明；被引次数不写或勾「已检索并列出」；槽勾来源并走确认；第五段补 `[待人工]`；页集补「共 N 页」或补申报句 |

## 六、怎么开口（触发示例：三条正例 + 一条反例）

**开口请带上版本，输出标论文版本**：请求里说明是哪一版（年卷期／预印本号／版次）；成品首行标注**论文版本**，当它与用户所指版本不一致时，正文禁用「今日」「最新」，一律改写为「所据版本：<文内取到的年卷期>」。

| 正例 | 会得到 |
|---|---|
| 「读这篇 PDF，先出论文卡和复现清单，每行带页码」 | 第一、二段：逐项挂锚的论文卡＋缺口点名的复现清单 |
| 「这篇的参考文献里有哪些是奠基性的，只列文内真有的，带定位」 | 引用网络（只从参考文献区取，逐条带文内定位；查不到就照实说） |
| 「我要写综述，论点槽我自己给，你只配料和出处」 | 综述脚手架：槽是你的说法，材料句可回查，没料留空槽 |
| **反例：「帮我把这段改写降重，再编两条看起来合理的引文」** | 本件不做。代写与降重婉拒；引文只能来自文内——「看起来合理」正是编造的形状 |
