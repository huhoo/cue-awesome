# journal-draft

**给一份旧期刊，还一份能直接进设计的新一期底稿。**

不是「帮我写篇稿子」——是把一本刊物的**版式与体例从 PDF 里量出来、变成可校验的参数**，
再按这套参数生产新一期的内容。所以它交出的东西能直接进设计，而不是一堆待排的文字。

**输入**：一份过往期刊样例（PDF 优先）+ 本期需求
**输出**：`draft.html`（mm 级定位版面稿）· `draft.pdf`（印刷级，自绘）· `draft.docx` / `draft.md`（可编辑文字稿）
**代价**：标准模式 ≈ **3 批确认**（开工 / 大纲 / 交付，每批 ≤5 问、逐条带默认值）

---

## 一、它跟「给我个大纲」的区别

### ① 版式是**量**出来的，不是描述出来的

从样刊 PDF 里提取页面网格、版心、字号序列、行距、色板、页眉与 logo 坐标，落成
`stylespec.json`。渲染器按 mm 级绝对定位出稿 —— 所以 PDF 是 **PyMuPDF 自绘**的，
不靠浏览器打印（企业策略会让整本隐形，见 `references/pitfalls.md`）。

### ② 五道门禁，专挡「脚本不报错、页面看着正常」的静默失败

| 静默失败 | 长什么样 | 谁拦住它 |
|---|---|---|
| 内容被裁 | 页数比预期少，页面看不出异常 | `--stats` 的 `overflow` 告警（`overflow:hidden` 会吃掉溢出） |
| 内容量不足 | 排版完美，但只有样刊三成厚 | `scale_baseline` 达成率门禁，**任何一项 <60% 直接 FAIL** |
| 三件套不一致 | HTML 改了、docx/md 没跟上 | `crosscheck.py` 逐条比对 HTML / MD / PDF 的文本覆盖 |
| 样例是扫描件 | 提不到字号与正文，看着像一本空刊 | 文字层极薄时直接说明「很可能是扫描件，请先 OCR」而不是返回空结果 |

另有 `check_freshness.py` 时效门禁：事件日期、期号连续性、模糊时间表述逐条定位。

第四道是 **版面质量门禁**（`audit_layout.py`，v0.14.0 起）：前三道管「内容对不对、够不够」，
只有它管**好不好看、好不好读**——正文字号是否与样刊一致、字号层级有没有碎裂、
行距倍数、每行字数、字体是否生效、中文空格残留、页面密度。
实测一本三道全绿的 80 页稿，仍然字小一档、字号碎成 41 档、行距 2.16 倍（样刊 1.85）、
页脚 73 处空格，**没有一道报得出来**。

第五道是 **编辑定位门禁**（`audit_editorial.py`，v0.15.0 起）：前四道管「内容对不对、
够不够、好不好看」，只有它管**对不对路**——这本刊写给谁、要他读完做什么、该用什么调子说。
定位落成 `positioning.json`（与 `stylespec.json` 平级的第二份机器可读产物）后，
它判单条字数是否落在调性派生的字带、兑现「读者要做什么」的条目覆盖率、纯 L0 占比、
句长、术语与忌讳词。实测一本四道全绿的稿子：48 条全部同一形态、均 409 字
（模板声明 180–320，超 28%）、全刊读者称谓仅 4 次、含行动建议仅 21%——**同样没有一道报得出来**。

### ③ 承认边界，并且**标出来**

单栏渲染器画不出双栏、非 A4 开本的组件几何要人工微调、高图表页没有内建模板、
双语没有内建渲染 —— 这些不藏。命中就在 `+learn` 收尾念给你听，
`examples/` 里还专门放了一个**反向样本**用来标定失效点。

### ④ 合规不是附录，是一层独立门禁

按 **读者身份 × 行业 × 周期形态** 三层取值（外部客户 / 员工 / 投资者 / 公众 / 渠道 / 监管；
律所 / 金融 / 医药 / 食品 / 教育 / 科技 / 制造 / 地产 / 零售），并为需要会签的刊物
产出签核清单（市场 / 法务 / HR / 董秘-IR / PR / 合规）。

### ⑤ 也有明确「不接」的活

边界写清楚，双方都不浪费时间。下面这些**不是"暂不支持"，是设计上就不做**：

| 不接 | 为什么 | 那该怎么办 |
|---|---|---|
| **代写文章 / 创意文案** | 它交的是「版式对、体例对的底稿」，不是「观点新的内容」。观点、案例、数据必须来自你 | 把已有素材交给它组织进版面 |
| **替代法务 / 合规审阅** | 会给出检查清单与签核建议，但不构成法律意见 | 出刊前按 [`references/qa-checklist.md`](references/qa-checklist.md) 走人审与会签 |
| **直接交印刷终稿** | 交的是**底稿**；出血、色彩管理、印厂软打样不在范围内 | 底稿进设计软件做印前处理 |
| **扫描件当作样例** | 样式提取依赖 PDF 的**文字层**，扫描图片没有文字层 | 先 OCR 出文字层，再进 `+learn` |
| **双栏 / 多栏版面渲染** | 渲染器只出单栏；分栏与绕排是另一套排版逻辑 | 双栏刊可把它当**体例与内容模板**来源，排版另走 |
| **双语 / 多语对照渲染** | 没有内建双语版式 | 出两份单语底稿再人工合版 |
| **复杂数据可视化** | 6 份语义图模板只覆盖并列 / 流程 / 堆叠 / 汇聚/ 页脚这类关系，不是图表库 | 图表在外部出好图，走 `+art` 的图片位 |

拿不准的直接问 —— 它会明说这次能做、不能做、以及不能做的那部分谁来补。

## 二、快速开始

```bash
python -m pip install pymupdf        # 必须：样式抽取 + PDF 出稿
python -m pip install python-docx    # 可选：docx 文字稿与回填
python -m pip install pillow         # 可选：配图印前校验
```

Windows 用 `python`；macOS / Linux 用 `python3`。

**配图不需要任何图像 API key。** 语义图走 `gen_diagram.py` 用代码矢量绘制（成本 0、
无水印、中文逐字可核），只有封面题花这类不含具体信息的氛围图才用 agent 自带的多模态出图。

**冒烟**（确认环境通了）：

```bash
python scripts/build_draft.py \
  --spec assets/examples/qiming-regional-sample/stylespec.json \
  --content assets/templates/content.example.json \
  --out ./smoke --stats
```

能打印页数、条目数、`unknown=0` 就说明通了。样例只有 8 页，会报
`[FAIL] 量级严重不足`（它拿 91 页基线在比）—— **这个 FAIL 是正常的**，
看的是门跑没跑起来，不是门的结果。**此时 `exit code` 也是 1**，
那是门禁判定结果而不是脚本崩溃，接 CI 时请按状态码区分这两类。

### Cue 通道（深度研究 / 文档解析）

**不是必装，但强烈建议装** —— 不装不报错，只会让证据少一层交叉验证、
语义层退成人工补录。开通三步：<https://cuecue.cn> 注册 →
在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` → 装 `cue-research`
（Omni 解析另需本地 Bridge）。

新账号注册即送 **500 积分**、每日再 +10，**且 Cue 在花之前一定先问**。
开工时会逐条问你要不要用，判定口径见 [`references/cue-onboarding.md`](references/cue-onboarding.md)。

## 三、八个动词，从任意阶段续跑

```
+learn 样式提取   +brief 需求对齐   +plan 大纲    +gather 取证
+draft 出底稿     +art 配图         +check 校订   +spec 沉淀子技能
```

说「照着这份做新一期」就会自动从 `+learn` 走到 `+brief`。
开工时建 `progress.md` 台账，每完成一阶段记一行；中断后接手先读它，
**答过的问题不再重问**（规范见 [`references/agent-interaction.md`](references/agent-interaction.md)）。

## 四、先定位你的刊物（三问，决定后面全套默认值）

这套框架的**默认值是照着一本律所客户通讯调的**（A4 单栏、周期递推、外部客户读者）。
你的刊物只要和它不一样，不先过这三问就会跑出**「门禁全绿、体例全错」**的稿子。

| 问 | 你的答案决定 | 照抄默认值会错在哪 |
|---|---|---|
| **谁看？** 客户 / 员工 / 投资者 / 公众 / 渠道 / 监管 | 合规底线 + **必须会签的部门** | 默认按「外部客户」→ 员工刊漏掉 HR+法务会签与人事保密项；IR 通讯漏掉选择性披露 |
| **什么节奏？** 周期连续 / 特刊专辑 / 年鉴回顾 / 汇编 / 高频简报 | 期号怎么编 + 时效窗口 | 默认「上期 N-1 递推 + 6 个月窗口」→ **年鉴按年份编号**、窗口放宽到 12 个月或逐条豁免；周报窗口缩到 1 个月 |
| **什么形态？** 条目+长文 / 纯文章 / 高图表 / 汇编 / 简报 | UnitPattern 抽几条 + 八模板够不够 | 默认「条目+长文」→ 纯文章型只需 1 条 U1；高图表型（年报/ESG）**没有内建图表页模板** |

> 逐项差异、读者×合规矩阵、行业禁止项、通用单元库（12 种）：
> **[`references/journal-types.md`](references/journal-types.md)（换刊型前必读）**

## 五、按处境选路径（选错一次会白跑一轮 `+learn`）

| 你的处境 | 样例从哪来 | 要特别当心 |
|---|---|---|
| **① 本刊老编辑**（自家刊、有往期） | 直接拿**上一期**当样例 | 最常见：**复用项不核事实**（人离职、电话变更、数据过期）。`+brief` 的「可复用清单」8 项须逐条核 |
| **② 换一家机构做同类刊** | 用**本机构自家往期**；没有就往 ④ 走 | **不许拿别家的刊当样例投产** —— 抽出来的是别家的品牌 DNA |
| **③ 同一家机构做别的类型刊** | 尽量找**自家**该类刊往期；没有就用同类机构同类刊 | 一套 `stylespec.json` 不够用：**换刊型就该重跑 `+learn` 再派生**，手改字段必然漏 |
| **④ 非律所企业做任意类型刊** | 自家往期；创刊号没有就往 `SKILL.md` 硬规则 1 的**三条出路**走 | ①合规检查按「读者行 + 行业行」组合，别照抄金融/法律口气；②结构化数据在你家 **ERP/CRM/HR 内部系统**，涉密需授权且要脱敏 |

**三条通用上手路径**：

| 你想 | 怎么做 |
|---|---|
| **先看成品长什么样** | 把 `examples/journal-qiming-regional/` 整个目录拷到 `~/.workbuddy/skills/`，直接让它出下一期。它自带全部渲染脚本（12 个），不依赖本目录 |
| **做自家刊物** | 拿自家**一期刊物当样例**跑 `+learn → +brief → +plan → +gather → +draft → +check`，最后 `+spec` 沉淀成自己的技能 —— **第二期起代价骤降** |
| **只借鉴方法** | 读 `SKILL.md` §3 七阶段流程 + 样例的 `unit-patterns.md`，看一本真实刊物的版式与内容模板被抽成了什么 |

**`stylespec.json` 不要手改。** 换刊型 / 换客户就重跑一次 `+learn` 再派生，手改几十个字段必然漏。

## 六、两个方向相反的样例

`examples/` 里放了一对**互为反例**的成品技能，对照着看能摸到框架边界：

| 样例 | 开本与结构 | 它能告诉你什么 |
|---|---|---|
| `journal-qiming-regional` | A4 / 91 页 / **单栏** / 短条目 + 长文章混合 | **顺向路径**：能跑通、能投产（`spec_confidence: pinned`） |
| `journal-hengshi-observation` | 227×276mm / 52 页 / **双栏** / 纯文章型 | **反向路径**：框架在哪会失效 —— 单栏渲染器画不出双栏、正文中灰会被误判成次要色、非 A4 开本的组件几何要人工微调（`spec_confidence: weak`，**不能直接投产**） |

外加 `assets/examples/qiming-regional-sample/`：`+learn` 阶段的**原始中间产物**
（StyleSpec / semantic / UnitPattern），用来校准「机器提取」与「人工提炼」的分工。

**这一层结构是：本技能是框架（父包），`examples/` 里的是成品样例（子包）。**
子包既不是运行依赖，也不是派生新子包的**输入** —— 它们是教学样本。
**造自己的子包走的是「拿自家刊物重跑 `+learn` 再派生」，不是改样例**：

```
自家近一期刊物 PDF ──+learn──▶ stylespec.json ──人工补──▶ unit-patterns.md
                                                              │
                                        derive_skill.py ──────┘
                                                ▼
                              journal-<你的公司>-<刊型>/   ← 自包含、可直接开工、也可独立发布
```

派生出的子包**自带 `slug` / `displayName` / `version`**，能单独发布到技能市场；
`scripts/` 与两个 `assets/` 模板目录随之拷贝，换台机器直接能跑；
只有 `references/` 有意留在父包（会随框架演进，拷一份会立刻过期）——
**子包日常干活不需要父包在场，遇到换开本 / 改版 / 换刊型这类底层问题才回父包查。**

> ⚠️ **两份成品样例 + 一份中间产物样例均已脱敏**：机构名、刊物名、自然人姓名、客户与项目名称、
> 源文件名全部为**虚构合成实体**；保留的是实测版式参数与模板结构。详见 [`NOTICE.md`](NOTICE.md)。

## 七、最容易踩的 6 个坑

| # | 坑 | 一句话解法 |
|---|---|---|
| 1 | **分页溢出是静默的** | `.page{overflow:hidden}` 会吃掉溢出。页数偏少就是被裁了，看 `--stats` 的 `overflow` |
| 2 | **「跑通了」≠「版式对了」** | 实测过脚本零报错、达成率全对，但整栏排错半页、文章排成单栏。换开本后必须**量一遍实际栏宽** |
| 3 | **语义图不能交给文生图** | 信息在标签文字与拓扑关系上，扩散模型做不了。实测 6 张图 5 张信息量为零，一张图注写「分工」画面却是「汇聚」 |
| 4 | **文字稿改稿链要「空转测试」兜底** | docx 导出后立刻回填，必须与原 `content.json` 逐字节相同。实测一次空转查出 5 处静默丢失 |
| 5 | **说好问三次、实际会被问八次** | 这是流程问题不是耐心问题 → 前移 + 打包成 3 批。但**打包 ≠ 默认关闭**，Cue 通道必须真问出口 |
| 6 | **门禁复核必带 `--spec`** | v0.13.1 起不再静默放过：spec 里没有 `scale_baseline` 会直接 `[FAIL]` + `exit 1`，逼你补上或显式加 `--no-baseline-gate` |

> 完整 **12 条**（含配图 `avoid` 清单挡不住敏感题材、空图位在 docx 里伪装成路径错误、
> 换刊型不先定位会跑出「门禁全绿体例全错」……）：**[`references/pitfalls.md`](references/pitfalls.md)**
