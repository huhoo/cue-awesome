# tear-sheet

**[中文](README.md) · [English](README.en.md)**

**见客户前 30 秒，来得及吗？** 来得及——给「主体 + 用途」，还你一张每行都查得着出处的一页纸（屏内读完），观点那一栏诚实地空着。

这是本套件**门槛最低的入门件**：默认零深研、以结构化披露直查为主，单次消耗量级无实测凭据（消耗以服务端返回为准，页眉当场打印本次通道用量）；
它不替你下判断，它把「30 秒内能确定的事实」一次摆齐——身份三行、近四期速览（累计+单季双口径）、
在场事件（有明确披露日期的才算）、风险命中项、以及三行 `[待人工]` 的观点空位。

**输入**：主体（官方全称或代码，≤5 个）+ 用途（会前速览/客户简报）+ 可选关注点一句话
**输出**：`tearsheet-<日期>-<n>主体/` —— `page.md`（五段形制一页纸）· `sources.jsonl` · `progress.md` 台账
**代价**：三段管线+一道形制门禁；默认 0 次深研，全流程计费确认至多弹一次

## 一、是什么 / 不是什么

| 你要 | 用什么 |
|---|---|
| 会前 30 秒的一页速览（每行带披露锚） | **本 skill** |
| 持仓未来三个月的日期表 | 姊妹件 `catalyst-calendar` |
| 财报深度点评/季度连续剧 | 姊妹件 `cn-earnings-note` |
| 表格引擎交付物、>5 主体批量、任何评级/目标价/买卖建议 | 不做——观点区就是三行空位，等人来写 |

## 二、形制即纪律（为什么长这样）

五段顺序钉死，页眉三声明必在场（生成 asof / 数据截止日 / 本次通道用量）——这几条不是审美，是机检：

- **每行可锚**：数字回指公告索引号/URL/域 ref，列级校验，别的列拿数字冒充锚即 FAIL；
- **事件先过闸**：在场事件条目直接复用 `catalyst-calendar` 的 v2 入类第一闸（只引用不复制，防双事实源）——没有明确披露日期的「事」不上页；
- **风险不装干净**：直查没命中就写「直查面内未命中≠无敞口」，这句话本身是必选动作；
- **宁缺毋滥**：取不到的行删掉并记台账，空行合法，编行违法。

## 三、快速开始（三步）

1. **装**：本目录放进 agent 的 skills 目录。
2. **说**：「见客户前给我一页纸看看东方雨虹」或「客户简报里加一节美的」（中英触发词都行）。≤3 问补齐输入契约。
3. **收**：三段管线跑完过门禁 `check_page.py` 四道（声明/列级锚+双向/禁词零容忍/形制与行数），**不过不出**。

## 四、首次开通 Cue（三步，可跳过）

注册 <https://cuecue.cn>（新账号注册送 500、每日 10，以服务端为准）→ <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 入本地凭据（**别贴进聊天**）→ 装 `cue-data-mcp`（`cue-omni-reader` 按需）。
不装也能跑（你贴披露原文，agent 组织成页并标「用户直供」）——但那就看不到通道取证的真实样子了，而这正是本件想展示的。
