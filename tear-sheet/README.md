# tear-sheet

**本文件为中文主面；英文版是同目录下的 `README.en.md`（仓库内查阅用——渠道页不解析相对链接，这里不做可点切换）。**

**见客户前 30 秒，来得及吗？** 来得及——给「主体 + 用途」，还你一张每行都查得着出处的一页纸（屏内读完），观点那一栏诚实地空着。

这是本套件**门槛最低的入门件**：默认零深研、以结构化披露直查为主，单次消耗量级无实测凭据（消耗以服务端返回为准，页眉当场打印本次通道用量）；
它不替你下判断，它把「30 秒内能确定的事实」一次摆齐——身份三行、近四期速览（累计+单季双口径）、
在场事件（有明确披露日期的才算）、风险命中项、以及三行 `[待人工]` 的观点空位。

**输入**：主体（官方全称或代码，≤5 个）+ 用途（会前速览/客户简报）+ 可选关注点一句话
**输出**：`tearsheet-<日期>-<n>主体/` —— `page.md`（五段形制一页纸）· `sources.jsonl` · `progress.md` 台账
**代价**：三段管线+一道形制门禁；默认 0 次深研，全流程计费确认至多弹一次

## 二、形制即纪律（为什么长这样）

五段顺序钉死，页眉三声明必在场（生成 asof / 数据截止日 / 本次通道用量）——这几条不是审美，是机检：

- **每行可锚**：速览表**只校验末列**，该列须落在 `ANCHOR_OK_RE` 现值白名单内（公告索引号 / URL / 域 ref / `[S<n>]` 等形）；白名单里有接受纯数字的形（六位以上，索引号与证券代码族），**所以"页上有数字"不等于"这行有锚"**——读者要核的是那一列指不指得回披露；
- **事件先过闸**：在场事件只收过入类第一闸的条目——已有披露在场且含明确 `YYYY-MM-DD`，或 statute 规则推导且适用条件在锚内可判；日期形状=`check_page.py` 里 `FULL_DATE_RE` 现值、推测词族=`ESTIMATE_RE` 现值（常见例命中即拦，例不穷尽）——没有明确披露日期的「事」不上页，本件页上不设类型枚举列；
- **风险不装干净**：直查没命中就写「直查面内未命中≠无敞口」，这句话本身是必选动作；
- **宁缺毋滥**：取不到的行删掉并记台账，空行合法，编行违法。

## 三、快速开始（三步）

1. **装**：`npx skills add huhoo/cue-awesome --skill tear-sheet`——这条只装本包；装完在你这一侧重列一次已安装 skill，清单里看得到 `tear-sheet` 这个名字才算文件到位。没有 CLI 环境时的兜底是把本目录整个放进 agent 的 skills 目录（`~/.workbuddy/skills/`）。
2. **说**：「见客户前给我一页纸看看东方雨虹」或「客户简报里加一节美的」（中英触发词都行）。≤3 问补齐输入契约。
3. **收**：三段管线跑完过门禁 `check_page.py` 四道（声明/列级锚+双向/禁词零容忍/形制与行数），**不过不出**。

## 四、首次开通 Cue（三步，可跳过）

注册 <https://cuecue.cn>（新账号注册送 500 积分、每日 10 积分，以服务端为准）→ <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 入本地凭据（**别贴进聊天**）→ 装 `cue-data-mcp`（`cue-omni-reader` 按需）。
不装也能跑（你贴披露原文，agent 组织成页并标「用户直供」）——但那就看不到通道取证的真实样子了，而这正是本件想展示的。

三层各自能证到什么，互不等价：**装好 skill ≠ 已配凭据 ≠ 通道已连**。装好＝你这一侧重列一次已安装 skill，清单里看得到上面那些名字（只证明文件到位，不证明取到数）；配好凭据＝那把 `CUE_API_KEY` 存在于本地凭据设施即可，**key 在场不等于 key 被接受**；已连＝带上那把 key 按目标域 `routing` 里的 `url` 实连（`Authorization: Bearer <$CUE_API_KEY>`，并带 `Accept: application/json, text/event-stream`——缺这个头会 406，是协议行为不是鉴权失败），且 `tools/list` 有返回，工具名与入参 schema 一律以那份返回现值为准，不硬编码、不臆造参数。

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
[print(r.get("id"), r.get("external_status"), (r.get("routing") or {}).get("url", "-")) for r in rows]'
DOMAIN_ID="<把这里换成上一行列出的那个域 id>"
ROUTING_URL="$(curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
hit=[r["routing"]["url"] for r in rows if r.get("id")==sys.argv[1] and r.get("routing")]
print(*hit,sep="\n") if hit else sys.exit("未取到：该 id 不在目录现值里（或它没有 routing 里的 url 字段）——先跑上面那行列出现场的 id 再填")' "$DOMAIN_ID")"
[ -n "$ROUTING_URL" ] || { echo "取值失败：ROUTING_URL 为空——先跑上面那行列出现场 id，再把 DOMAIN_ID 换成其中之一" >&2; exit 1; }
curl -s -X POST "$ROUTING_URL" \
  -H "Authorization: Bearer $CUE_API_KEY" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  -w '\nHTTP %{http_code}\n'
```

`CATALOG` 是本面唯一一处目录入口字面（赋一次、散文不重抄）；`$ROUTING_URL` ＝上面那两行从该域 `routing` 里的 `url` 字段现取的逐字值，别把域名或路径抄死在这张面上。匿名 `GET` 那两行有返回**只证目录可达**，本面不把它叫「已连」；通过＝HTTP 200 且返回体里 `result.tools` 非空（只按形状认，形如 `{"result":{"tools":[…]}}`，本面不列具体工具名也不承诺枚数）。目录返回里没有的域本面不装也不承诺；连接报错不等于域无数据，如实报。这处端点可能以 SSE 形回字（一行 event、紧跟一行 data），要看的 `result.tools` 就在那条 data 载荷里。本块不新增任何凭据读取动作：key 取自上一层那把本地凭据，不进聊天、不在终端回显。**本包不随带连通自测脚本**（这一趟只有上面那两条 curl，别的都不发）。

## 六、常见问题与反模式（你想这么用 → 本件不接，因为 → 替代去向）

只重组已审清的边界条款与夹具形状；被禁词族、推测词族、锚形制三套判据一律以 `check_page.py` 现值为准（定位命令见 §五 注行）。

| 你想 | 本件接不接，为什么不接 | 替代去向 |
|---|---|---|
| 让我替你把观点区填成能直接对客发出去的话术 | **不接**。观点区就是三行空位，代填即越界 | 空位由会前会后的人手写；本件负责让每一行数都回指披露 |
| 加个 Excel / 表格文件交付 | **不接**。本件只产 md 回客页 | 需要可编辑表格自行取数另建，别指望本件形制里长出文件 |
| 一次做七八家，做个组合页 | **不接**。主体上限 5（机检计数），超限会掉进「每行锚」守不住的档位 | 分批跑；要盯一批主体的日期表用 `catalyst-calendar` |
| 数据取不到，先按常识凑一行 | **不接**。该行删掉并记台账弃行——空行合法，编行违法 | 缺项如实留白并在台账记一行；披露到场才建行 |
| 把未来某天的事件日期也写进速览 | **不接**（本件是过去的披露）。前瞻日期属日历件 | 用 `catalyst-calendar`，那边逐事件带披露锚 |
| 要行情数值流（现价、涨跌幅那类） | **不含**。该通道未开放，本件不承诺未开放数据域 | 行情另取自你的终端；本件只交披露口径 |

## 七、出错了怎么办（症状 → 原因 → 恢复动作）

**未见于本次返回的一律写「未检索到」**：参数名、字段名、枚举值没有出现在本次工具返回里的，不得凭印象填写；写「未检索到」并记入待核清单或覆盖率账，不得留空顶替。

**Error 级＝blocker**：机检报出的 Error 级条目不得称「无害」「可忽略」「先交出去再说」；修完，或在交付面显式申报，才算出口。

形制按 `check_page.py` **当前出口**现跑取得：失败一行 `FAIL: <文件>（N 条）`，其下详行**先打错误码前缀（五枚 `E-*` 之一）、后接道名标签**（`[E-FORMAT] [参数]`、`[E-BANWORD] [③]`、`[E-ANCHOR] [②]`、`[E-FORMAT] [④]`），再接行号与该道规格；末行 `码表:` 只列本次用到的码与含义。全过印 `PASS: <文件>（四道全过,主体块扫描正常）`。

五码为全族同源封闭集（与四件姊妹件逐字一致）：`E-FORMAT`／`E-ANCHOR`／`E-BANWORD`／`E-COVERAGE`／`E-LEDGER`。处置印在出口的 `码表:` 行里；本件哪道标签归哪枚码是脚本内的分类表，一条命令原地取（把 §五 那条 grep 的关键词换成下面两个）：

    grep -n "^E_LEGEND\|^E_RULES" ~/.workbuddy/skills/tear-sheet/scripts/check_page.py

| 症状（详行前缀） | 原因 | 恢复动作 |
|---|---|---|
| `[E-FORMAT] [参数] 缺 --subjects(…)` | 正式命令式要求声明主体数（与页内主体块双向对齐） | 补 `--subjects N`，N 与页内实际主体块数量一致；另一向不一致同样会报 |
| `[E-FORMAT] [①] / [④] …` | 首屏声明缺失，或五段形制、节名、表列位、行序不合式（改名、增删节都触发） | 按该行括号内规格复原形制；固定风险句那条必须在位，缺就是 FAIL |
| `[E-ANCHOR] [②] 来源锚为空/不在白名单: …` | 该行没有可回指披露的锚，或锚形制不在接受集合 | 补一个可回查形制的披露锚（公告索引号 / 函件号 / URL），补不出就删该行；禁造锚 |
| `[E-BANWORD] [③] 第 N 行命中禁词「…」` | 被禁词族进了正文（评级、价位、买卖动作那一类） | 改中性陈述或删除；本件无豁免区，词表全集见 §五 定位命令 |
| `[E-COVERAGE] [④] --subjects 声明 N ≠ 机检主体数 M(少报多搭/顶替申报)` | 声明的主体数与页内实际主体块数不符（少报多搭，或拿别的主体顶上来） | 把 `--subjects` 改成与页内实际块数一致；不要改块数来迁就声明 |
| 域没装 / 某项取不到 | 通道缺失，或该口径当期无披露 | 降级路径：用户直供素材（标来源级别）；取不到的行删掉并记弃行，不以估计值凑页 |
| Traceback 而不是 `FAIL …（N 条）` | 属事故：本件定义零崩溃，解析点全 try 化 | 停手回报：把稿件与整条命令记进台账，先跑 §五 的守护样命令区分稿件问题与脚本问题 |

## 八、怎么开口（触发示例：三条正例 + 一条反例）

**开口请带上时点，输出标数据日期**：请求里给出报告期／基准日或回看窗口；成品首行标注**数据日期**，当它与用户所指日期不一致时，正文禁用「今日」「最新」，一律改写为「截至 <日期>」。
- **正例（单主体）**：「见客户前给我一页纸看看东方雨虹」——§三 那句，≤3 问补齐（主体 / 用途 / 关注点）。
- **正例（多主体 + 指定用途 + 关注点 + 输出目录）**：「明天见两家：美的集团和宁德时代。用途是授信前初谈，
  各出一页，重点看现金流与在手订单口径，输出到 `~/sheets/2026-10/`」——两页各自带锚、各建台账，主体数声明要一致。
- **正例（带关注点的一句话）**：「见客户前给我一页纸看看美的，重点看现金流最近怎么样」——关注点只让
  该主题在页内升加粗行，**不引入新数据源、不加新段**（输入契约里的可选第三问，形制不因此变）。
- **反例（相邻需求，本件不接）**：「把这几家未来三个月的确定日子排一张表」→ `catalyst-calendar`；
  「逐条摊开公开信息里的风险，查不到什么也记账」→ `dd-checklist`。本件交的是「已披露事实的一页速览」。
