# 岗位说明（合成 JD，虚构样本，不属于任何真公司）

岗位：数据平台后端工程师（虚构）
团队与汇报线、地点与薪资区间都在原文里，本样件只留核对用得上的部分。

## 岗位职责

1. 负责数据接入服务的接口设计与长期维护，覆盖批量与流式两条路径。
2. 参与存储与计算选型的评审，并输出可落地的选型建议。
3. 承担线上服务的容量规划与稳定性值守，含告警闭环。

## 任职要求

1. 三年以上服务端开发经验，主力语言为 Go 或 Java。
2. 熟悉至少一种主流 OLAP 引擎的运维与调优。
3. 具备数据分析基础，能写复杂的 SQL 查询。
4. 有良好的英文文档读写能力；有小团队管理经验者加分。
5. 能接受每月不超过一次的值班轮换。

## 工作地点

远程为主，每季度一次线下评审。
