# dd-checklist

**本文件为中文主面；英文版是同目录下的 `README.en.md`（仓库内查阅用——渠道页不解析相对链接，这里不做可点切换）。**

**公开信息能替你尽到什么程度？** 这份清单的答案是：**能查到的逐条带锚摊开，查不到的逐类写清是「域面没工具」还是「窗口内零条」**。它不给结论——结论位是三行 `[待人工]`。

给「唯一主体 + asof + 回看窗口 + 用途档位」，还你一张固定七列的风险事实表：每条都能回指一条在场披露（公告号 / 函件号 / 裁判文书号 / URL / 研究件 / 法条原文），外加一份九类覆盖率对账表和全链证据快照。
本件最大的敌人不是漏查，而是**编一条看起来像的风险**——所以入类第一闸写死三条：有在场锚、有在场日期且落在窗内、归属可判；任一不满足即不入表，进账。

**输入**：`--subject`（唯一主体）· `--asof` · `--lookback`（如 `36m`，必传）· `--purpose`（investment/credit/mna）· `--sources` · `--evidence`——六参数全必传
**输出**：`dd-<代码>-<asof>/` —— `report.md` · `sources.jsonl` · `evidence/`（含 `LEDGER.sha256`）· `references/coverage-map.md` · `progress.md`
**代价**：五段管线 + 一道八层门禁；深研按缺口发起（发起前报耗时与消耗），计费一律以服务端返回为准

## 一、是什么 / 不是什么

| 你要 | 用什么 |
|---|---|
| 单一主体一段窗口内的公开面风险事项，逐条带锚 | **本 skill** |
| 见客户前多主体速览 | 姊妹件 `tear-sheet` |
| 未来窗口的确定日期 | 姊妹件 `catalyst-calendar` |
| 财报深度点评与兑现度对账 | 姊妹件 `cn-earnings-note` |
| 投资结论、法律定性、宣称「已查全查尽」 | 不做——判断位留白，这三类措辞本身就是机检级禁语 |

## 二、四条为什么钉死

- **锚只认最后一列**：把公告号写进事实列不补位，把金额写成「像事件号」的数字也不算锚。宁可这行空着，不可那行有锚的幻觉。
- **未检到要分三种**：无工具（域面外，需人工/商用库）／零条（查了，窗内没有）／未发起（本次没查）。把第一种写成「该公司无 X」是本件的红线。
- **证据 fail-closed**：`evidence/` 缺失、为空或哈希对不上即不交付，不放行「先交后补」。表内每一行的锚都要能在快照里逐字找到——法定推导行更要找到法条原文。
- **日期算术零自由**：「报告期后 N 日内应披露」这类推导，只有当场取回法条原文（法名+条号+短引三件齐）才落行；`statute` 域不含部门规章与交易所规则，所以这条路径当前**预期零锚**，取不到就拒推并在台账写理由。

## 三、快速开始（三步）

1. **装**：本目录放进 agent 的 skills 目录。
2. **说**：「给我做一份北辰股份近三年的公开信息预尽调清单」——缺窗口或用途档位会被反问，不会替你猜。
3. **收**：五段管线跑完过门禁：

   ```bash
   python3 scripts/check_dd.py report.md \
     --subject '北辰股份有限公司（600001.SH）' --asof 2026-09-21 --lookback 36m --purpose investment \
     --sources sources.jsonl --evidence evidence
   ```

   诊断码分层（此处八枚为码集镜像；全集=`check_dd.py` 现值，定位命令见 §五 注行），**不过不出**。题库自跑：`bash scripts/fixtures/run_fixtures.sh`。

## 六、常见问题与反模式（你想这么用 → 本件不接，因为 → 替代去向）

只重组已审清条款，不新增承诺；类目、锚种、禁语三套判据一律以 `check_dd.py` 现值为准（定位命令见 §五 注行）。

| 你想 | 本件接不接，为什么不接 | 替代去向 |
|---|---|---|
| 结尾给个结论：能不能投、要不要否 | **不接**。判断位永远是 `[待人工]`，本件交的是带锚事实 + 一张「查不到什么」的账 | 结论由人下；需要一页速览用 `tear-sheet` |
| 查不到的类目写成「该公司没有这类问题」 | **不接**。搜不到 ≠ 不存在；无工具项禁写主体性否定断言 | 写进覆盖率账，标清是域面无工具还是检到零条 |
| 顺手推一下定期报告的法定披露期限 | **无 statute 原文锚在场即拒推**。期限推导只在法条原文与适用条件同时可判时入表 | 拒推不落行，`progress.md` 记一行理由与探针清单（该路径当前预期零锚） |
| 一次跑几家主体横向比 | **不接**（一单一主体）。多主体必然让逐条锚失守 | 一家一次；批量速览走 `tear-sheet` |
| 不给回溯窗口，让我用默认 | **不接**。窗口必传，不用 wall clock 兜默认 | 给一个明确区间（如近三年、自某基准日回看 12 个月） |
| 想要评级段、价位段、法律定性段那三段 | **只转述披露原文并带锚**，不代出意见，也不给合规定性 | 意见与定性由人出；本件负责让每一条都指得回原文 |

## 七、出错了怎么办（症状 → 原因 → 恢复动作）

按 `check_dd.py` **当前已发布出口**写：失败形制是详行在前（每行以一枚 `DD-*` 诊断码加冒号开头、带行号与中文原因；诊断码全集以 `check_dd.py` 现值为准，枚数与含义用 §五 定位命令现跑取全），末行 `RESULT: FAIL report.md（N 项；码集 …）`；全过印
`RESULT: PASS report.md（八道门禁全过）`。

| 症状 | 原因 | 恢复动作 |
|---|---|---|
| `RESULT: FAIL …（N 项；码集 DD-INPUT）` | 六参数缺项或非法（主体形制、日期形制、档位不在封闭枚举） | 补齐六个必传参数再跑；主体写法接受「全称(6位代码.SH\|.SZ\|.BJ)」或纯代码两种形制 |
| `DD-ROW` / `DD-TABLE` 类详行（含行号） | 表行形制不合固定七列、类目或档位取值越界、日期非正序、锚列不在末列 | 按该行括号内规格改形制；改不了的行删除，不补内容 |
| 详行提示锚不在 `sources` 唯一解析 / evidence 缺对应件 | 有表行无账、或有账无原始快照 | 补 `sources.jsonl` 行并把该域原始回包落进 `evidence/`（`LEDGER.sha256` 可核）；目录缺失或哈希不符是 fail-closed，不放行「先交付后补证」 |
| `DD-COVERAGE`（含账龄申报类） | 九类不齐、某类「检到 N」与流水对不上，或长窗调了披露域却没写那一行账龄申报 | 逐类补账；长窗按契约 §v2-11 写该行（先收后判口径），申报窗口与复算窗一致 |
| `DD-OMISSION` | 正文声称查过的域多于对账表记录的调用集（声称而未记账） | 补记须「三件齐」（账格全域、流水含该域、逐域各有一份标类目的原始件）；只删正文不补账是形状性失效 |
| 域没装 / 该类公开面无工具 | 通道缺失或该类目本就无公开检索面 | 降级路径：用户贴披露清单（标 L2 直供，`sources` 用 user_supplied + path）；深研不发起则该类整类标「未检索到」并进账，**不以常识补条目**。全降级仍可用，代价是覆盖率不是准确度 |
| Traceback（不是 FAIL 清单） | 属事故：解析点已 try 化 | 停手回报：稿件与整条命令记进 `progress.md`，先跑 §五 的现跑命令区分稿件问题与脚本问题 |

## 八、怎么开口（触发示例：三条正例 + 一条反例，含档位怎么选）

- **正例（最简一句）**：「给我做一份北辰股份近三年的公开信息预尽调清单」——缺窗口或用途档位会先追问，不用默认窗兜。
- **正例（档位明确 + 关注点，复杂输入）**：「主体：北京东方雨虹防水技术股份有限公司（002271.SZ)，基准日
  2026-09-23，回看 12 个月，用途走并购档；关注控制权与同业竞争、历史并购痕迹，输出目录 `~/dd/2026q3/`」
  ——档位选择指引（三档必查集不同）：投资档看常规九类；授信档在担保与资金占用上加严；并购档在控制权、
  同业竞争与并购史加严。选错档位不是格式问题，是会漏查。
- **正例（参数不齐时怎么被追问）**：只说「帮我尽调一下贵州茅台」→ 应当回你三问：基准日、回看窗口、用途档位
  （六参数全必传）；把这三项一次答齐即可开工，例如「基准日今天、回看 24 个月、投资档」。
- **反例（相邻需求，本件不接）**：「顺手告诉我这票能不能买、值多少」→ 不出结论与价位；
  「我只要未来三个月的确定日子」→ `catalyst-calendar`；「会前 30 秒一页速览」→ `tear-sheet`。
