# ic-memo-cn · 投决备忘录起草（P0 骨架）

给一家公司起草**投决讨论稿**：七节结构，每个数字带官方出处与定位，取不到的行写「未取到」不填空，看多与看空各至少一条否则机检拦下。不评级、不给目标价、不表决——决议在人，本件只出可被逐条核对的草稿。

- 第一次进入：给 agent 公司名或六位代码，第一句说「起草一份投决讨论稿，每个数字带出处，缺数点名，正反两方都要」。也可以直接把手里的材料（PDF／网页／内部文件）一起给它。
- 能力边界：**不含估值测算**（没有行情与持仓数据腿，只做适用性声明）；正文长度有已知上限，超限会声明并回官方原文；不评整体风险、不建议买卖。
- 状态：**P0 骨架，未上架**；逐家真公司的全链案例账未做，因此不作能力宣称。
