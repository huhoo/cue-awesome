# 限售解禁压力·逐条挂源

把同一只股票**未来数轮限售解禁**按解禁日串成一条日历，逐轮登记解禁日、解禁方类型、解禁股数、占总股本比、成本区间，每行挂原公告锚与检索日。公告没写的，逐轮点名未取到。

**不判股价、不给买卖建议、不出评级与目标价。** 判断位一律 `[待人工]`。

---

## 一、打开就干：三步

1. **定基准日**，收齐这只票的限售股来源材料：招股说明书、定增发行结果公告、股权激励授予公告、限售股上市流通公告。
2. **每份材料抄四样**：解禁日、解禁方类型、解禁股数、占总股本比（连分母总股本一起抄），再加成本价、链接、检索日。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_lockup.py 你的解禁稿.md
```

退码 `0` 全过、`1` 有发条、`3` 读不到文件。

---

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `LK-STRUCT` | 形制 | 头部四件自标在第一个 `## ` 之前；`基准日：YYYY-MM-DD` 在场；`跟踪口径：` 在场；七节齐且按序；二节有 `- 总股本：N 股 [S#]` 行；三节日历每行 `- 日期｜解禁方类型｜一句话事实 [S#]` 且类型在册、日期非降序、每行晚于基准日；四节压力行形制 | 把基准日之前的解禁也排进日历；日历倒序；忘写总股本行 |
| `LK-QUOTE` | 锚 | 事实行不得空锚；七节来源每行齐 `[S#]`＋URL＋`检索日`；压力行至少两枚**不同号**锚；总股本行必须自己挂锚 | 压力行只挂一枚锚——分子分母都从同一处来；来源行只有标题没有链接 |
| `LK-LINE` | 红线 | 股价预测、涨跌承诺、买卖与减持建议、评级与目标价、解禁压力档位评价、`约`／`左右`／`大概` 改数词，一律零命中 | 写「解禁必跌」「抛压较大」「建议减持」；把 1.2 亿股写成「约 1.2 亿股」 |
| `LK-GAP` | 点名与占比 | 正文写「未取到 X」⇒ 六节必须点名 X，反过来六节点了名正文没有也发；压力行必须自报`占比出处`；标了`自算`的，六节必须写明自算口径；压力行分母总股本须与二节总股本行同数 | **自己拿解禁股数除总股本**得出一个百分比，却当成公告原句；分母用错时点 |
| `LK-BOUND` | 边界 | `跟踪口径` 须以「解禁」起头；写成已发生／减持／分红／回购／股东回报 → 点名走 `cn-shareholder-return`；写成质押／解押 → 点名走 `cn-share-pledge-tracker`；日历不足两行 → 点名走 `cn-shareholder-return` | 把已经发生的减持公告塞进解禁日历 |

### 这一枚最要紧的一格：比例不得自算

公告只写「本次解禁 180,000,000 股」而不写占比时，卡面若自己拿股数除总股本得出 4.50%，这个百分比在公告原句里**找不到**。所以第四节每一行都必须自报来源：

```
- 第 1 轮 2026-12-20｜解禁 180,000,000 股／占总股本 4.50%（分母总股本 4,000,000,000 股）｜占比出处：公告原文 [S1][S3]
```

报 `公告原文` 的，占比就是照抄；报 `自算` 的，第六节必须有一条写明自算口径，否则机检发 `LK-GAP`。两种都合法，含糊才不合法。

### 分母单独挂源

总股本这个**分母本身**也要挂公告与检索日——不同时点的总股本不一样（增发、回购注销都会改），拿错时点的分母，这一整节的占比全错。所以二节总股本行有自己的一枚锚，四节每轮要两枚不同号锚：分子一枚、分母一枚。压力行写的分母数与二节总股本行不是同一个数，也发 `LK-GAP`。

## 三、快速开始

先列目录，再按目录里的路由地址确认工具在场，取到公告与原文解析后再落笔：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

拿到公告清单后，可以先把骨架排出来：

```bash
python3 scripts/make_outline.py 清单.jsonl 骨架.md
```

再逐条读原文，把占位行换成带锚的事实行。

## 四、首次开通 Cue

本包走 Cue 的 MCP 通道取公告与原文解析。首次使用要拿一个凭据（`CUE_API_KEY`），在 Cue 控制台开通后写进环境变量即可，包本身不存凭据、不打印凭据。

不装也能跑：零通道时本包只把用户手上的解禁清单排成骨架，代价是**看不到原文**——没有原文就没有分母、没有成本价，占比与成本区间留占位，这份稿只剩一串日期。

## 五、边界与不承诺

- 本件登记的是**未来解禁的时间表**与两个可查的比值（占总股本比、成本区间），不是对股价的判断。
- 解禁＝限售到期可流通，**是否减持是股东的事**。本件不写「解禁即抛」「必然套现」，也不写「抛压」。
- 解禁压力算大还是小、解禁后股价怎么走：`[待人工]`，本件不下这个结论，也不假装有个客观阈值。
- 不转述研报、新闻、股吧。没有公告链接与检索日的事实不进日历。
- 不推算解禁日。公告没写具体日期，就写未取到，不用「限售期满后即可流通」倒推一个日期出来。

## 六、出错了怎么办

| 症状 | 多半是 | 怎么改 |
|---|---|---|
| `LK-STRUCT` 说日历行不是三格 | 用了全角冒号或漏了 `｜` | 照 `- YYYY-MM-DD｜解禁方类型｜一句话事实 [S#]` 重写 |
| `LK-STRUCT` 说解禁日不晚于基准日 | 把已发生的解禁排进来了 | 移出日历；已发生的股东行为走 `cn-shareholder-return` |
| `LK-QUOTE` 说压力行只有一枚不同号锚 | 分子分母用了同一个来源号 | 分母总股本单独找一份文件并给它自己的编号 |
| `LK-GAP` 说没自报占比出处 | 漏了 `｜占比出处：…` | 写 `公告原文` 或 `自算`，二选一，不许空 |
| `LK-GAP` 说自算没写口径 | 标了 `自算` 但六节没交代 | 在六节写 `口径：本轮占比为自算…` |
| `LK-GAP` 说分母与总股本行不是同一个数 | 两处引了不同时点的总股本 | 统一到一个时点，并在六节写明取值时点 |
| `LK-LINE` 命中「约」「左右」 | 把确切数字改成了模糊词 | 公告写多少抄多少 |
| `LK-BOUND` 说跟踪口径混入已发生行为 | 头部口径句写串了 | 口径句以「解禁」起头 |

## 七、怎么开口

- **正例**：「这只票未来一年有几轮解禁」「下次解禁是哪天、多少股」「解禁股数占总股本多少、分母用的哪份文件的哪个时点」「当初的定增价是多少，这一轮解禁的成本在哪一档」
- **反例**：「解禁了会不会跌」「这轮解禁压力大不大」「该不该趁解禁前卖出」「给我个目标价」——这些本件不产出，会直接回 `[待人工]`。

---

## 八、能力边界（诚实清单）

- 只认公告原文。公告写得含糊的地方，本件跟着含糊并点名未取到，不替它补全。
- 解禁股东名单常不逐名列示，这类只能记到「发行对象家数」这一层，并写进未取到。
- 多轮解禁之间有无承诺、解锁条件是否达成，只能照公告写，公告没说的一句不添。
- 机检判的是形制与口径，判不了内容真假。数字对不对，最终要人回原文核对——这也是头部那四件自标的意思。
