# 双语文档约定（i18n）

**[English](i18n.md) · [中文](i18n.zh-CN.md)**

本仓文档双语化，做法参照 [sensedeal/cue-skills](https://github.com/sensedeal/cue-skills)。

## 文件对

| 文件 | 语言 | 角色 |
|---|---|---|
| `README.md` | 英文 | 权威版 |
| `README.zh-CN.md` | 简体中文 | 完整翻译 |
| `SKILL.md` | 见[单 skill 策略](#单-skill-策略) | agent 实际加载的文件 |
| `SKILL.zh-CN.md` | 简体中文 | 完整翻译 |

## 规则

1. **命名**：在扩展名前加 `.zh-CN`。不用 `_en` / `_zh` 后缀，不建 `lang/` 或 `locales/` 目录。
2. **两份文件的 frontmatter 必须完全一致**（`name` / `description` / `license` / `metadata.version`），只有正文语言不同——不能让 agent 看到两个不同的 skill 身份。
3. **译文开头要指向权威文件**，例如：「本文件是 `SKILL.md` 的完整中文翻译，语义与英文版一致。加载机制以英文 `SKILL.md` 为准。」
4. **每个双语页面顶部加语言切换行**：`**[English](X.md) · [中文](X.zh-CN.md)**`。
5. **改一个就要改另一个，同一个 commit 提交。** 版本号同步递增，两份不允许漂移。
6. **以下内容不翻译**：代码、脚本路径、命令行参数、JSON 字段名、文件名、硬规则编号，以及形式固定的专业术语。

## 单 skill 策略

每个 skill 在自己的 `README` 里声明权威语言。两种合法形态：

- **英文权威**（与 cue-skills 一致）：`SKILL.md` 为英文，`SKILL.zh-CN.md` 为中文翻译。
- **中文权威**：`SKILL.md` 为中文，`SKILL.en.md` 为英文翻译。适用于面向中文用户编写、且全量翻译风险高的 skill（例如体积很大、含大量编号硬规则的文件）。

每个 skill 选一种并在其 README 中写明，同一个 skill 内不允许混用。
