# 现金流质量·逐条挂源

给一份财报，把第三张表读成一张**每个数都能回到原句**的登记表：经营活动、投资活动、筹资活动三项现金流，加上净现比、收现比、自由现金流，以及净利润调节表。

利润表看的是赚了多少，本件看的是**赚到的钱有没有真的收回来**。

**不判造假、不判暴雷、不预测下期现金流、不给评级与目标价。** 比率只认披露值；要自己算的，必须单列并交代分子分母各出自哪一句。

---

## 一、打开就干：三步

1. **定主体与报告期**，拿到年报/半年报原文（现金流量表、合并利润表、现金流量表补充资料三处）。
2. **每节抄事实，连原句一起抄**：一个数 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_cash_flow.py 你的现金流稿.md
python3 scripts/check_cash_flow.py --selftest      # 12 条内置夹具自检
```

退码 `0` 全过、`1` 有发条、`3` 读不到文件或空稿。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `CF-STRUCT` | 形制 | 头部四件自标、`主体：`、`报告期：` 在场；六节齐且有序；前五节各至少一条发现行 | 六节缺一节；某节只有小标题 |
| `CF-QUOTE` | 原句与锚 | 每个数字行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行带可点 URL 与检索日；引用的编号须已登记 | 只写数字没抄原句；来源行只有标题没有链接 |
| `CF-NOSELF` | 不得自算 | 净现比／收现比／自由现金流的数值原句没写就必须标 `〔自算〕` 并写明分子分母各出自哪句；调节表不许合并、不许取绝对值 | 拿经营现金流÷净利润当披露值；把调节表几项合成「合计」 |
| `CF-GAP` | 未取到两向点名 | 正文写了未取到而第六节没列要发，反之也发；零缺口须显式写「未取到：无」 | 用「不适用」「无此项」「无需披露」搪塞 |
| `CF-LINE` | 红线 | 造假、暴雷、资金链断裂、下期预测、评级目标价、建议关注零命中 | 「经营现金流为正说明不存在财务造假」 |

## 三、四条红线（这件的立身之本）

1. **净现比不许自算充披露值。** 「经营活动现金流净额」与「净利润」是两个口径，报表没在同一句写这个比值，就必须标 `〔自算〕`。
2. **间接法调节表逐项照抄。** 「资产减值准备」「存货的减少」不许合并、不许取绝对值——正负号就是信息本身。
3. **自由现金流不自创口径。** 要么照抄披露值，要么标 `〔自算〕` 并写明资本开支取的是哪个科目。
4. **期末现金余额 ≠ 货币资金。** 现金流量表的「期末现金及现金等价物余额」与资产负债表的「货币资金」不是一个数，不许互相印证当作相等。

## 四、一条发现长什么样

```markdown
- 经营活动产生的现金流量净额 12,340.00 万元「经营活动产生的现金流量净额 123,400,000.00 元」〔锚：2025 年年报·第 58 页·合并现金流量表〕[S1]
```

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 净现比为 1.21 倍〔自算〕分子＝经营活动产生的现金流量净额 123,400,000.00 元 [S1]｜分母＝归属于母公司所有者的净利润 102,000,000.00 元 [S2]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 现金流量表、净现比、收现比、自由现金流 | **本件** |
| 利润表逐数点评：四期差异、科目勾稽 | `cn-earnings-note` |
| 存货、应收账款、合同资产的余额与账龄 | `cn-working-capital-quality` |
| 商誉减值风险 | `cn-goodwill-impairment-risk` |
| 分红、回购、减持 | `cn-shareholder-return` |

## 六、零通道：先排骨架

没有通道产物也能跑，本脚本只读你给的那份清单：

```bash
python3 scripts/make_outline.py 清单.jsonl 骨架.md
```

清单是 JSONL，每行三键必需：`title`／`url`／`asof`（检索日 `YYYY-MM-DD`），`id` 可省按行序给 `S1`/`S2`…

- 坏行（非法 JSON／缺键／日期不合形／url 不是 http）**逐行点名、不采信**，好行照收。
- **空清单退 1，不出空壳。**
- 排出的骨架**故意过不了机检**，这是设计，不是待修。

```bash
python3 scripts/make_outline.py --selftest       # 7 条内置夹具
```
