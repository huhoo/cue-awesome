# 现金流质量·逐条挂源

**定位**：给一份财报，把第三张表（现金流量表）读成一张**每个数都能回到原句**的登记表。
利润表看的是赚了多少，本件看的是**赚到的钱有没有真的收回来**。

**不是**造假鉴定，不是暴雷预警，不是评级报告。

## 0. 什么时候用 / 不用

| 你要 | 用什么 |
|---|---|
| 经营现金流与净利润背离多少、收现比多少、自由现金流多少、三张表的钱从哪来往哪去 | **本 skill** |
| 利润表逐数点评：四期差异、科目勾稽、指引与兑现对照 | `cn-earnings-note` |
| 存货、应收账款、合同资产的余额与账龄质量 | `cn-working-capital-quality` |
| 商誉减值风险 | `cn-goodwill-impairment-risk` |
| 分红、回购、减持 | `cn-shareholder-return` |
| 判断这家公司是不是财务造假、会不会暴雷 | 不做——本件只登记披露过的事实 |

**与 `cn-earnings-note` 的分界**：那一件从利润表出发，本件从现金流量表出发。同一份财报，本件只抄现金流量表与调节表里的数，利润表数字只作为比率的分母出现，且必须挂它自己的来源。

## 1. 六节形制

一份合格的稿子必须有且仅有这六节，顺序固定：

| # | 节 | 记什么 |
|---|---|---|
| 1 | 经营活动现金流 | 经营活动现金流量净额，以及构成它的主要项目（销售收现、购买商品付现、支付给职工的现金、支付的各项税费） |
| 2 | 投资活动现金流 | 投资活动现金流量净额，以及购建固定资产等长期资产支付的现金（资本开支）、投资支付的现金 |
| 3 | 筹资活动现金流 | 筹资活动现金流量净额，以及取得借款收到的现金、偿还债务支付的现金、分配股利利润或偿付利息支付的现金 |
| 4 | 净现比与收现比 | 净现比＝经营活动现金流净额÷净利润；收现比＝销售收现÷营业收入；自由现金流＝经营现金流−资本开支 |
| 5 | 净利润调节表（间接法） | 从净利润调节到经营活动现金流量净额的逐项调节，**逐项照抄** |
| 6 | 口径与未取到 | 口径说明与未取到的逐条点名 |

另有一节 `## 来源` 承接来源行——CF-QUOTE 要求来源行带 URL 与检索日，它不塞进第六节，故独立成节。

## 2. 原句与锚（CF-QUOTE）

每个数字行行末必须是：

```
- 经营活动现金流量净额 12,340.00 万元「经营活动产生的现金流量净额 123,400,000.00 元」〔锚：2025 年年报·第 58 页·现金流量表〕[S1]
```

- **原句**：用「」包住，从来源里**连续**摘录，不改写、不拼接。
- **锚**：`〔锚：…〕`，页码、章节号、表格名、段落序号之一。
- **编号**：`[S#]` 与来源节那一行对应。
- 一个数由多处支撑就挂多组，不合并成一句假原句。

## 3. 四条红线（CF-LINE 与 CF-NOSELF 的判据来源）

1. **净现比不许自算充披露值。** 「经营活动现金流净额」与「净利润」是两个口径。比率要拿两者相除，除非报表同一句写了这个比值，否则必须标 `〔自算〕` 并写明分子分母各出自哪一句。
2. **间接法调节表逐项照抄。** 「资产减值准备」「存货的减少」「经营性应收项目的减少」这些项目**不许合并、不许取绝对值**。调节表里正负号就是信息本身。
3. **自由现金流不自创口径。** 各机构口径不同。要么照抄披露值，要么标 `〔自算〕` 并写明资本开支取的是哪个科目（「购建固定资产、无形资产和其他长期资产支付的现金」）。
4. **期末现金余额 ≠ 货币资金。** 现金流量表的「期末现金及现金等价物余额」与资产负债表的「货币资金」不是一个数（受限资金、等价物范围不同）。不许互相印证当作相等。

另：不判「现金流造假／暴雷」，不预测下期现金流，不给评级与目标价，不写「建议关注」。

## 4. 五道机检

判据以 `scripts/check_cash_flow.py` 现值为准，本节是口径说明：

1. **CF-STRUCT 形制**：六节齐且有序、每节至少一条发现行；来源节在场。
2. **CF-QUOTE 原句与锚**：每条数字行带 `「」原句＋〔锚：…〕＋[S#]`；来源行带 URL 与检索日；引用的编号必须在来源节登记。
3. **CF-NOSELF 不得自算（承重格）**：净现比、收现比、自由现金流及一切百分数/倍数，原句里没有同一数值就必须标 `〔自算〕` 并同时给出分子与分母各自的 `[S#]`。
4. **CF-GAP 未取到两向点名**：正文写了未取到而第六节没列要发；第六节列了而正文没有这条也发；零缺口须在第六节显式写「未取到：无」，禁用「不适用／无此项／无需披露」搪塞。
5. **CF-LINE 红线**：造假、暴雷、资金链断裂、下期预测、评级目标价、建议关注一类断言零命中。

## 5. 来源节

```
## 来源

- [S1] 示例科技 2025 年年度报告 | https://example.com/ann/S1 | 检索日 2026-11-09 | 类型：公告
```

URL 必须可点；拿不到就写进第六节「未取到」，不进来源节。检索日是**实际检索那天**，不是财报发布日。

## 6. 零通道与做法

`scripts/make_outline.py` 把材料清单排成骨架，**零通道也能独立跑**（不需要任何通道产物）：

```bash
python3 scripts/make_outline.py 清单.jsonl 骨架.md
```

清单是 JSONL，每行三键必需：`title`／`url`／`asof`（检索日 `YYYY-MM-DD`），`id` 可省按行序给 `S1`/`S2`…
坏行逐行点名不采信；空清单退 1，不出空壳。**骨架故意过不了机检，是设计**，不是待修。
