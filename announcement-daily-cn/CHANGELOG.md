# 更新日志

### 0.1.1 — 2026-11-02（机检追上本面第 37 行那句既有承诺＝能力面变更，非新增能力：新增「值位不许占位顶替」这一档）
- 改的是什么：`scripts/check_digest.py` 的机检从四道增至五道，新增 `FILLER` 档——逐条要点行的值位（「要点：」到「锚：」之间那一段）若整体为空、剥掉空白与各类标点括注后只剩单字，或值位里任一处引号（«»、「」、『』、“”）内为空、只剩单字或只剩标点，一律发红；带「未检索到」那一格的行照旧豁免（没取到该走的是缺数清单，不是占位）。判据只加不减，原四道的射程一字未动。
- 为什么这是能力面而非文字面：本面「是什么／不是什么」那张两列表第 37 行早就写着左栏「未取到＝明写『未检索到』并进缺数清单」、右栏不许「用常识补写公告内容、留空顶替」；此前尺只判形制齐不齐，值位写成 `«略»` 或干脆留空照样 PASS——面上有承诺、尺上不兑现，是缺档。本次让尺追上那一句，两列表那两栏原文一字未动（本版对上一版的差只有版号一行与机检那一节一行）。
- 五形两头值（同一枚夹具跑两版尺：形一 引号槽内为空 `«»`、形二 引号槽内只剩单字 `«略»`、形三 引号槽内只剩标点 `«——»`、形四 值位整体只剩单字（整段替成 `«略»`）、形五 值位整体留空（`要点： 锚：…`））：改前跑上一版尺五形全 PASS（退码 0、静默），改后跑现尺五形各自 rc=1 且红在 `FILLER`；未注入的原好样在两版尺上均 PASS＝真值不报、复原必绿。
- `--selftest` 随之加长：坏样现在五道各发一条并逐条点名行号；五形钉阈各成一档，各钉自己那条说明句（引号槽那三形钉「引号内是空、只剩单字或只剩标点」，值位整体那两形钉「剥掉标点与括注后为空或只剩单字」），断言里带注入生效核对——夹具串与原文不等才计入，空注入作废。临时件仍建在一次性目录里、退出时自清。
- 随面改动：`SKILL.md` 机检那一节改写为五道并点出新档；`README.md`／`README.en.md` 的小标题、过闸句与 `--selftest` 注释同步；`scripts/fixtures/bad-digest.md` 的补助那一行改为占位形以让第五道真发。红线句、缺数句与那张两列表的原文均不动。
- 本版不复写上版的读数；出包 digest 与首屏以各闸自报行为准。

### 0.1.0 — 2026-11-02（本枚首次建包：A股公告的清单级速览，两条取证腿与四道机检随包）
- 选题来路：问法是「今天有什么公告」「我这清单里哪几只发了业绩预告」——问的是清单，不是单份公告的条款。单份拆解那一层已有姊妹件 `event-brief-cn`（本件列「今天有哪几条」，那件拆「这一条讲什么」），清单级逐条要点这一层本仓没有对应件，本枚补这一层，两面分工在 `SKILL.md`「是什么／不是什么」那一表与 `README.md` 导语各写一句，不重叠也不互指空位。
- 产出契约（四段，缺一即退回）：头部申报（对象枚数／日期窗／通道现值／本次是否发起过解析腿）→ 逐条要点（形制＝`[披露日] 公告标题逐字 — 要点：关键数逐字 锚：<来源定位>`）→ 同类事项前后串 → 缺数与待人工。原文在 `SKILL.md`「输出契约」那一节，逐条要点那一行的四枚要素（日期、标题、关键数、锚）由随包机检按形制判，不靠约定。
- 红线：评级、目标价、走势与持续影响判断一律挂 `[待人工]`；未检索到照实写「未检索到」，禁以常识补写公告内容、禁以「无」顶替空窗；数字逐字，不四舍五入、不写「约」；取不到代码只列名并标「代码待补」，不代填。
- 两条取证腿：清单取数在数据腿上，附件正文与长附件在解析腿上。两条都写成可选并各自带代价——不装也出清单骨架，代价是条款级差异与附件正文看不到、要点只能停在清单级。指路只给指针、不复述开通步骤：数据腿官方配置页 <https://cuecue.cn/hub/mcp>；解析腿官方配置页 <https://cuecue.cn/hub/omni-reader>；取 key 走 <https://cuecue.cn/hub/api-key>。域与工具名以 live catalog 现值为准，三面不列固定清单、不承诺枚数与实时性。
- 名形制：`displayName` 取「公告速览·A股」＝意图词落在词首＋名短；目录名与 frontmatter `name` 同值 `announcement-daily-cn`，`slug` 为 `cue-announcement-daily-cn`，`SKILL.md` 的 H1 随 displayName 走同一短形。
- 随包机检：`scripts/check_digest.py` 四道——形制与四段齐、逐条双要素与锚、红线断言只准出现在 `[待人工]` 行、计数与申报一致；零网络。`--selftest` 直接吃 `scripts/fixtures/` 那两份样例（好样须过、坏样四道齐发并逐条点名行号），临时件建在一次性目录里、退出时自清。
- 首测：本枚建包当拍各闸的读数与出包 digest 以各闸自报行为准，本条不复写。
