# sector-overview

**本文件为中文主面；英文版是同目录下的 `README.en.md`（仓库内查阅用——渠道页不解析相对链接，这里不做可点切换）。**

「这行业回暖了。」——凭什么？

大多数行业报告答不上这个问题：判断词满天飞，翻遍全文找不到一条可比序列。本件反着做：
**输入行业名 + 窗口，还你一份六节简报（≤6 页），其中每一个判断词（「升/降/回暖/承压/拐点」这类——哪些词算判断词以机检脚本现值为准，本文只举常见例）都必须同句挂着
它引用的那条序列（S 锚，含口径与截止日期）——挂不上的句子，就老实写「无可比序列，不做景气判定」。**
薄一点没关系，没锚的判断一句不给。

**输入**：行业（申万/中信一级或口语名，歧义列候选拒猜）+ 窗口（缺省近 4 个完整季度）+ 可选角度
**输出**：`sector-<行业>-<窗口>/` —— `report.md`（画像与结论/量价与驱动/供需与产能/格局与代表公司/政策时间线/复核清单）· `sources.jsonl` · 台账
**代价**：五段管线+四道机检；深研 ≤1 次（发起前报成本征询）；默认不碰任何预期类均值

## 一、和另几件怎么分

| 你要 | 用什么 |
|---|---|
| 一个行业近四季的冷热证据（每个判断词当场可查凭据） | **本 skill** |
| 某家公司财报深度点评 | `cn-earnings-note`（覆盖账本/beat-miss 在其契约内） |
| 见客户前 30 秒的一页纸 | `tear-sheet` |
| 持仓未来三个月的日期表 | `catalyst-calendar` |
| 「看好哪个行业」 | 哪儿都不给——本件评级词零容忍且**无豁免区** |

## 二、为什么值得用（三条硬话）

- **判断词-锚同行**是本件的命门，也是机检第二道：哪些词算判断词不靠本文列举，**判定=`check_sector.py` 里 `JUDGE_PHRASE` ∪ `JUDGE_SINGLE` 两条现值**（上文只举常见例，**例不穷尽**；全量一条命令自查，见 §五 注行）⇒ 命中即同句含 `S<n>` 或整句走逐字态二句（非逐字改写句只要还带判断词或态二提示词即 FAIL；两者都不带的含糊句机器不认，归人工复核）——
  判断词无锚，按本套件的定义就是幻觉（姊妹件日期幻觉的行业版）；
- **维度不背模板**：每次运行先由深研按行业类型动态生成 2–4 个分析维度（养殖看存栏、光伏看排产），
  不套上一个行业用过的框架库——行业是每次现问的，不是每次默写的；
- **协会口径全标可信级 L3（深研二手）**、进复核清单；行业均值的预期类数字默认不取（高危超售话术，从源头不碰）。

## 四、首次开通 Cue（三步，可跳过）

取证腿装 `cue-data-mcp` / `cue-research`（`cue-omni-reader` 按需）——这几枚由 Cue 官方技能集合（sensedeal）发布：整套 `npx skills add sensedeal/cue-skills`（列出该集合公开的各枚，按提示挑），单装 `npx skills add sensedeal/cue-skills --skill cue-data-mcp`（把末尾那枚换成 `cue-research` 或 `cue-omni-reader` 就只装那一枚）。装本件是上一节那条 `huhoo/cue-awesome --skill sector-overview`，两件事别混。
注册 <https://cuecue.cn>（新账号注册送 500 积分、每日 10 积分，以服务端为准）→ <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 入本地凭据（别贴进聊天，也不在终端回显）。
三层各自能证到什么，互不等价：**装好 skill ≠ 已配凭据 ≠ 通道已连**。装好＝重列一次已安装 skill 看得到上面那些名字（只证明文件到位，不证明取到数）；配好凭据＝那把 key 存在于本地凭据设施即可，**key 在场不等于 key 被接受**，接受与否要到下一层才判得出；已连＝带上那把 key 按目标域 `routing` 里的 `url` 实连（`Authorization: Bearer <$CUE_API_KEY>`，并带 `Accept: application/json, text/event-stream`——缺这个头会 406，是协议行为不是鉴权失败）且 `tools/list` 有返回，工具名与入参 schema 以那份返回现值为准。匿名 `GET` 块里那枚 `CATALOG` 有返回**只证目录可达**，本件不把它叫「已连」；连接报错≠域无数据，如实报。

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
[print(r.get("id"), r.get("external_status"), (r.get("routing") or {}).get("url", "-")) for r in rows]'
DOMAIN_ID="<把这里换成上一行列出的那个域 id>"
ROUTING_URL="$(curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
hit=[r["routing"]["url"] for r in rows if r.get("id")==sys.argv[1] and r.get("routing")]
print(*hit,sep="\n") if hit else sys.exit("未取到：该 id 不在目录现值里（或它没有 routing 里的 url 字段）——先跑上面那行列出现场的 id 再填")' "$DOMAIN_ID")"
[ -n "$ROUTING_URL" ] || { echo "取值失败：ROUTING_URL 为空——先跑上面那行列出现场 id，再把 DOMAIN_ID 换成其中之一" >&2; exit 1; }
curl -s -X POST "$ROUTING_URL" \
  -H "Authorization: Bearer $CUE_API_KEY" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  -w '\nHTTP %{http_code}\n'
```

取值：块里 `CATALOG` 是本面唯一一处目录入口字面（赋一次、散文不重抄）；`$ROUTING_URL` ＝上面那两行从该域 `routing` 里的 `url` 字段现取的逐字值，别把域名或路径抄死在这张面上；`$CUE_API_KEY` 取自上一层那把本地凭据，不进聊天、不在终端回显，本块不新增任何凭据读取动作。
通过＝HTTP 200，且返回体里 `result.tools` 非空（只按形状认，形如 `{"result":{"tools":[…]}}`；本面不列具体工具名，也不承诺枚数）。
一句现场精度：这处端点可能以 SSE 形回字（一行 event、紧跟一行 data），要看的 result.tools 就在那条 data 载荷里——判据不变，只是回字在外层多包了一层。
一条命令形（不必手改块里那一行）：`cd sector-overview && python3 -B scripts/cue_connectivity_check.py --domain <你的域 id> --post`。这支随包件缺省一个包都不发——不带 --post 时只把该域 routing 里的 url 取出来给你看；有哪些域 id 可填，先跑同一支脚本的 `--list`（只列在场域与 url，不发 POST）。本件不另立判据：退码 0，退 4＝还没证过连通（带上 --post 再跑一次），退 5＝连上了但现场值没满足它，退 1＝取不到、发不出去、或 HTTP 层报错（含 4xx 与 5xx），退 6＝目的地没过凭据外发两关（本件拒发，一个凭据字节都不附），退 7＝目录入口本身不是 https。按默认目录入口时，本件只验运行端点连通，不向渠道发布、不产生受理。**换源不免检**：无论那个 url 来自缺省目录、--catalog-url 还是 --catalog-file 那份快照，带 key 那一次发出去之前都要过同一道两关——scheme 必须是 https，且 host 命中授权后缀（缺省那一枚由件头那处目录入口现值推出，不是本件另编的一张清单；要显式放行别处请带 --allow-host）；过不了就拒发，并把拒绝原因与那个 host 印在回字里，本件不读 key、也不构造那个请求。代价同句写明：老的「换进去什么就打什么」那一形关掉了，换来的是凭据不会外发到未授权目的地；若你的正当端点恰在授权后缀之外，退 6 是请你用 --allow-host 显式认下它，不是断言那枚端点不该存在。

不装不报错，代价是通道直查那一层整块缺位：你贴协会月报/统计原文也能跑（标「用户直供」），但判断词-锚纪律不放松——直供素材当锚挂得上的才配判断词。

## 六、常见问题与反模式（你想这么用 → 本件不接，因为 → 替代去向）

只重组已审清的铁律与边界条款；判断词族、被禁词族、推测词族与锚形制的判据全集以 `check_sector.py` 现值为准（定位命令见 §五 注行）。

| 你想 | 本件接不接，为什么不接 | 替代去向 |
|---|---|---|
| 直接说这行业能不能买 | **不接**。评级那一类词零豁免区（无列位例外，也无「只是口头」例外） | 本件交的是带可比序列锚的冷热证据；结论由人下 |
| 保留「回暖 / 承压 / 拐点」那类判断词但不给锚 | **不接**。判断词与锚同行是命门，机检第二道就是它 | 当场取到可比序列锚才写；取不到就写态二（薄简报），不回退旧值顶替 |
| 拿推测句式补一个当场取不到的数 | **不接**。缺数走申报，不走补数 | 缺数申报 + 复核清单挂行 |
| 按一套固定行业框架直接套 | **不接**。维度不背框架库，每次由深研按行业类型动态生成 2–4 个再取数 | 接受动态维度；要固定框架属另一种产品，不在本件 |
| 行业一家序列都取不到，还想交六节满量 | **不接**（合法形状是空结论）。空结论合法，无锚判断违法 | 态二简报 + 说明为什么薄；硬凑就是机检要拦的 |
| 把某只票的近期冷暖也写进来 | **不在本件面**（本件主体是行业）。个股速览是姊妹件 | 一页速览用 `tear-sheet`，财报点评用 `cn-earnings-note` |

## 七、出错了怎么办（症状 → 原因 → 恢复动作）

**未见于本次返回的一律写「未检索到」**：参数名、字段名、枚举值没有出现在本次工具返回里的，不得凭印象填写；写「未检索到」并记入待核清单或覆盖率账，不得留空顶替。

**Error 级＝blocker**：机检报出的 Error 级条目不得称「无害」「可忽略」「先交出去再说」；修完，或在交付面显式申报，才算出口。

形制按 `check_sector.py` **当前出口**现跑取得：失败一行 `FAIL: <文件>（N 条）`，其下详行**先打错误码前缀（五枚 `E-*` 之一）、后接道名标签**（`[E-FORMAT] [参数]`、`[E-BANWORD] [③]`、`[E-ANCHOR] [②]`、`[E-FORMAT] [④]` 等），再接行号与该道规格；末行 `码表:` 只列本次用到的码与含义。全过印 `PASS: <文件>（四道全过:声明/命门/禁词/形制）`。

五码为全族同源封闭集（与四件姊妹件逐字一致）：`E-FORMAT`／`E-ANCHOR`／`E-BANWORD`／`E-COVERAGE`／`E-LEDGER`。处置写在出口的 `码表:` 行里，本件哪道标签归哪枚码是脚本内的分类表——一条命令原地取（把 §五 那条 grep 的关键词换成下面两个）：

    grep -n "^E_LEGEND\|^E_RULES" ~/.workbuddy/skills/sector-overview/scripts/check_sector.py

| 症状（详行前缀） | 原因 | 恢复动作 |
|---|---|---|
| `[E-FORMAT] [参数] 缺 --window(…)` | 正式命令式必传窗口（反 wall-clock） | 补 `--window YYYY-MM-DD~YYYY-MM-DD`，与正文声明窗口逐字一致 |
| `[E-FORMAT] [①] / [④] …` | 声明节缺失，或六节形制、表列位、行序不合式 | 按该行括号内规格复原形制；本件形制是固定的，不自行增删节 |
| `[E-ANCHOR] [②] …` | 命门未守：写了冷暖类判断，同行没有可比的序列锚 | 补当场取回的序列锚（域 + 具体值 + 期间），补不出就把该句改成申报或缺数陈述 |
| `[E-FORMAT] [④] sources 第 N 行字段 … 缺失或为空`（同类还有 id 非 S<n>、kind/confidence 非枚举、asof 非日期） | 取证账不成形：字段缺或取值非法 | 按该行括号内规格补 sources 行；深研件须 `conv_id` + 落盘路径 |
| `[E-BANWORD] [③] 第 N 行命中…` | 被禁词族进了正文（评级、价位、买卖动作那一类） | 改中性或删除；本件无豁免区，词表全集见 §五 定位命令 |
| `[E-COVERAGE] [④] 第 N 行数字/序列行未锚:含数值而本行无 [S<n>]（缺数须申报）` | 含数值的行没带锚，缺数也没走申报 | 补 `[S<n>]` 锚，或把该行改成缺数申报；缺就是缺，不回退旧值顶替 |
| `[E-ANCHOR] [④] 正文孤儿锚:S<n> 在 sources 不存在（④双向账）` / `[E-ANCHOR] [④] 法定锚不可核:statute …` | 正文有锚而账里没有（断链），或法定锚形制不可核 | 补该锚的 sources 行与原始快照；statute 类须《法名》第N条（要点）三件齐，否则删该行 |
| 证据目录缺失或哈希对不上 | 证据 fail-closed | 补原始回包快照并重记账；改不动就删该条主张 |
| 协会/域数据窗口内断更 | 当期无更新（数据形状，不是脚本报错） | 缺数申报 + 挂复核清单；深研发起前先报成本（消耗花之前先问） |
| Traceback 而不是 `FAIL …（N 条）` | 属事故：本件定义零崩溃，解析点全 try 化 | 停手回报：稿件与整条命令记进台账，先跑 §五 的守护样命令区分稿件问题与脚本问题 |

## 八、怎么开口（触发示例：三条正例 + 一条反例）

**开口请带上时点，输出标数据日期**：请求里给出报告期／基准日或回看窗口；成品首行标注**数据日期**，当它与用户所指日期不一致时，正文禁用「今日」「最新」，一律改写为「截至 <日期>」。
- **正例（行业 + 角度）**：「光伏行业近况盘一下，重点看排产和价格」——§三 那句，≤3 问补齐（行业名 / 窗口 / 角度）。
- **正例（歧义行业名，会先消歧）**：「消费电子链上半年怎么样」——「消费电子」可指面板、可指终端、也可指零组件，
  本件列候选请你选，**不替你猜**；选定后窗口默认取近 4 个完整季度并回显。
- **正例（多角度 + 指定窗口 + 政策锚要求，复杂输入）**：「工程机械，窗口 2025-01-01~2026-06-30，看三个角度：
  开工小时数、挖掘机销量、出口结构；政策与规划那节只收当场取回、名称+条号+短引三件齐的原文锚」
  ——三件不齐的政策锚不落行，落 `progress.md` 一行拒推理由。
- **反例（相邻需求，本件不接）**：「宁德时代这只票最近一页纸」→ `tear-sheet`；「2026Q2 财报深度点评」→
