# watchlist-digest-cn · 自选清单增量日报(P0 骨架)

一份你维护的自选清单,每天跑一次只给**增量**:回购、股权激励、两融标的与折算率、A股港股披露公告、中国监管措施五腿,逐条带官方出处与 asof;窗口内没东西就明写「未检索到新增」,不写「无风险」。不评风险、不给评级,不构成投资建议。

- 第一次进入:给 agent 一组公司名或六位代码,第一句说「把这几只落成清单,跑今天的增量日报」。
- 能力边界:行情、涨跌、资金流与北向**本件没有这条腿**(该数据域当前未开放,以 catalog 现值为准);本件也不自带定时,只提供幂等命令与退出码,调度在你自己的那一侧。
- 状态:**P0 骨架,未上架**;件级实测(真清单连跑两日、逐条可回查)未做,因此不作能力宣称。
