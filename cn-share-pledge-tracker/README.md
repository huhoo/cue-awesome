# 股权质押与解押跟踪·逐条挂源

把同一股东的多次质押与解押公告串成一条余额变化线，每笔挂公告原句与锚；比例只认公告写的，不自己拿股数除。

## 一、打开就干：今天这三步

1. 把质押/解押公告（URL 或本地文件，可多份）交给本件。
2. 本件逐笔登记六要素（质押：出质人·质权人·股数·占所持比例·占总股本比例·质押期间）／三要素（解押：出质人·解押股数·解押日期），每笔挂原句与锚。
3. 累计与剩余写成「前值 → 后值」；公告没写的进未取到清单，判断类问题全部进「待人工」。

## 二、五道机检（零网络）

```bash
python3 -B scripts/check_pledge_tracker.py <卡面.md>     # 五道码逐条发红，全过则 PASS
python3 -B scripts/check_pledge_tracker.py --selftest    # 好样须过、坏样六枚各发其码
bash scripts/fixtures/run_fixtures.sh                    # 离线样例三档（30 秒、零网络零计费）
```

| 码 | 判什么 |
|---|---|
| `SP-STRUCT` | 五段齐；变动明细段每笔**行级在场**；质押行六要素齐、解押行三要素齐；累计与剩余每行须是「前值 → 后值」两处之差 |
| `SP-QUOTE` | 每行书名号内原句不得为空或只剩单字；「锚：」在而锚值为空同样发 |
| `SP-LINE` | 红线三道：定式禁词（平仓风险判断／比例高低评价／股价预测／评级目标价／收益承诺／代办）／主题词×判断语气同段／自裁效力层 |
| `SP-GAP` | 未取到两向点名（申报多了是虚报、少了是漏报）；「不适用／无需披露」一律发；**比例数字必须在该行自己的原句里**，否则判「自算比例」 |
| `SP-BOUND` | 出现股东回报速读的项行 ⇒ 改走 `cn-shareholder-return`；出现单份公告速读的单选行 ⇒ 改走 `event-brief-cn` |

3. 连通自查：

# 2) 按 MCP 协议握手，确认三枚工具在场

## 五、边界与不承诺

- 不判平仓风险（有平仓风险、面临平仓、爆仓风险、触及预警线、触及平仓线、风险可控、风险不大、质押安全）。
- 不评比例高低（质押比例偏高、偏低、合理、过高、充分、不足）。
- 不预测股价（股价将、股价会、利空、利好、压制股价、提振股价、拖累股价）。
- 不给评级与目标价。
- 不承诺收益（稳赚、零风险、保证收益、必涨、必跌）。
- 不代拟、不代算、不代申报、不代客。
- 不裁断效力（质押是否有效、是否违规、是否合规）。
- 不重复登记分红回购减持——那是 `cn-shareholder-return` 的活；不做单份公告的事件速读——那是 `event-brief-cn` 的活。

## 六、出错了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `SP-STRUCT 缺段` | 五段标题被改名或漏写 | 按 SKILL.md §3 输出契约的五段标题原样写 |
| `SP-STRUCT 本次变动明细段内无质押/解押行` | 变动只在散文里提到 | 每笔单独一行，以 `- 质押：` 或 `- 解押：` 起头 |
| `SP-STRUCT 质押行缺要素：质权人` | 该笔原句没写质权人 | 公告没写就整笔改成「未取到」，不许补常识 |
| `SP-STRUCT 累计与剩余行不是「前值 → 后值」两处之差` | 只写了当前余额 | 补上前值，写成 `前值 → 后值` |
| `SP-QUOTE 书名号内原句为空` | 抄成了概括或留空 | 回原文抄原句，不许转述 |
| `SP-GAP 申报共 N 笔…` | 头部申报与明细段行数不符 | 数一遍明细段有几行 |
| `SP-GAP 比例 … 不在本行原句里` | 比例是卡面自己拿股数除出来的 | 删掉自算的比例；公告没写就写「未取到」 |
| `SP-BOUND 出现股东回报速读的项行` | 写成了分红回购减持速读 | 改走 `cn-shareholder-return` |
| `SP-BOUND 出现单份公告速读的单选行` | 写成了单份公告事件速读 | 改走 `event-brief-cn` |
| `SP-LINE 定式禁词` | 写了平仓风险判断、比例评价或股价预测 | 删掉，改成原句登记或进「待人工」 |

## 七、怎么开口（正例与反例）

**正例**

- 「这个控股股东质押了多少、占所持多少、占总股本多少？」
- 「隔了三周又质押了一笔，帮我串起来看余额怎么变。」
- 「这次解押了多少、什么时候解的？」

**反例**

- 「这个质押比例高不高、有没有平仓风险？」→ 本件不判风险、不评比例，只登记原句。
- 「质押这么多，股价会跌吗？」→ 本件不预测股价。
- 「帮我算一下质押比例。」→ 本件不代算；比例只认公告写的。
- 「这份公告讲了什么？」→ 那是单份公告速读，改走 `event-brief-cn`。

## 八、能力边界（诚实清单）

- 比例只认**该行自己的书名号原句**里的百分比；公告只写股数不写比例时，本件判「未取到」，不替你除。
- 累计与剩余判的是**两处之差在场**，不判前后值算得对不对；余额加减请人工复核。
- 六要素／三要素判的是**名词在场**，不判数值真伪。
- 解押日期判的是**标签或日期在场**：「解除质押登记日／解押日／解除日／购回日」任一在场，或行内出现 `2026 年 6 月 12 日`、`2026-06-12`、`2026/6/12`、`2026.6.12` 之一。
- 公告用「T 日」「空白期首日」这类相对表述时需人工换算；本件不替你推日历。
- 出质人别名按原句认（控股股东、大股东、股东名称等），不做主体归一；同一主体在不同公告里写法不同时，累计行请人工对齐。
