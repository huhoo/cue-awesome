# 股权质押与解押跟踪·术语与判据

本件只回答一件事：**同一股东的质押余额怎么变**。
质押/解押公告说了什么，在本件里只以「六要素／三要素 + 原句 + 锚」的形制登记，不评风险、不评比例高低。

## 一、两类变动

| 类别 | 项行写法 | 余额方向 |
|---|---|---|
| 质押 | `- 质押：「原句」 锚：出处` | 所持被质押的股数增加 |
| 解押 | `- 解押：「原句」 锚：出处` | 所持被质押的股数减少 |

只有这两类进「本次变动明细」段。分红、回购、减持不在此登记——那是 `cn-shareholder-return` 的活；
单份公告的事件速读是 `event-brief-cn` 的活。

## 二、六要素与三要素

**质押行六要素**（非「未取到」的行必须齐，缺一即发 `SP-STRUCT`）：

| 要素 | 认什么（别名族） | 不认什么 |
|---|---|---|
| 出质人 | 出质人、质押人、质押股东、出质股东、股东名称、控股股东、大股东 | 「该股东」「其」这类指代 |
| 质权人 | 质权人、质权方、受托人、质权代理人、银行、信托、证券、资产管理 | 只写「相关金融机构」 |
| 质押股数 | 质押数量／股数、本次质押股份数量、质押 N 万股 | 持股总数、总股本（那是比例的分母，不是本次质押量） |
| 占所持比例 | 占其所持公司股份的 X%、占其持股、占所持股份 | 只写股数，比例留空 |
| 占总股本比例 | 占公司总股本的 X%、占总股本 | 同上 |
| 质押期间 | 质押期限／期间／起止、起始日、到期日、质押登记日、解除日、购回日 | 「长期」「至办理解除登记止」这类无数值的表述（属未取到） |

**解押行三要素**：

| 要素 | 认什么 | 不认什么 |
|---|---|---|
| 出质人 | 同质押行出质人别名族 | 同 |
| 解押股数 | 解除质押股份数量、解押股数、本次解除质押 N 万股 | 剩余质押总量（那是累计段的格） |
| 解押日期 | 解除质押登记日、解押日、解除日、购回日 + 一个日期 | 只写「近日」「已完成」（属未取到） |

要素判的是**名词在场**，不判数值真伪；股数与比例的算术关系请人工复核。

## 三、累计与剩余：必须是两处之差

「累计与剩余」段每行写成 `前值 → 后值`，两侧各须有数字：

```
- 示例控股集团有限公司：累计质押 4,500 万股 → 累计质押 6,000 万股
- 示例控股集团有限公司：占其所持股份 30.00% → 占其所持股份 40.00%
- 示例控股集团有限公司：占公司总股本 9.00% → 占公司总股本 12.00%
```

只写当前余额（一处）不构成变化，`SP-STRUCT` 直接发。三行不必齐——公告只披露口径之一时，
另一口径写「未取到」并进未取到清单。

## 四、本域最要紧的一格：比例不得自算

`SP-GAP` 的第三条：**比例数字必须在该行自己的书名号原句里出现**。

```
- 质押：「出质人示例控股集团有限公司，质权人中国工商银行股份有限公司，本次质押股份数量 1,200 万股，质押期限自 2026 年 6 月 12 日至 2027 年 6 月 11 日」 占其所持公司股份的 8.00%，占公司总股本的 2.40% 锚：公告 二、本次质押情况
```

上面这行，`8.00%` 与 `2.40%` 在书名号**外面**——公告原句只说了股数，比例是卡面自己拿股数除出来的。
`SP-GAP` 发「比例 8.00% 不在本行原句里（自算比例）」。

**为什么这条是本域的分水岭**：比例是**公告说的**，不是**卡面算的**。分母可能是持股数、可能是总股本、
可能是剔除回购专户后的股本；算错一个分母，余额读数和风险读数就全错。公告只写股数不写比例时，
正确写法是「未取到」+ 未取到清单点名缺什么、回哪份公告核对。

同一族的另一条：把「未取到」写成「无此项／不适用／无需披露」也是替公告下结论，
`SP-GAP` 一律发。公告没提不等于公告说没有。

## 五、未取到两向点名

头部只准出现一处申报：`- 共 N 笔质押变动·未取到 M 笔`。

- N **大于**变动明细段实际行数 ⇒ 虚报
- N **小于**变动明细段实际行数 ⇒ 漏报
- M 与段内写「未取到」的行数不等 ⇒ 两个方向都发
- 申报出现两处 ⇒ 发

未取到清单要**点名**：第几笔、缺哪一格、回哪份文件核对。只写「部分信息未取到」等于没点名。

## 六、书名号豁免的四个条件

`SP-LINE` 扫红线时，书名号内的原句默认不扫（那是公告说的话，不是卡面说的话），但**四个条件全满足**才豁免：

1. 该行有 `锚：`；
2. 书名号外只剩引注标签（原文/摘录/公告/第X条/页/行…）；
3. 书名号内若有 `短标签：`，该短标签本身也须是引注标签；
4. 书名号内不得有自指（本件/本卡/本速读/笔者）。

任一不满足 ⇒ 书名号内容留在判据域内照扫。这条防的是「把断言塞进书名号冒充原句」。
锚是**行尾标签**，不是判据域的终点——`锚：公告 三；该股质押比例偏高` 里的后半句照样发红。

## 七、红线三道（`SP-LINE`）

| 道 | 判什么 | 例 |
|---|---|---|
| ① 定式禁词 | 平仓风险判断 | 有平仓风险、面临平仓、爆仓风险、触及预警线、触及平仓线、风险可控、风险不大、质押安全 |
| | 比例高低评价 | 质押比例偏高／偏低／合理／过高／充分／不足 |
| | 股价预测 | 股价将、股价会、利空、利好、压制股价、提振股价、拖累股价 |
| | 评级目标价 | 目标价、评级、买入评级、增持评级、强烈推荐、建议买入/卖出/增持/减持/持有 |
| | 收益承诺 | 稳赚、零风险、保证收益、必涨、必跌 |
| | 代办 | 代拟、代算、代申报、代客 |
| ② 主题词×判断语气同段 | 主题词（质押·解押·出质·质权·平仓·预警线·平仓线·履约保障·累计质押·质押比例·占总股本·占所持）与判断语气（应当·应予·将·会·必·有望·可期·可能·足以·构成·属于·意味着·高于·低于·划算·合理·偏高·偏低·充分·不足·无疑·显然·肯定）同段 | 「累计质押比例将会升至…」 |
| ③ 自裁效力层 | 裁定前缀（结论·综上·因此·可见·本件认为·判定·认定·断言）与效力判断（有效·无效·成立·不成立·违法·违规·合规·属实）同现 | 「综上，该质押有效」 |

**豁免只豁免自己那一分句**：`[待人工]` 标记与免责句（不接/不出/不判/不代…）按分号·句号·逗号
切段后逐段判，同一行后半写的断言照发。

**机构名里的「会」不误红**：董事会、股东大会、监事会、审计委员会里的「会」先按形态从语气域洗掉。

## 八、日期写法

解押日期判的是**标签或日期在场**：「解除质押登记日／解押日／解除日／购回日」任一在场，
或行内出现 `2026 年 6 月 12 日`、`2026-06-12`、`2026/6/12`、`2026.6.12` 之一，即算该要素齐。

已知限度：这是**标签/日期在场**判定，不是日期有效性判定——「解除质押登记日待定」「解除日为下一交易日」
这类只有标签、没有具体日期的写法也能过闸（日期本身请人工复核）；反过来「至办理解除质押登记之日止」
这种把「日」换成「之日止」的写法匹配不上标签，会判缺要素，得按标签原样写。
公告用「T 日」「空白期首日」这类相对表述时需人工换算，本件不替你推日历。

## 九、与 `cn-shareholder-return` / `event-brief-cn` 的切割线

| | `cn-shareholder-return` | `event-brief-cn` | 本件 |
|---|---|---|---|
| 回答 | 分红回购减持**说了什么** | 单份公告**讲了什么** | 质押余额**怎么变** |
| 形制 | 八项逐字登记（含「质押与解押情况」一项） | 事件类型单选 + 要点摘录 | 五段跟踪卡 + 六要素/三要素 + 累计两处之差 |
| 数字判据 | 短语结构体归属（参照数更近即剔、比率不结算） | 事件类型单选唯一 | 比例必须在原句里（自算即发） |
| 时间维度 | 单份公告 | 单份公告 | 跨公告、跨期串成余额线 |

**写错件的信号**：卡面出现 `- 分红方案与每股派息：`、`- 回购方案与回购规模：` 这类股东回报速读的项行，
或出现 `事件类型：` 这类单份公告速读的单选行 ⇒ `SP-BOUND` 发，点名改走对应件。
