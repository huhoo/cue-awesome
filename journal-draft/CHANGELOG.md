# 更新日志

本技能遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。
`0.x` 阶段允许出现不兼容变更，但**每一条都会在下方单独标注**，并在条目里写明迁移动作。

版本号同时出现在两处，必须一致：

- `SKILL.md` frontmatter 的顶层 `version`（平台读取）
- `SKILL.md` frontmatter 的 `metadata.version`（技能内部与派生器读取）

> 说明：`0.4.0` 之前为早期迭代，未逐版留痕；下表自 `0.4.0` 起完整。

## [0.15.2] — 2026-09-18

补上「溯源」这一层：**CTA「阅读原文」此前只是一行字，没有去处。**

实测（某律所区域观察第 27 期）：全刊 46 条 CTA 写着「阅读原文」，`content.json` 里
**一个 URL 都没有**——HTML 渲染成 `<div>`、PDF 只是一行字，纸刊点不动、电子刊没去处、
编辑部复核时回溯不了，而四道门禁全绿。这是「看着正常、实则不可用」的又一类静默失败。

- `cta` 支持对象写法：`{"text","href","source","date"}`（字符串写法仍兼容，但会被点名）。
- `build_draft.py`：HTML 里落成 `<a href>`；`--stats` 报**溯源覆盖率**（CTA n 条 / 带链接 m 条）
  并把缺链接的条目逐条点名（页码 + 标题）。
- `export_pdf.py`：CTA 行加 PDF **URI 链接热区**（右半栏，避开左半留白）；
  新增 `--cta-domain`，把来源域名印在 CTA 行上（「阅读原文 · info.gov.hk」），纸刊也能溯源。
- 硬规则 32：URL 只取官方原文（监管机构 / 政府官网 > 官方媒体 > 二手不取），
  拿到要打开核对标题与日期；检索不到就留空进待补清单，**不许编造 URL**。

本期实测：48 条动态回填 45 条官方原文链接（98%），3 条检索不到已进待补清单
（金管局稳定币传闻仅书面回复媒体、2 条律所自有新闻稿）。

## [0.15.1] — 2026-09-18

修掉一类**静默丢图**：`content.json` 里的图是相对路径（`art/diagrams/fig_0.png`），
而 `export_pdf.py` / `build_draft.py` 都只按**当前工作目录**去解析。只要不在期刊根目录跑
脚本（例如从别的目录用绝对路径调脚本），六张图会全部降级成灰色占位块——
**图注文字照常印出来、脚本不报错、退出码为 0**，肉眼只看得出「图没了」，
是最难发现的一类失败（第 27 期实测：80 页带 6 图 → 85 页 0 图）。

- `build_draft.py`：新增模块级 `CONTENT_ROOT` 与 `_img_abs()`；
  分页估算（`fig_height_mm`）与 HTML 图源（`img_src`）都按 **content.json 所在目录**兜底解析。
- `export_pdf.py`：新增 `_resolve_img()` 走同一套兜底（顺带剥掉 `file://` 前缀）；
  空图位告警改为**带上图源路径**，不再只报图注。
- 顺带统一分页口径：此前换目录跑会出现「分页器按 62mm 占位算、渲染器按真实图高画」，
  两者打架 → 多页内容溢出告警。现在跨目录跑与在期刊根目录跑结果一致
  （实测同一份 `content.json`：均出 86 页 / 6 图 / 无告警）。

迁移：无需改任何配置。旧稿若是在错误 cwd 下生成的，按原命令重跑一次 `export_pdf.py` 即可恢复配图。

## [0.15.0] — 2026-09-18

补齐「定位」这一层：**此前 `journal-types.md` 只覆盖「读者 → 合规底线」**（谁能看、
谁会签、哪些话不能说），而**发刊目的、读者价值期待、内容调性没有任何机器可读载体**——
只在 `issue-brief.md` 里以散文提一句，每期重新问、无法继承、无法校验、无法派生。
版式有 `stylespec.json`，定位却没有对等产物，这是结构上的不对称。

实测证据（某律所区域观察第 27 期，全刊 46676 字，四道门禁全绿）：
48 个内容单元**全部同一形态**、均 409 字，而 `unit-patterns.md` 声明 180–320（**超上限 28%**）；
全刊读者称谓仅 **4 次**（0.09‰）；含行动建议 **10/48（21%）**；句长中位 46 字、31% 超 60 字。
**四条全都不报错**——不是写错了，是没有这一层（没有定位卡时，模型默认往长写、默认第三人称）。

### 新增

- **`positioning.json` 刊物定位卡**：与 `stylespec.json` 平级的第二份机器可读产物。
  五段：`purpose`（六选一主目的，只能一个）/ `audience`（岗位＋处境＋专业水平＋**时间预算**）/
  `value_promise`（一句话＋`reader_action` 动词短语）/ `tone`（权威・密度・立场 三刻度 1–5，
  **直接换算单条字数带与句长上限**）/ `industry_rules`（术语密度上限、忌讳词、必标出处）。
  模板 `assets/templates/positioning.template.json`；填好的样例
  `assets/examples/qiming-regional-sample/positioning.json`。
- **`scripts/audit_editorial.py` 编辑定位门禁**（硬规则 31）：读 positioning + content，
  判定位卡完整度 / 单条字数是否落在调性派生的字带 / 兑现 `reader_action` 的条目覆盖率
  （<50% FAIL）/ 纯 L0 占比（>50% FAIL）/ 句长中位 / 术语密度与行业忌讳词（命中即 FAIL）。
  缺定位卡明确 FAIL 并 exit 1，不假装检查过；`--no-positioning-gate` 才能跳过。
  在同一份真实稿上试跑：**FAIL 3 / WARN 3**，把上面的实测缺陷逐条抓了出来。
- **`references/audience-value.md` 读者价值与调性手册**：发刊目的六选一与各自的「成功长什么样」、
  行业 × 岗位价值期待矩阵、**同一事件写给四种读者的四种写法对照**（含各自的字数带，
  客户版 300–500 / 员工版 120–200 / 投资者版 150–300 / 公众版 100–180）、
  调性三刻度 → 字数带/句长/人称/标题句式换算表、术语门槛与忌讳词、五条常见错配。
- `derive_skill.py` 生成的子技能自带「定位」一节；`assets/templates/` 与 `scripts/` 是整目录
  打包，定位卡模板与 `audit_editorial.py` 自动随子技能分发，无需改拷贝清单。

### 变更

- `+brief` 的编辑方针四问，答案**必须落成 `positioning.json`**，不能只写进 `issue-brief.md`。
- 门禁由四道增至五道（新增编辑定位门禁）。

### 兼容性

- 既有项目**没有 `positioning.json` 会在 `audit_editorial.py` 上 FAIL**。
  这是有意为之（定位缺失正是要暴露的问题）；一次性补一份即可，
  或先用 `--no-positioning-gate` 让既有流程照旧跑。
- `references/` 仍不拷进派生子技能（会演进的方法论，拷一份立刻过期），
  定位口径的最小集已写进派生出的 `SKILL.md` 正文。

## [0.14.0] — 2026-09-18

一次「效果质量」审计的产物：**之前所有门禁都不管成品好不好看、好不好读，也不管内容有没有洞察。**
实测一本三道门禁全绿的 80 页交付稿，仍然字小一档、字号碎成 41 档、行距 2.16 倍、
页脚 73 处中文空格、品牌字体被静默换掉——**五条都不报错**。

### 新增

- **`scripts/audit_layout.py` 版面质量门禁**（硬规则 29，交付前必跑）。
  量成品 PDF 的七项：正文字号 vs 样刊实测、字号碎裂度、行距倍数、每行字数、
  字体是否兜底、中文空格残留、页面密度。FAIL 判 exit 1，`--strict` 让 WARN 也失败。
  实测对照（同一份 80 页稿 / 样刊 10.4pt）：修复前 body 9.0pt(87%)、41 档碎裂、
  行距 2.16、54 字/行、空格 73；修复后 10.4pt(100%)、主峰 76%、行距 1.87、47 字/行、空格 0。
- **`references/editorial-quality.md` 编辑质量手册**（硬规则 30）。
  本期编辑方针四问、内容价值四级阶梯 L0–L3、反「信息堆叠」五条红线、深度文章骨架、
  交付前十条自检。框架层原本对「工作目的 / 读者价值 / 洞察深度」是**零指引**
  （SKILL.md 里这些词全部 0 次命中），好稿子靠的是当次 agent 自觉，不可复现。
- `+brief` / `issue-brief.md` 顶部新增「本期编辑方针」四问；
  `outline.md` 每篇卡片新增「读者价值」与「洞察层级」两列。
- `derive_skill.py` 生成的子技能自带「编辑质量」与「版面门禁」两节最小口径
  （`references/` 仍不拷，按既有设计留在父技能）。

### 修复

- **`insert_htmlbox` 静默缩字**（根因级）。PyMuPDF 在内容装不下时会**自动缩小字号塞进框里**，
  且返回值变成 ≥0，连溢出都不报：实测请求 20pt / 框高 60pt 只渲染出 14.28pt，
  框高 20pt 出 7.69pt，框高 8pt 出 3.08pt。一本真实稿子因此把正文 10.4pt 印成
  8.4–9.9pt 的 41 个不同字号（每个框内容量不同 → 缩放比例不同）。
  现在框高留 `FIT_SLACK=1.25` 余量并夹到页底。
- **行距倍数 2.16（样刊 1.85）**。MuPDF 的 CSS `line-height` 乘的是**字体自然行盒**
  （实测约 1.22em）不是字号，写 1.75 出来是 2.15 倍。新增 `LINE_ADJ` / `LINEBOX`
  两个换算常量，成品实测 1.87 倍。
- **分页高度估算与 PDF 实际占高不同尺**（`build_draft.LINE_H_FACTOR`）。
  两边不一致会同时导致「分页器以为装得下、渲染时溢出」和「框给矮了触发缩字」。
  HTML 侧保持 1.0（浏览器语义不同），export_pdf 导入后改写为 `LINE_ADJ*LINEBOX`。
- **页脚固定件 73 处中文空格**（硬规则 13）。`lbl()` 为保住「2026.04.10 香港金融管理局」
  这类结构空格而完全不收紧，结果「2026 年第 8 期」被原样印进每一页。
  现在只收紧「数字＋年月日期号卷册章」与「第＋数字」两类，结构空格仍保留。

### 变更（不兼容）

- **成品 PDF 的页数与密度会变**：正文字号从被缩小的 8.4–9.9pt 回到 spec 的 10.4pt，
  同一份内容页数由 78 增至 85、密度由 602 字/页降到 571 字/页（样刊 615）。
  这是**对齐样刊**的结果，不是回退；若你的刊此前一直按缩小后的字号排版交付，
  升级后请重新过一遍 `audit_layout.py` 与分页。
- 新增硬规则 29 / 30：交付前必跑 `audit_layout.py`；内容不得停在 L0。
  既有流程多一步门禁，`--strict` 会让它变成强制。

### 已知缺口（本次未修）

- **品牌字体在 PDF 里不复现**：PyMuPDF 的 `insert_htmlbox` 只认内置字体与显式注册的字体文件，
  spec 量到的字族（如 PingFangSC）会静默换成兜底字体（Droid Sans Fallback 等）。
  已写进 §1「能力边界」表，`audit_layout.py` 会报 WARN。本稿定位为版式骨架，
  字体由设计师在 InDesign 套。
- **单栏全宽时每行 47 字**，超出中文舒适区（20–45）。渲染器不分栏是既有缺口，
  补偿办法是收窄版心到 100–115mm，不是把字调小；`audit_layout.py` 会报。

## [0.13.2] — 2026-09-18

修掉「派生出来的子技能发不出去」——这是「父包是框架、用户参照样例造自己的子包」这条主路径上的堵点。

### 修复

- **派生出的子技能缺 `slug` / `version` / `displayName`，无法独立发布。**
  这三个是技能市场（skillhub.cn）**唯一硬校验**的字段，而 `derive_skill.py` 生成的
  SKILL.md 只有 `name` 和 `metadata.version`。用户按文档派生完，想把自己的刊发出去，
  必须先手改 frontmatter，漏一个就被平台拒。
  现在 `--name` / `--publisher` / `--title` 会被自动写成
  `slug` + `displayName` + 顶层 `version`（`0.1.0`）+ `summary` + `tags`，
  派生完即可直接发布。
  *影响范围*：仅新派生的子技能；已存在的子技能不受影响（`examples/` 下两个样例此前已手工补齐）。
- **`--title` 带书名号会渲染成 `《《刊名》》`。** 传入的 `《…》` / `【…】` 现在会自动剥掉。
  同时修掉由它派生的 `displayName` 与 `summary`。

### 新增

- `derive_skill.py` 新增 `--slug`（可选，默认取 `--name`）。非 kebab-case 会被规范化
  （小写、非字母数字折成 `-`）并打印 `[NOTE]`；平台报 `409 slug 被占用` 时在此加 handle 前后缀重跑。
- `metadata.version` 由 `"0.2.0"` 改为与顶层 `version` 一致的 `"0.1.0"`，避免两个版本号不一致。

### 文档

- `SKILL.md` 的派生命令补 `--slug`，并说明子技能自带发布字段。
- `references/instantiation.md` 新增「派生出的 SKILL.md 自带发布字段」一节：
  三个硬校验字段、`409` 的处理方式、`--title` 不带书名号、以及子技能自包含的是
  `scripts/`（11 个，排除 `derive_skill.py` 自身）与两个 `assets/` 模板目录，
  `references/` 有意留在父技能。

### 验证

派生了 `journal-demo-instance` 实测：`slug=journal-demo-instance` / `displayName=某专业服务机构《体验观察》期刊底稿技能` /
`version=0.1.0` 全部就位；发布打包脚本判定通过；子技能独立渲染 `OK pages=8 … unknown=0`；
正文无 `《《` 残留；`scripts/` 12 个脚本三份副本 MD5 全同、`--help` 12/12。

## [0.13.1] — 2026-09-18

面向公开发布（SkillHub）的适配与门禁加固。

### 新增

- 新增本文件 `CHANGELOG.md`。
- `SKILL.md` frontmatter 补齐平台发布所需字段：`slug` / `displayName` / 顶层 `version` / `summary` / `tags`（三份 SKILL.md 均已补齐；原有 `name` / `metadata` 保持不动，本地加载不受影响）。
- 新增 `assets/demo/` —— **可直接用浏览器打开的成品版面稿**（13 页 / 22.5 KB），附内容源 `content.demo.json`、两张由 `gen_diagram.py` 绘制的语义图，以及说明文件。覆盖八种页面模板。
- `build_draft.py` 新增 `--no-baseline-gate`：`--stats` 时显式跳过量级门禁。

### 变更（含不兼容变更）

- **⚠️ 不兼容：量级门禁不再静默通过。**
  此前若 spec 里没有 `scale_baseline`，脚本只打一行 `[WARN]`，随后照常打印 `OK ...` 并以 `exit 0` 退出 ——
  看起来通过，实际根本没算达成率。现在改为打印 `[FAIL]` 并 **`exit 1`**。
  *迁移*：① 正解是传带 `scale_baseline` 的 `--spec`（`extract_style.py` 抽取时一定会写入它）；
  ② 若确实只要计数、不做达成率对照，显式加 `--no-baseline-gate`。
- **⚠️ 不兼容：`--spec` 路径错误不再降级。**
  此前 `--spec nope.json` 只警告「spec 不存在，使用内置默认网格」后继续跑；现在直接 `[ERR]` 并以 `exit 1` 退出。
  *迁移*：检查路径；确实想用内置默认网格就整个省掉 `--spec`。
- 达成率 `<60%` 的 `[FAIL]` 现在同样以 **`exit 1`** 退出，便于接进 CI。
  提示语补上「这是门禁判定结果，不是脚本崩溃」，避免与真实崩溃混淆。
  *注意*：README 的冒烟命令按设计就会触发这个 FAIL（8 页样例对 91 页基线），因此**它的 exit code 是 1，属预期**。
- `build_draft.py` 模块头部的用法示例去掉 `--pdf` 示例行，并把 `--pdf` 明确标注为遗留路径（需 playwright + chromium，海外下载）。

### 修复

- **补完 0.13.0 脱敏的遗漏**：示例引语页原署名某商业评级机构（英文名已移除）
  并逐字引用其评语 —— 属对第三方的实际引用与署名，与「样例已脱敏」的声明相矛盾。
  已换为标注「示例文本，非真实评价」的合成引语（3 份副本）；`unit-patterns` 中对第三方榜单
  产品名的列举也改为中性表述。
- **`assets/diagram-templates/fig_0.json`（3 份）**承载的源刊首条选题的实质内容
  （机构名、法规名、栏目分工）已重写为中性的角色化示例，只保留布局结构。
- **`assets/templates/issue-brief.template.md`** 在父技能已演进、两个样例仍是旧版
  （5080 → 6541 字节），已同步为三份一致。
- **随包 `assets/demo/demo.html` 的绝对路径**：`img_src()` 在图片存在时会输出 `file:///` + 绝对路径，
  已改为相对路径；这一项也加进了 `NOTICE.md` 的发布自检表（**重新渲染后须重做**）。

## [0.4.0]

### 新增

- 渲染器确立三个关键行为：
  1. **无底图降级** —— 样刊压在深色满版图上的页码 / 目录页码 / 编委会 / 分隔页标题，抽出来的色值常是 `#FFFFFF`；新刊没有底图时这些字会全部隐形。现按「本页有没有底图」切换两套前景色，无封面图 / 分隔页图时改画纯 CSS 色块版式。
  2. **自动分页（`--autoflow`，默认开）** —— 按估算高度装页，装不下自动续页并标「（续）」。
  3. **量级门禁（`--stats`）** —— 拿 `spec.scale_baseline` 对照页数 / 条数 / 字数，避免「25 页对 91 页还自我感觉良好」。
