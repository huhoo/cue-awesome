- **`insert_htmlbox` 静默缩字**（根因级）。PyMuPDF 在内容装不下时会**自动缩小字号塞进框里**，

## [0.4.0]

### 新增

- 渲染器确立三个关键行为：
  1. **无底图降级** —— 样刊压在深色满版图上的页码 / 目录页码 / 编委会 / 分隔页标题，抽出来的色值常是 `#FFFFFF`；新刊没有底图时这些字会全部隐形。现按「本页有没有底图」切换两套前景色，无封面图 / 分隔页图时改画纯 CSS 色块版式。
  2. **自动分页（`--autoflow`，默认开）** —— 按估算高度装页，装不下自动续页并标「（续）」。
  3. **量级门禁（`--stats`）** —— 拿 `spec.scale_baseline` 对照页数 / 条数 / 字数，避免「25 页对 91 页还自我感觉良好」。
