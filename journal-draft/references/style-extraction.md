# style-extraction — 从样例提炼 StyleSpec 的方法

## 〇、先跑几何层，再跑语义层（两条通道都要跑）

样例学习跑两条独立通道，谁也替不了谁：

| 通道 | 怎么跑 | 得到 |
|---|---|---|
| 几何层 | `scripts/extract_style.py`（本地 PyMuPDF，零成本） | 页 / 网格 / 字族字号 / 色板 / 图片槽位 / 跨页重复文本 |
| 语义层 | `omni-reader` MCP → `scripts/enrich_from_omni.py` | 目录与栏目树 / 单元边界 / 字数分布 / 题头日期+作者 / 段落型重复条目 / 页眉与 CTA 频次 / 术语种子 |

合并：`enrich_from_omni.py` 给了 `--geo <stylespec.json>` 会直接产出 `stylespec.merged.json`（几何层原有字段不动，只挂 `semantic` 段）。
图片一律以几何层 `image_slots` 为准 —— 富文本层不保留图。

完整调用顺序、能力档位、费用与坑见 [`omni-channel.md`](omni-channel.md)。

## 一、先看样例是什么形态

| 形态 | 识别方法 | 取路 |
|---|---|---|
| 有文字层 PDF | `extract_style.py` 能正常产出抽取结果 | 几何层直接跑；语义层走 Omni `parse` |
| 扫描件 PDF | 脚本报 `[WARN] 文字层极薄` | 走 Omni `parse` 拿正文（它在扫描件上通常比本地 OCR 稳），几何层则退化为只能量图片与色块，须标注低置信 |
| 图片一堆 | 无 PDF | 用视觉能力逐页判读网格/色/字号，标记**低置信** |
| 网页版 / H5 | 无 PDF | 抓正文另存；版面按 CSS 推断，**同样标记低置信** |
| InDesign / IDML /  sketches | 源文件 | 优先！ 可直接读段落样式与色板，比逆向 PDF 准得多 |

**源文件 > PDF > 图片 > 网页**。能拿到源文件就去要，别硬逆向。

## 二、脚本提什么、提不准什么

### 脚本提得准（可直接采信）

- 开本尺寸、页数
- 色板与占比（`#RRGGBB` + 出现行数）
- 字族清单、字号清单
- 跨页重复文本 → 页眉 / 页脚 / CTA / 刊头
- 页码位置（y 坐标、左中右、字号、颜色）
- 每页图片槽位的绝对坐标（mm）+ 宽高比 + 出现频次

### 脚本提不准（必须人工补）

| 项 | 为什么 | 怎么补 |
|---|---|---|
| **版心网格只有两套** | 脚本会按「左边界 + 图片数」聚成十几个模板，把同一套版心因末行长短拆开 | 人工看「哪几个模板的 left/right 其实一样」，合并成 A / B 两套并命名用途 |
| 单位换算 | PDF 单位是 pt，务必 ×0.3528 转 mm | 脚本已处理；若手写注意别二次换算 |
| 行距倍数 | 只能测出相邻基线间距（如 22pt），不等于 CSS line-height | 用基线间距 ÷ 字号反推，并在 PDF 上目测核一遍 |
| 段间距 | 无段落标记 | 直接量相邻段落基线的额外间隙 |
| logo / 装饰件 vs 插图 | 脚本只按位置和尺寸猜 | 人工把「每页都在左上角、尺寸恒定」的标为 logo；「细长条、紧贴标题」的标为 decoration |
| 图片内容语义 | 提取不到语义 | 把样刊关键页渲染成图，肉眼记：摄影？插画？实景？抽象纹理？有无人像？ |

## 三、跑之前的两条建议

1. **先看置信度别急着用**：脚本输出的组件名（cover / toc / unit_list …）是猜的。真实答案通常很朴素——**一套窄版心给栏目页，一套宽版心给文章页**，再加几张整版图做封面和分隔页。
2. **把页码和印刷页码对齐**：PDF 物理页码 ≠ 印刷页码（样刊往往差 5–6 页，因为前面有封面/题词/目录）。务必确定偏移量，否则目录页码全错。做法：取目录里第一条的页码 a 与它在正文中出现的物理页 b，offset = b − a。

## 四、必须回答的七个问题

跑完脚本后，你至少要能回答这七个，StyleSpec 才算定稿：

1. 开本、出血、装订方式（骑马钉 / 胶装）？→ 决定页边距与安全边
2. 主色 + 辅色各是什么？有没有 CMYK / Pantone？
3. 正文 / 各级标题的字号与行距？
4. 有几套版心？各自用在哪些页面？
5. 每页必有的固定件是什么（页眉、页码、博览会刊名、logo）？
6. 重复出现的内容原子（UnitPattern）有哪几种？各自的字数区间与固定收尾是什么？
7. 图片扮演什么角色？必须有图的位置有哪些？图文比大概多少？

答不上来的，写进 `stylespec.md` 的「待人工补全」，并在 +brief 阶段一次性问用户。

## 五、常见坑

- **把带子集前缀的字族名当成新字体**：`ABCDEE+PingFangSC-Semibold` 这种前缀是子集嵌入标记，去重时要剥掉 `ABCDEF+`。
- **把别名 Quaternion 当两色**：同一品牌色在OCR 后 常裂成 ``#A10F34`、`#A10F3E`、`#A21036` 三四个近似值，合并成一个主色再记 tolerance。
- **忘了 ISBN 页、广告页、插页**：它们不属于任何栏目，聚类出来就该是孤立页，别强行塞进业务模板。
- **双栏刊物被当成单栏**：如果 left 出现两个明显不同的众数（如 20mm 与 110mm），说明是双栏，网格要记两列而不是一个宽版心。
