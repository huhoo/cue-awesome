# 编辑质量 — 别把底稿做成「信息堆叠」

> 这一份管的是**内容好不好**，与 `qa-checklist.md`（管**有没有错**）分工不同。
> 一本刊可以「事实全对、零阻塞项」，却仍然是一堆读过就忘的资料汇编。
> 用户拿到手的感受是「能用」还是「这也要我重写一遍」，差别全在这里。

**为什么必须写成文档**：框架层原本对「目的 / 洞察 / 读者价值」是零指引的
（实测：SKILL.md 里「工作目的」「办刊目的」「编辑方针」「读者价值」「立场」「观点」
「主线」「叙事」「行动建议」全部 0 次命中）。第 22 期那批稿子写得有洞察，
靠的是当次 agent 的自觉，**不是技能要求的**——换个模型、换个执行者就会退化成堆料。
质量不可复现，等于没有质量。

---

## 一、开工先问「这本刊是来干什么的」——四问

`+brief` 的 B1 里，这四个问题排在篇幅与 deadline **之前**。答不上来，
后面所有「篇幅配平」「栏目沿用」都是在给一堆没有重心的文字配版。

| # | 问 | 用户可能的说法 | 你要追到的粒度 |
|---|---|---|---|
| 1 | **谁看** | 「客户」「员工」 | 具体到**岗位与处境**：外资制造业的区域法务总监 / 刚入职三个月的分析师。**抽象的读者造不出具体的内容** |
| 2 | **看完做什么** | 「了解动态」 | 具体到**动作**：去核对自家基金的附带权益条款 / 决定要不要在海南设主体 / 在周会上能讲三分钟。「了解」不是动作 |
| 3 | **记住什么** | 「知道我们在关注」 | 具体到**一句话**：本期如果只留一句，是哪句。写不出这句，说明这一期没有主张 |
| 4 | **为什么是我们说** | 「我们有专业团队」 | **不可替代性**：别人转述得了的不必写；只有站在业务现场才知道的才写 |

四个答案写进 `issue-brief.md` 顶部，作为**本期编辑方针**。之后每一次取舍
（这篇要不要、这条写多长、这个数据要不要放）都回到这四句来判。

> 用户答不上来时**不要替他编**，给一个基于上期的默认建议让他确认：
> 「按上期看，这批稿子是给区域法务做合规预判用的，本期沿用？」——
> 确认过的方针才是方针，你猜的不是。

## 二、内容价值的四级阶梯

每一条内容、每一篇稿子都要标明它落在哪一级。**一期刊物里 L0 占满，就是信息堆叠。**

| 级 | 是什么 | 判据 | 反例（常见冒充） |
|---|---|---|---|
| **L0 事实** | 发生了什么：时间、主体、文件名、金额、生效日 | 可核查、有出处 | —（必要，但只是起点） |
| **L1 影响** | 「这对谁、在哪件事上、改变了什么」 | 能指出**受影响的主体**与**具体环节** | 「具有重要意义」「将进一步促进」——**零信息** |
| **L2 判断** | 作者的专业判断：为什么这样定、边界在哪、市场容易踩哪条线 | 换成另一个人写会写得不一样 | 把官方答问复述一遍当作分析 |
| **L3 行动** | 读者接下来该做什么、在什么时点之前、不做的代价 | 能落成**动作 + 时点 + 责任人** | 「建议持续关注」——不是行动 |

**配比要求**（按正文篇幅算，不是按条数）：

- 快讯 / 动态类栏目：**L0 + L1**，每条至少一句 L1，且 L1 必须点名受影响主体；
- 深度文章：**L0 打底 + 全文至少 3 处 L2 + 结尾一段 L3**；
- 整期：**纯 L0 的条目不超过一半**。

**同一条内容跨级时的写法**（第 27 期实例，可直接当 few-shot）：

> **L0** 2026年7月8日，立法会通过《2026年印花税（修订）（第2号）条例草案》，
> 订明双柜台证券人民币柜台交易的印花税以人民币计算和缴付，修订条例于7月17日刊宪。
>
> **L1** 该修订对市场参与者的直接影响在于币种口径：券商与托管机构的交易系统、
> 结算流程及内部会计科目需同步支持以人民币计缴印花税。
>
> **L3** 建议在市场参与者完成系统调整前，以港交所与税务局后续公告为准安排过渡期操作。

反例（同一条写成堆叠的样子）：
> 该条例的通过将进一步提升香港金融市场的竞争力，为人民币国际化注入新动能。

## 三、反「信息堆叠」五条红线

1. **不许把官网通稿改写成期刊语体就算完。** 内容来源表里 `B 官方改写` 是**省成本的通道，
   不是终点**——改写完必须补上 L1/L2/L3，否则这一条就是企业自述的搬运。
   判据很简单：把企业名遮掉，还看得出是谁写的吗？看不出就是搬运。
2. **不许用「意义/赋能/助力/进一步」这类词收尾。** 它们是「我没有判断」的遮羞布。
   每条都要落到**主体 + 环节**。
3. **不许只列事实不标边界。** 新规写了适用什么，就要写不适用什么；
   写了扩容，就要写排除。边界才是专业读者真要看的
   （第 27 期那篇税制修订，价值最高的正是「两条明确排除的边界」一节）。
4. **不许一期里全是并列条目。** 至少要有**一条主线**把它们串起来——
   在 `+plan` 阶段就要定：本期的主线是什么，哪篇是主稿，其余怎么呼应它。
   没有主线的刊，读者翻完记不住任何东西。
5. **不许把「篇幅不够」用灌水补。** 差页数就去补**素材与证据**（硬规则 17：素材量 ≥ 正式稿 2–3 倍），
   不是把每条从 180 字写成 400 字。灌水出来的条目，L1 密度反而更低。

## 四、深度文章的骨架（不是堆料的顺序）

```
① 为什么现在要谈这件事       —— 时点 + 变化 + 对读者的切身处境
② 事实骨架（L0）            —— 出处、文号、时间线，逐条可核查
③ 变化点逐条展开（L2 主战场）—— 每一处变化单独成节：改了什么 / 为什么改 / 边界在哪
④ 反直觉或被忽略的一处        —— 至少写一处「大多数人会想错」的地方，这是文章的价值锚
⑤ 读者的动作清单（L3）       —— 动作 + 时点 + 不做的代价
⑥ 效力声明                  —— 草案未通过、以正式文本为准这类必须写明
```

**第 ④ 条最容易被跳过，也最决定文章成色。** 判断标准：这一节能不能让一个
熟手读者说「这条我没想到」。写不出就不算深度文章，退回动态条目。

## 五、标题与导语

- **标题给结论，不给话题。**「香港基金与家族办公室优惠税制修订：附带权益扩容的实务影响」
  优于「香港税制修订动态」。话题式标题等于告诉读者「里面可能有什么」。
- **导语回答「为什么现在」。** 第一句就要给时点压力（"追溯至 2025/26 课税年度"、
  "8 月 12 日官方定调"），不要从背景铺垫起。
- **小标题要能连读成目录。** 把全文小标题单独抽出来读一遍，
  应当看得出论证走向（`一、修法进程 → 二、三处扩容 → 三、两条排除 → 四、动作清单`）。
  连读不成话，说明结构没想清楚。

## 六、交付前逐篇自检（`+check` 里过一遍）

| # | 检查 | 不通过怎么办 |
|---|---|---|
| 1 | 每篇能说出**读者读完要做的动作**吗 | 补 L3，或砍掉这篇 |
| 2 | 有没有一句**只可能是我们说的话**（L2） | 补判断，不是补事实 |
| 3 | 有没有写**边界 / 排除 / 例外** | 至少补一条 |
| 4 | 有没有一处**反直觉**的提醒 | 深度文章缺这条，降级为动态 |
| 5 | 把所有「意义 / 助力 / 赋能」划掉，还剩多少实质 | 剩太少就重写 |
| 6 | 遮掉机构名，还看得出是谁写的吗 | 看不出 = 搬运，补 L2 |
| 7 | 小标题连读能不能成话 | 重排结构 |
| 8 | 本篇与上期有没有**延续性**（这个话题上期讲到哪） | 补一句衔接，别让读者自己接 |
| 9 | 数字有没有**口径与时点**（谁的统计、哪一天） | 补；补不上就删掉这个数字 |
| 10 | 有没有把**未生效 / 待通过**的效力状态写清楚 | 必须写，这是执业风险 |

## 七、目的要落到产物里，不能只在对话里

| 产物 | 落什么 |
|---|---|
| `issue-brief.md` | 顶部「本期编辑方针」四问的答案（§一） |
| `outline.md` | 每篇卡片加两列：**读者价值**（一句话）、**洞察层级**（L0–L3 配比） |
| `copy/*.md` | 每篇开头一行「本文要读者做的事：…」 |
| `review.md` | 编辑质量自检结果（§六 十条），与事实阻塞项**分开列** |

> 分开列很重要：事实错是**阻塞项**，洞察不足是**建议项**，
> 但建议在 `review.md` 里要说清「哪些条目是纯 L0」——
> 让用户知道他手里哪一截需要自己补判断，不要等他翻完才发现。
