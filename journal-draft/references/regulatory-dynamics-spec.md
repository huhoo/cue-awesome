# 法规动态章节规范（regulatory-dynamics）

适用于期刊里的「法规动态 / 政策快讯 / 区域新规」类栏目：每条是一条独立政策快讯，多条并列成栏。
本规范来自《大湾区与海南自贸港》第 27 期实测沉淀，**默认套用**——新一期做这类栏目时不必每次重新定义。

## 一、标题格式

```
地区（到市级）：动作 + 法规 / 文件名称
```

- **地区**：发文管辖区，写到市级。
  `香港` / `澳门` / `横琴` / `海南` / `广东` / `深圳` / `珠海` / `汕头` / `肇庆` / `前海` / `南沙` / `国家`（中央机关，如国家网信办）。
  按**实际发文机关**定，不要沿用样例里的省名（深圳发的就写「深圳」、中央发的就写「国家」）。
- **动作**：从 `印发` / `出台` / `获批` / `建立` 中选最贴切的一个。
  - 印发 = 正式发布文件；
  - 出台 = 推出政策 / 举措（含条例、办法、工作方案、措施）；
  - 获批 = 获批（如牌照、试点）；
  - 建立 = 设立机制 / 平台 / 公司。
  本身是「动态 / 新闻」而非正式发文的（机构表态、名录更新、统计公布），用四词中最贴近者配简短语，保持标题简短。
- **法规 / 文件名称**：正式名称放《》里。无正式文件名的事件用简短语（可不加《》）。
- 标题要短，像示例那样，**不要写成一句话长标题**。

正例：
```
香港：通过《2026年印花税（修订）（第2号）条例草案》
海南：印发《海南自由贸易港“零关税”生产设备及维修用货物管理暂行办法》
广东：出台《广东省促进粤港澳大湾区海上搜寻救助合作条例》
深圳：印发《深圳市支持海港口岸高质量发展工作措施（2026—2028年）》
前海：印发《金融赋能低空经济产业高质量发展的十二条措施》
肇庆：出台《肇庆市燃气管理条例》
```

## 二、摘要格式

**单一段落，250–350 个汉字，不得分段**（无 `\n\n`、无项目符号）。结构：

```
【时间】，【主体】发布/通过【文件名称】（简称【简称】），【主要内容概述】。
该【文件/政策】【核心变化或创新点】，【预期影响】。
【文件/政策】自【生效时间】起施行，有效期至【截止时间】。
```

槽位规则：

| 槽位 | 取值 | 缺省处理 |
|---|---|---|
| 时间 | 发布 / 通过日期（取 meta 或正文） | — |
| 主体 | 发文机关 | — |
| 文件名称 | 带《》的正式名称 | — |
| 简称 | 有通行简称 / 缩写才写（简称…） | 无则**整句省略**该分句 |
| 主要内容概述 | 一两句说明文件管什么 | — |
| 核心变化或创新点 | 新在哪、有何突破 | — |
| 预期影响 | 对行业 / 客户的预期效果 | — |
| 生效时间 | 施行日期 | 未明文用「自公布 / 发布之日起施行」或正文提到的施行日 |
| 截止时间 | 有效期届满日 | 长期有效 →「长期有效」；固定期限写具体日；不明 →「（有效期按文件规定执行）」 |

硬约束：
- body 必须是单一段落，**无换行**。
- 目标 250–350 字（用 `len()` 对中文串核验，取 ~300 字）。
- body 里**不得出现**「阅读原文」或任何 URL——超链接由 CTA 字段处理（见下）。渲染脚本会对 body 做 `.replace("阅读原文","")` 防御，但稿源侧就不应写。

正例（约 300 字，单段）：
```
2026年7月8日，立法会三读通过《2026年印花税（修订）（第2号）条例草案》。该草案核心在于：
自双柜台机制下，以人民币计价交易的股票，其印花税改以人民币计缴，不再先折算港币再计税。
此前人民币柜台成交须按港元等值缴税，存在汇兑损耗与对账摩擦；修订后可直接以人民币交税，
降低跨境结算成本，与「港币—人民币双柜台」及人民币国际化方向一致。草案于刊宪后即生效，
长期有效，是香港资本市场配套人民币柜台、便利离岸人民币回流的重要一步。
```

## 三、「阅读原文」= 隐式超链接

- 每条法规动态的原文出处落成 **CTA 字段**，链接指向**官方原文**（监管机构 / 政府官网 > 官方媒体 > 二手，二手一律不取）。
- URL **不显示**：纸面只印「阅读原文」四字，电子刊里该四字是热区、可点；域名标注版（`--cta-domain`）才额外印出处域名。
- 取链后必须打开核对标题与日期对得上；打不开就当没找到。
- 检索不到（企业自有内容、只有媒体转载）就**如实留空、进待补清单交业务方回填**，
  **绝不许编造看起来像真的 URL**——假链接比缺链接更糟。
- `build_draft.py --stats` 会输出溯源覆盖率（「CTA n 条，带原文链接 m 条」）并逐条点名缺链项。

```json
{"cta": {"text": "阅读原文",
         "href": "https://www.info.gov.hk/gia/general/202607/08/P2026070800288.htm",
         "source": "香港特别行政区政府资讯中心", "date": "2026-07-08"}}
```

## 四、校验口径（给审计 / 自检用）

- 标题前缀匹配 `^(香港|澳门|横琴|海南|广东|深圳|珠海|汕头|前海|南沙|国家|肇庆)：`。
- 摘要 250 ≤ len(body) ≤ 350，且 `\n` 计数 = 0。
- body 不含「【】」字面占位符、不含「阅读原文」、不含 `http`。
- CTA 为对象且 `href` 非空即计为「已溯源」。
