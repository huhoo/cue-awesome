# pitfalls — 实测踩过的坑（全部来自真实交付，不是推演）

> README 只留最容易踩的 6 条；完整 11 条在这里。
> 每一条都注明**版本**，便于追溯修没修。

## 1. 不要指望浏览器打印出 PDF

HTML 版面稿在部分预览器 / 企业策略下整本看不见。PDF 一律用
`scripts/export_pdf.py` 自绘生成，这是硬规则。

## 2. 分页溢出是静默的

`.page{overflow:hidden}` —— 页数比预期少就是内容被裁了，只有 `--stats` 的
`overflow` 告警会告诉你。

## 3. 中文不要在数字与汉字之间加空格，也不要两端对齐

「2026 年 4 月 10 日」在两端对齐时会被拉散成碎块。渲染器已自动收紧，
但手写素材时要留意。

## 4. 「跑通了」不等于「版式对了」

第二开本实测：脚本零报错、`unknown=0`、三件套齐全，但法规动态整栏被排进右半页
94mm（左半页全空）、文章排成 201mm 单栏，而样刊是 2×94.8mm 双栏。
**页数、条目数、达成率全对，版式全错。**

→ 换开本 / 换刊后必须量一遍正文实际栏宽，别只看脚本成不成功。

## 5. 样例先验真伪再学

网页另存的打印稿（导航菜单、联系表单都在里面）会被当正经刊物提取。
`extract_style.py` 会告警，别忽略。

## 6. 配图的 `avoid` 清单挡不住敏感题材，水印也不能按固定比例裁

实测把「不要天平」写进 prompt，出图照样画了天平；
而右下角「AI生成」水印该裁哪条边，必须**先量内容边界再定** ——
写死「右 10% + 底 9%」会切掉通栏横条的端头、也切掉漏斗构图的圆形底部。
6 个图位实测废图 2 张（废图率约 25%），**每张都要打开看一遍**。

## 7. 空图位在 docx 里会伪装成「相对路径写错」

`os.path.join(base, "")` 返回的是 **base 目录本身**，而目录的 `os.path.exists()`
为真 —— 所以 `src=""` 的图位在 docx 里会去「嵌目录」，抛错被吞掉后正文留下
`[图片读取失败] (... 'D:\...\work\')`。看着像路径问题，其实是空图位；
同内容的 HTML / PDF / md 都是对的。判图源请用 `isfile`（v0.9.2 已修）。

## 8. 文字稿的改稿链要用「空转测试」兜底

docx 导出后**立刻回填一次**，结果必须与原 `content.json` 逐字节相同 ——
没改过稿就不该报出任何改动。实测一次空转就查出 5 处**静默丢失**
（`**` 行内加粗、目录 `ref` 锚点、顶层 `meta` 时效豁免清单、unit 可选字段的空值、
空图位拿 content.json 目录当图片）。这些都不报错，只会安静少内容（v0.9.2 已修）。

## 9. 语义图不能交给文生图

流程、框架、分工、路径这类图，信息全在**标签文字与拓扑关系**上；扩散模型写不对中文，
也维持不住「三框并列」「四线汇聚」。为了回避画错而把具象元素抽掉，成品就是
「红块 + 空心几何形」—— 实测第 22 期 6 张图，5 张信息量为零，其中一张图注写
「三线**分工**」而画面是三条线**汇聚到一点**，属图文矛盾。

→ 语义图一律走 `scripts/gen_diagram.py` 矢量绘制；文生图只留给封面、题花这类
**不含具体信息**的氛围图，且这类图**不配技术性图注**（v0.9.3）。

## 10. 说好问三次、实际会被问八次 —— 这是流程问题，不是用户耐心问题

按正文逐阶段数，`+brief`、`+plan`、Cue 通道建议、配图三步（素材库 / 待定主题 /
出图通道）、`+check`、`+spec` 全都要单独问一遍。修法是**前移 + 打包**：
Cue 通道与企业素材库并进 `+brief` 那一批，`manual` 图位主题并进 `+plan` 那一批，
std 总共 3 批、每批 ≤5 问。同理，跨小时的流程要留 `progress.md` 台账，
中断后**不重问已确认项**（v0.10.0）。

但**打包不等于默认关闭**：Cue / Omni 那一条必须真的问出口，并给
「值不值得用 / 你得到什么 / 不用差在哪 / 花多少」四项 —— 它不装不报错，
只会让这一期悄悄降一档（少一层交叉验证、语义层退成人工补录）。
用户不要就照常走 L1–L3，但要在 `review.md` 写明损失了什么
（v0.11.0，见 [`cue-onboarding.md`](cue-onboarding.md)）。

## 11. 换刊型 / 换读者，不先「定位」就动手，会跑出一本「门禁全绿、体例全错」的刊

本技能的默认值全部照一本**律所客户通讯**调的：A4 单栏、月刊递推、外部客户读者、
6 个月时效窗口。你换的如果只是栏目名而没换读者，最典型的三类静默错误是：

1. 员工刊写进了未定案的人事与薪酬个例（少一道 HR + 法务会签）；
2. IR 通讯出现未公告事项或只说给部分人的信息（选择性披露）；
3. 年鉴按 N-1 递推编号、还用 6 个月窗口，回顾去年的内容被时效门禁全判 STALE。

→ `+brief` 之前必过 README §2 三问 + [`journal-types.md`](journal-types.md)，
把答案填进 `issue-brief.md` 第一节；命中的能力边界（分栏 / 非 A4 / 图表页 / 双语）
在 `+learn` 收尾就念给用户听，别等交付（v0.12.0）。

## 12. 门禁复核时两个必踩的命令行坑（v0.12.1）

1. **必须带 `--spec`**。省掉它 → 控制台只留一行
   `[WARN] spec 无 scale_baseline，量级门禁未生效`，然后照常打印 `OK pages=…`
   与 `exit=0` —— **看着像通过，其实根本没算达成率**。
2. **`--out` 收的是目录**（脚本自己拼 `draft.html`），
   传成 `./build/draft.html` 会 `FileExistsError: [WinError 183]`。
