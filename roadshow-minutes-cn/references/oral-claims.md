# 口头表述与披露事实的分层速查

本件把一份纪要里的话分四层登记，**层与层之间不许互相冒充**。这四层不是可信度评分，只是「这句话的出处走到哪一步」的状态。

## 四层与各自写法

| 层 | 含义 | 卡面上的写法 |
|---|---|---|
| 甲｜口头表述 | 只在纪要里出现、本件未与任何披露文件核对 | 原句逐字＋锚，行末带「（口头表述，未经披露文件核对）」 |
| 乙｜转手件 | 纪要本身是券商、自媒体或群转发来的 | 头部申报写「转手件，未与官方记录表核对」，降 C 级 |
| 丙｜官方记录表一致 | 公司发布的投资者关系活动记录表里有同句或等价句 | 「口径对照」里两句并列、各挂各锚，注明两份都取到 |
| 丁｜披露文件口径 | 定期报告或临时公告里写过 | 这已超出本件射程：写「请以该披露文件为准」并给定位，不代转述 |

## 为什么甲层必须带标注

1. 纪要的体裁决定它留不住限定词：「预计全年」「大概在…区间」「如果订单落地」这类结构在转抄中最容易被抹平，抹平之后就变成既成事实；
2. 数字一旦失去层位就会被下游当披露引用：本件不做真伪判断，但要把「这句话目前只是口头表述」这件事留在行内，让读卡的人不必猜；
3. 写不出标注就等于核不了出处——这一项按缺数处理，而不是去掉标注硬出。

## 什么时候起对照腿（数据腿）与正文腿（解析通道）

- 只用甲层出卡：两条腿都不起，卡照样齐（五段与八项名目不缺），代价是所有数字停在口头层；
- 要把某句升到丙层：起数据腿去取公司发布的投资者关系活动记录表，取到才写两句并列；取不到就照实写「本次两份未齐，口径不判」；
- 原句在多页附件里：起解析通道按节取用，取到那一句才写进项行，取不到就进缺数清单。

三条通道的官方配置页在本包对外面只给指针：解析腿 <https://cuecue.cn/hub/omni-reader>；数据腿 <https://cuecue.cn/hub/mcp>；取 key <https://cuecue.cn/hub/api-key>。域与工具名一律以 live catalog 现值为准，本文不列固定清单、不写枚数。

## 待人工的三类

- 「这算利好还是利空」「要不要动仓位」——本件不答；
- 管理层表态与公司既往披露之间的差异定性；
- 传闻性数字（第三方转述、未经公司口径确认的量）的可信度判断。
