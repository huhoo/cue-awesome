# employee-stock-ownership-cn

**给一份 A 股员工持股计划草案，产出八项逐字卡：计划名称与期次、参加对象与确定标准、资金来源、股票来源、受让价格与规模、存续期与锁定期、管理模式与持有人会议、变更终止与权益处置，每项挂原句＋来源锚；值不值得参与、价格公不公允、能否解锁、个税与递延纳税一律 `[待人工]`。**

**它和股权激励不是一件事（这一句是本件存在的理由）**：**员工持股计划走《关于上市公司实施员工持股计划试点的指导意见》，股权激励计划走《上市公司股权激励管理办法》**——规则来源不同、参加对象与定价口径不同、审议与披露程序不同。一份员工持股草案里不会出现「授予价格」「行权」「解除限售」这套激励语汇，一份激励草案里也不会出现「持有人会议」「管理委员会」「受让价格」这套持股语汇。所以**员工持股的条款在 `equity-incentive-plan-cn` 里读不到，激励计划的条款在本件里也读不到**；两枚包不互相覆盖，也不互为替代。同一家公司同一年既做激励又做持股时，是两份文件、两套规则、两张卡。

它只管一份员工持股草案的条款怎么写：哪天过户、哪个解锁窗口开闭这类**事件日期**在 `catalyst-calendar`，自选清单里**这项计划推进到哪一步**的日增量在 `watchlist-digest-cn`，公告清单在 `announcement-daily-cn`，定增方案在 `placement-terms-cn`，可转债条款在 `convertible-bond-terms-cn`。草案原文是唯一依据——**媒体解读与转手摘要都要标明层级**，这条界线是本件存在的理由。

## 一、打开就干：今天这三步

1. 给一份草案或公告：正文粘贴、披露页定位、摘要件都行；没写的那一项要求它写「未检索到」，不许按「员工持股一般都设三年存续期」这类惯例补。
2. 读前两段：头部申报＋八项逐字速读——这两段只要文件到手就能出，不需要任何通道。
3. 盯两格数字：受让价格与标的股票数量、资金来源与资金总额必须落在**该项自己的原句**里，且机检先把原句**切成短语、以结构体为主定性**（每枚数只在自己那条短语里找所有者：跳过「每股」「不低于」这类单位与连接词后最近的实义名词属本格族才算，属交易均价·收盘价·面值·每股净资产·股本总额·每份份额·授予价格这类参照数即剔，哪怕同一短语别处写了本格名词；短语两头都空才继承前序最近一次的本格名词，**前序最近的若是参照数就不继承**；每格两个元素各自要有落点——受让价格要有元/股原值、标的股票数量要有股数原值，只给一枚不算这格取到）——「届时公告」「由管理委员会确定」「另行约定」不算数，「草案公布前 20 个交易日交易均价 34.70 元/股」「公司股本总额 130,953.3797 万股」「每份份额 1.00 元」是参照数不算数，「受让价格不低于交易均价的 50%」里的 50% 是比率不算价格，「存续期 36 个月」是期限不算价格；遇到了就让它进缺数清单。

## 二、五道机检（零网络）

产物交给 `scripts/check_esop_card.py` 过闸：五段齐＋八项名目行级在场（每枚名目须占一行，散文里提到不算；名目按**别名表**归一到同一枚——写「购买价格与规模」与写「受让价格与规模」是同一项，写「持有人范围与确定标准」与写「参加对象与确定标准」是同一项）／每项原句与锚（书名号内空或只剩一个字算缺原句，「锚：」后面空着也发）／红线断言三道（定式禁词族含评价、预测与**税务**三支——「方案很合理」「受让价格基本公允」「解锁概率大」「应缴个人所得税」「可递延纳税」「税务筹划」同判；「主题词＋判断语气同段」；「裁定前缀＋效力判断」，只准出现在 `[待人工]` 或明写不接的那一**分句**里——标记与免责都不跨句；「X 会」机构名与「会 X」名词里的「会」先从语气域洗掉，所以「持有人会议」「管理委员会」「薪酬与考核委员会」不误红）／齐缺申报恰一枚且与未检索到行数对账（两处互相矛盾的申报同样发）／两格数字以短语结构体为主判（拆字段取该项原句、先剥日期，再按「标点 ∪ 数字边界」切成短语表：每枚候选只在自己那条短语里定档——数左跳过单位取最近实义名词、数左空着看数右、两头都空＝孤立数才继承前序最近一次的本格名词且前序最近的若是参照数则不继承；比率与期限不参与——以 ％·%·倍 收尾的候选不结算元素，被比率词紧领的金额同样不结算）：每格两元素各自要有落点，缺任一元素又没写未检索到才发——别格的数、参照数与日期都不顶账。

```bash
python3 scripts/check_esop_card.py --help                          # 参数说明
python3 scripts/check_esop_card.py --selftest                       # 好样须过、坏样五道齐发、钉阈按整族各钉一档、对照样不误伤、临时件自清（枚数由自测自报）
python3 scripts/check_esop_card.py scripts/fixtures/good-esop-card.md     # PASS（发条 0 条）
python3 scripts/check_esop_card.py scripts/fixtures/bad-esop-card.md      # FAIL（五道各发，逐条点名行号）

```

## 五、边界与不承诺

- 这份方案值不值得参与、受让价格是否公允、考核目标能否达成、解锁能否实现、个人所得税与递延纳税如何处理、对当期业绩与股价的影响一律 `[待人工]`；不出「建议参与」「建议认购」「稳赚」「零风险」「保证收益」「利好」「必涨」；
- **不判税务**：草案写「按国家有关规定执行」就逐字登记，写「递延纳税」就登记递延纳税；该缴多少、能不能递延、怎么筹划属税务位与人工——写出这类断语会被机检发红；
- 不判效力：计划是否有效、审议程序是否违规、持有人会议决议是否成立，属人工与监管认定位——写出这类自裁断语会被机检发红；
- 不判规则适用：该走自行管理还是委托管理、该不该提交股东会，本件只按原文登记写了哪种，不代答该用哪套规则；
- 不接代办：不出方案文书、不代拟草案、不代算税、不代客投票或申报，也不提供任何绕开审议、规避披露或打探内幕信息的路径；
- 两格数字逐字：「以…为准」「另行约定」「届时公告」「交易均价」「收盘价」「面值」「每股净资产」「股本总额」「每份份额」都不算本格原值，没取到就写「未检索到」；每格两个元素各自要有落点——受让价格要有元/股原值、标的股票数量要有股数原值，只给一枚不算这格取到；**名词族按真实公告的写法收**：数量那一格也认「标的股票上限」「标的股票规模」「认购的股数上限」，价格那一格也认名词中间插括注的写法（「购买股票（含预留部分）的价格」「受让价格（含预留）」）；
- 数字归属有射程：机检判的是同一短语内的相邻关系，加一次跨短语继承，不声称覆盖所有自然语言的归属表达；同位式共指与「价格待定但数量已定」的同段共存式属已知覆盖不到、按严格式发红，这类句型人工回原句核对；判不到又确实没写，`未检索到` 是合法答案；
- 八项名目按「任一表述命中即算在场」认：参加对象有的公司写「持有人」、受让价格有的写「购买价格」、股票来源有的写「股份来源」，**章节标题的写法也算**（「持有人的确定依据、范围及份额分配情况」「价格和规模」「存续期、锁定期、考核设置」），卡面写哪个别名都认；但别名只解决「这一项在不在」，不解决「这一项取没取到」；
- 未检索到＝照实写「未检索到」，禁以同类计划的惯例补写，也不写「无该项」顶替；
- 域与工具名以 live catalog 现值为准，本件不列固定清单、不承诺枚数，也不承诺该域是否开放与文件的实时性。

## 六、出错了怎么办

| 症状 | 来路 | 恢复动作 |
|---|---|---|
| 好几项是「未检索到」 | 文件是决议摘要，或价格与考核细则在草案附件里 | 起附件解析腿补原句；起不动就保留缺数点名，不补写 |
| 数据腿连不上 | 凭据缺位或该域未 live | 按 §四 自查；前两段仍可出，代价见 §四 那一句 |
| 机检发红 | 缺锚／缺原句／两格里没落定的元素／齐缺不符／写了判断句 | 按逐条点名的行号补齐；补不出的进缺数清单，不删行凑数 |
| 判断句被误红 | 那行写的是「持有人会议」「管理委员会」「薪酬与考核委员会」这类机构名，或引用草案原句 | 原句留在书名号内、锚照常挂；机检把「X 会」这类机构名 token 整体洗掉再判语气，正常登记句不误红 |
| 自裁句包进书名号仍发红 | 那句是本件自己的结论（「本件结论：『价格公允』」「我们判断：『价格公允』」），没有原文可引 | 把判断改写成 `[待人工]` 那一段的留人工说法，或引草案原句并挂锚——豁免按白名单准入：有锚＋书名号外只剩引用标签＋书名号内标签也是引用标签＋书名号内不得出现本件自称（本件·本卡·本速读·笔者；「本公司」「本计划」「本员工持股计划」不算；「样本件」「基本件」「成本件」「副本件」这类复合词也不算——前邻实词即不算；「本 件」这类空白断字算；前邻不在有限虚词表内的形如「通过本件判断」机检认不出、属已知覆盖不到，请人工回原句核对） |
| 本格数被判成参照数 | 一句里先写了交易均价或股本总额、本格名词在更左 | 把该格的数与本格名词写进同一句（照草案原句即可），或该项确未取到就写「未检索到」 |
| 名目写法与卡面不一致 | 草案章节标题用的是「购买价格」「持有人」「持有人的确定依据、范围及份额分配情况」这类别名 | 卡面写哪个别名都认（机检按别名表归一，章节标题原样也收）；但原句与锚仍要齐 |
| 税务那一格被判红 | 那行写了「应缴个人所得税」「可递延纳税」「税务筹划」这类判断 | 改成逐字登记草案原文（「按国家有关规定执行」），或挂 `[待人工]`；本件不判税务 |

## 七、怎么开口（正例与反例）

- 正例：「这份员工持股计划的参加对象是谁、有没有董监高」「钱从哪来、股票从哪来」「受让价格多少、一共多少股、占总股本多少」「存续期几年、锁定期多久、分几期解锁」「谁在管、持有人会议能决定什么」「离职了份额怎么办、什么情况下计划终止」「这份是员工持股还是股权激励」。
- 反例：「这份方案值不值得参与」「受让价格贵不贵」「考核目标能不能达成」「这次解锁稳不稳」「要缴多少个税、能不能递延」「复牌后股价怎么走」——参与价值、公允性、达标判断、税务处理与市场反应不在本件，一律 `[待人工]`。

## 八、能力边界（诚实清单）

行情与资金流类数值不在本件能力内（该域以 live catalog 现值为准，未开放就不承诺）；本件不做方案设计与测算（份额分配、考核指标设定、税务测算由公司、律师与税务顾问定）；不判断方案优劣、参与价值与内幕信息可能；不做监管规则适用判断（该走自行管理还是委托管理、该不该提交股东会，只按原文登记）；也不持久存你的文件，卡出完就交还给你。
