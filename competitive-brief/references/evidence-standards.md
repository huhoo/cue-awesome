# EvidenceCard 规范

## 结构

每条判断性结论一张 card，落在 `evidence/<条目>.md`。

```markdown
- 主张: <简报里要写的那句话>
- 层级: L1 / L2 / L3 / L4
- 来源: <机构全称>
- 题目: <文件名/文章名>
- 日期: YYYY-MM-DD
- 链接: <URL>
- 原文摘录: <≤80字，方引号>
- 可信度: 一手 / 二手 / 待验证
- 事实 vs 推断: fact / inference / opinion
```

## 可信度判据

| 可信度 | 判据 |
|---|---|
| 一手 | 来源是竞品官方发布的原文（官网、年报、SEC 文件、官方博客、官方定价页） |
| 二手 | 来源是第三方报道、评测、分析报告、用户评价 |
| 待验证 | 来源无法确认、或来自不可靠渠道（论坛、匿名、AI 生成内容） |

## fact / inference / opinion 标注规则

| 标注 | 定义 | 例子 |
|---|---|---|
| `fact` | 可被原始来源直接证实的断言 | 「定价 $99/月（来源：官网定价页 2026-09-01）」 |
| `inference` | 从多个 fact 推导的合理结论 | 「高价策略暗示面向企业客户」 |
| `opinion` | 作者判断，无可直接引用来源 | 「这个功能的设计体验优于竞品」 |

## 禁止行为

- 无 EvidenceCard 的声明进入简报正文
- `待验证` 条目不标待验证就写进结论
- inference 当 fact 交付
- opinion 前不加"I think / 我们认为"之类的明确标记
