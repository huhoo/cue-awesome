# Evidence 标注说明

## fact / inference / opinion

| 标注 | 含义 | 例子 |
|---|---|---|
| fact | 可从原始来源直接证实 | 「定价 $99/月 → 官网 2026-09-01」 |
| inference | 从多个 fact 推导的合理结论 | 「高定价+企业案例暗示目标客群是 enterprise」 |
| opinion | 作者判断，无直接引用 | 「这个交互设计比竞品好」 |

## 可信度

| 可信度 | 含义 |
|---|---|
| 一手 | 竞品官方发布（官网、年报、SEC 文件、官方博客） |
| 二手 | 第三方报道、评测、分析报告 |
| 待验证 | 来源不可靠或无法确认 |

## 约束

- 结论性判断必须可追溯
- 不是每句话都要标，但结论性判断必须有来源
- 不往简报里放没有来源的数字
