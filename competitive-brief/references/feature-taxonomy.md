# 通用特征分类法

## SaaS / 软件产品 默认特征维度

| 大类 | 维度 | 说明 | 证据层级 |
|---|---|---|---|
| 产品功能 | 核心能力 | 产品解决的核心问题与覆盖范围 | L1（竞品官网/文档） |
| 产品功能 | 技术架构 | 部署方式（SaaS/私有/混合）、数据驻留 | L1（技术文档） |
| 产品功能 | AI 能力 | 是否内建 AI 功能、模型、自动化程度 | L1 + L4 验证 |
| 产品功能 | 集成生态 | API 开放度、第三方集成数量、市场 | L1（文档）+ L3（市集数量） |
| 定价 | 计价模型 | 按 seat / 按 usage / 按 tier / 自建 | L1（官网定价页） |
| 定价 | 免费额度 | 有/无、量级 | L1+L3（用户评价验证） |
| 定价 | 隐藏成本 | 实施费/年约/超额/培训 | L1+L3（二手验证） |
| 市场定位 | 目标客户 | 企业规模（SMB/Mid/Enterprise） | L1（官网/案例） |
| 市场定位 | 地理覆盖 | 区域/全球、数据驻留合规 | L1+L4 |
| 市场定位 | 行业垂直 | 专注通用/行业版 | L1+L4 |
| 市场信号 | 融资历史 | 最近轮次、金额、估值、投资者 | L4（Cue 深研） |
| 市场信号 | 团队增速 | 招聘变化、关键人事 | L4 |
| 市场信号 | 产品上新 | 近期发布/收购/下线 | L4 |
| 市场信号 | 客户口碑 | NPS / G2 评分 / 财报提及 | L3 + L4 |

## 金融 / FinTech 默认特征维度

（替换核心能力为资管/风控/合规/交易覆盖等）

## 医疗 / HealthTech 默认特征维度

（替换核心能力为诊疗范围/认证/数据合规/临床证据等）

---

> 行业预设维度在派生 `competitive-<行业>-brief` 子技能时钉死。
