# 分红到账与扣税时间轴·逐条挂源

把一份权益分派实施公告排成三个日期节点，并按五类股东分列税率、计税基数与扣税后实得，每条挂原句与锚；公告没写的类型逐条写「未取到」。

## 一、打开就干：今天这三步

1. 把权益分派实施公告（URL 或本地文件）交给本件。
2. 本件排出股权登记日 → 除权除息日 → 现金红利发放日，并按五类股东分列税率、计税基数、扣税后实得。
3. 公告没写的股东类型进未取到清单，判断类问题全部进「待人工」。

## 二、五道机检（零网络）

```bash
python3 -B scripts/check_dividend_tax_timeline.py <卡面.md>     # 五道码逐条发红，全过则 PASS
python3 -B scripts/check_dividend_tax_timeline.py --selftest    # 好样须过、坏样五道齐发
bash scripts/fixtures/run_fixtures.sh                           # 离线样例三档（30 秒、零网络零计费）
```

| 码 | 判什么 |
|---|---|
| `DT-STRUCT` | 五段齐；三日期节点**行级在场**且**有序**（登记日 ≤ 除权除息日 ≤ 发放日）；五类股东行级在场；非「未取到」的行三要素齐（税率·计税基数·扣税后实得） |
| `DT-QUOTE` | 每行书名号内原句不得为空或只剩单字；「锚：」在而锚值为空同样发 |
| `DT-LINE` | 红线三道：定式禁词（择时建议／评级目标价／收益承诺／代办／税负高低）／主题词×判断语气同段／自裁效力层 |
| `DT-GAP` | 未取到两向点名（申报多了是虚报、少了是漏报）；「不适用／无需扣税」一律发；**税率数字必须在该行自己的原句里**，否则判「套用默认税率」 |
| `DT-BOUND` | 出现分红方案速读的项行 ⇒ 写错了件，点名改走 `cn-shareholder-return` |

## 四、首次开通 Cue（三步，可跳过）

1. 在 cuecue.cn 注册并拿到 `CUE_API_KEY`。
2. 导出到环境：`export CUE_API_KEY=...`。
3. 连通自查：

```bash
# 1) 看目录，拿端点
curl -s https://cuecue.cn/api/mcp-catalog | head -c 500

# 2) 按 MCP 协议握手，确认三枚工具在场
curl -s -X POST "$MCP_ENDPOINT" -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

**不装也能跑**：没有 key 时本件只走用户直供的公告正文与本地文件，代价是取不到渠道侧的披露原文与附件正文解析，锚只能落在用户给的那份上，跨文件核对做不了。

## 五、边界与不承诺

- 不给择时建议（建议持有到登记日、登记日前买入、抢权、填权行情）。
- 不给评级与目标价。
- 不承诺收益（稳赚、零风险、保证收益、必涨、必跌）。
- 不代拟、不代算、不代申报、不代客。
- 不判税负高低（税率划不划算、税负偏高偏低）。
- 不裁断效力（扣税口径是否合规、是否有效）。
- 不重复登记分红方案本身——那是 `cn-shareholder-return` 的活。

## 六、出错了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `DT-STRUCT 缺段` | 五段标题被改名或漏写 | 按 SKILL.md §3 输出契约的五段标题原样写 |
| `DT-STRUCT 时间轴段内缺节点行` | 节点只在散文里提到 | 三个节点各占一行，以 `- 节点名：` 起头 |
| `DT-STRUCT 日期节点次序错` | 除权除息日早于登记日 | 回公告核对三个日期，别按记忆排 |
| `DT-STRUCT 原句里没有适用税率` | 该行原句没写税率 | 公告没写就整行改成「未取到」，不许补默认税率 |
| `DT-QUOTE 书名号内原句为空` | 抄成了概括或留空 | 回原文抄原句，不许转述 |
| `DT-GAP 申报未取到 N 类…` | 头部申报与段内「未取到」行数不符 | 数一遍分类型税负段里几行写了「未取到」 |
| `DT-GAP 税率 … 不在本行原句里` | 税率是税法默认值，不是公告说的 | 删掉自填的税率；公告没写就写「未取到」 |
| `DT-BOUND 出现分红方案速读的项行` | 写成了分红方案速读 | 方案本身改走 `cn-shareholder-return`，本件只做时间轴与税负 |
| `DT-LINE 定式禁词` | 写了择时建议、评级或收益承诺 | 删掉，改成原句登记或进「待人工」 |

## 七、怎么开口（正例与反例）

**正例**

- 「这份权益分派实施公告，登记日、除权除息日、发放日分别是哪天？」
- 「分红要扣多少税，个人股东和 QFII 到手各是多少？」
- 「我们这类股东适用什么税率？公告里写了吗？」

**反例**

- 「分红前该不该买入？」→ 本件不给择时建议，只排时间轴。
- 「这次分红划不划算？」→ 本件不判税负高低，只登记原句。
- 「帮我算一下我该交多少税、帮我申报。」→ 本件不代算、不代申报。
- 「每 10 股派多少、分红总额多少？」→ 那是分红方案速读，改走 `cn-shareholder-return`。

## 八、能力边界（诚实清单）

- 税率只认**该行自己的书名号原句**里的百分比；公告用「按适用税率代扣」这类不写数字的表述时，本件判「未取到」，不替你查税法。
- 股东类型按别名族认，别名表在 `scripts/check_dividend_tax_timeline.py` 的 `SH_ALIASES`；遇到新写法要加别名，不是改判据。
- 日期只认 `2026 年 6 月 12 日` / `2026-06-12` / `2026/6/12` 三种写法；公告用「T 日」「登记日次一交易日」这类相对表述时，本件判「行内无日期」，需人工换算。
- 三要素判的是**名词在场**，不判数值算得对不对；扣税后实得与税率的算术关系请人工复核。
