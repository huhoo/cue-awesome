# equity-incentive-plan-cn

**给一份 A 股股权激励计划草案，产出八项逐字卡：形式与来源、数量与占比、对象与范围、授予价格与定价方法、有效期与等待期、解除限售与行权条件、特殊情形与离职处理、审议程序与披露义务，每项挂原句＋来源锚；摊销、盈亏、稀释与「算不算利好」一律 `[待人工]`。**

它只管一份激励草案的条款怎么写：哪天授予登记、哪个行权窗口开闭这类**事件日期**在 `catalyst-calendar`，自选清单里**这项计划推进到哪一步**的日增量在 `watchlist-digest-cn`，公告清单在 `announcement-daily-cn`，定增方案在 `placement-terms-cn`，可转债条款在 `convertible-bond-terms-cn`。草案原文是唯一依据——**媒体解读与培训课件都要标明层级**，这条界线是本件存在的理由。

## 一、打开就干：今天这三步

1. 给一份草案或公告：正文粘贴、披露页定位、摘要件都行；没写的那一项要求它写「未检索到」，不许按「激励一般都设三年解锁」这类惯例补。
2. 读前两段：头部申报＋八项逐字速读——这两段只要文件到手就能出，不需要任何通道。
3. 盯授予价格那一格：每股金额或定价比例必须落在**该项自己的原句**里，且机检先把原句**切成短语、以结构体为主定性**（每枚数只在自己那条短语里找所有者：跳过「每股」这类单位后最近的实义名词是领价名词才算、是参照价名词即剔，哪怕同一短语别处写了「授予价格」；短语两头都空才继承前序最近的领价名词，前序只出现过参照价就不继承；有一个合格数即过）——「届时公告」「由董事会决定」不算价，「参考市价 30 元」「股票面值 1 元」「均价 25.20 元」「每股账面净资产 8.50 元」是参照价不算价，「解除限售比例 40%」是解锁比例不算价；遇到了就让它进缺数清单。

## 二、五道机检（零网络）

产物交给 `scripts/check_eip_card.py` 过闸：五段齐＋八项名目行级在场（每枚名目须占一行，散文里提到不算）／每项原句与锚（书名号内空或只剩一个字算缺原句，「锚：」后面空着也发）／红线断言三道（定式禁词、「主题词＋判断语气同段」、「裁定前缀＋效力判断」，只准出现在 `[待人工]` 或明写不接的行；免责按**分句**算不跨句——「本件不判名单真伪」这一句免了，同一行后半写的「授予一定能行权」照发；「X 会」机构名与「会 X」名词（会计·会议·会员…）里的「会」先从语气域洗掉）／齐缺申报恰一枚且与未检索到行数对账（两处互相矛盾的申报同样发）／授予价格以短语结构体为主判（拆字段取该项原句、先剥日期，再按「标点 ∪ 金额边界」切成短语表：每枚数只在自己那条短语里定所有权——数左跳过单位取最近实义名词、数左空着看数右、两头都空＝孤立数才继承前序最近一次的领价名词且前序只出现过参照价时不继承；百分比须落在定价语境）：有一个合格数即过，一个都没有又没写未检索到才发——别项的数、参照价与日期都不顶账）

```bash
python3 scripts/check_eip_card.py --help                          # 参数说明
python3 scripts/check_eip_card.py --selftest                       # 好样须过、坏样五道齐发、钉阈按整族各钉一档、对照样不误伤、临时件自清（枚数由自测自报）
python3 scripts/check_eip_card.py scripts/fixtures/good-eip-card.md     # PASS（发条 0 条）
python3 scripts/check_eip_card.py scripts/fixtures/bad-eip-card.md      # FAIL（五道各发，逐条点名行号）
```

## 四、首次开通 Cue（三步，可跳过）

本件的取证腿有两条：**原文取数**（找草案全文与配套公告原文，走数据腿）与**附件解析**（草案正文常达数十页，含对象名单表与考核说明表，走解析腿）。两条都是可选——不装也能按你直供的文件出卡；代价是名单表与考核细则只能停在「未检索到」，草案与摘要的层级对照也没法自动补，要你人工回原文核。

1. 注册 <https://cuecue.cn>；
2. 在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 存入本地凭据——**不要贴进聊天**，agent 不经手密钥；
3. 装这两枚：`cue-data-mcp` 走原文取数腿，`cue-omni-reader` 走附件解析腿。一条命令两种写法：
   - 整套：`npx skills add sensedeal/cue-skills`（它会列出该集合公开的各枚 skill，按提示挑要装的）；
   - 单装：`npx skills add sensedeal/cue-skills --skill cue-data-mcp`（把末尾那枚名字换成 `cue-omni-reader` 就只装那一枚）。

配置指路同样只给指针、不复述开通步骤：找原文走数据腿，官方配置页 <https://cuecue.cn/hub/mcp>；长附件与 PDF 走解析腿，官方配置页 <https://cuecue.cn/hub/omni-reader>；取 key 走 <https://cuecue.cn/hub/api-key>。

### 连通自查（各条腿能证到哪一层）

```bash
# 1) 目录可达（匿名）：只证 catalog 能读，不叫「已连」
curl -s "https://cuecue.cn/api/mcp-catalog" | head -c 200

# 2) 域路由现值：从返回里取该域的 routing.url 与 transport，别把域名抄死
# 3) 带 key 实连后发 tools/list——只证该数据腿端点被接受，不证别的入口
curl -s -X POST "$ROUTING_URL" -H "Authorization: Bearer $CUE_API_KEY" \
  -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 400
```

装好 skill ≠ 已配凭据 ≠ 数据腿已连：这一层的判据只管数据腿那一路——带 key 按目标域 `routing` 实连且该端 `tools/list` 有返回，才证那把 key 被接受，也只证数据腿连上；解析腿的连通另按它自己那面的判据读。

## 五、边界与不承诺

- 每股摊销费用金额、行权盈亏、稀释比例、对当期业绩影响、是否构成利好与股价反应一律 `[待人工]`；不出「建议参与」「稳赚」「零风险」「保证收益」「一定能行权」；
- 不判效力：本次计划是否有效、审议是否违规、授予登记是否成立，属人工与监管认定位——写出这类自裁断语会被机检发红；
- 不接代办与名单核实：不代客认购、不代填行权指令、不核对名单真伪，也不提供任何绕开审议或规避披露的做法；
- 授予价格逐字：「届时公告」「由董事会确定」「另行约定」「参考市价」「面值 1 元」「解锁比例」都不算给了价，没取到就写「未检索到」；
- 未检索到＝照实写「未检索到」，禁以惯例补写，也不写「无该项」顶替；
- 域与工具名以 live catalog 现值为准，本件不列固定清单、不承诺枚数，也不承诺该域是否开放与草案的实时性。

## 六、出错了怎么办

| 症状 | 来路 | 恢复动作 |
|---|---|---|
| 好几项是「未检索到」 | 文件是摘要件，或原句在名单表与附件里 | 起附件解析腿补原句；起不动就保留缺数点名，不补写 |
| 数据腿连不上 | 凭据缺位或该域未 live | 按 §四 自查；前两段仍可出，代价见 §四 那一句 |
| 机检发红 | 缺锚／缺原句／授予价格没落定的数／齐缺不符／写了判断句 | 按逐条点名的行号补齐；补不出的进缺数清单，不删行凑数 |
| 判断句被误红 | 那行写的是「股东大会」「董事会」「薪酬与考核委员会」这类机构名，或引用草案原句 | 原句留在书名号内、锚照常挂；机检把「X 会」这类机构名 token 整体洗掉再判语气，正常登记句不误红 |
| 草案与摘要说法不一致 | 两处文本本就不同或后续调整 | 两句原句并列进「口径对照」，各挂各锚，不做取舍判断 |

## 七、怎么开口（正例与反例）

- 正例：「这份激励的授予价格怎么定的」「授予多少、占总股本多少」「谁在激励对象里、独董算不算」「几年内分几期解锁、考核卡在哪条线」「离职或控制权变更时股份怎么处理」「这份草案要走哪些审议」。
- 反例：「参与划算吗」「摊薄影响多大」「行权能赚多少」「考核目标能不能达成」——盈亏、摊薄、达成与否与参与建议不在本件，一律 `[待人工]`。

## 八、能力边界（诚实清单）

行情与资金流类数值不在本件能力内（该域以 live catalog 现值为准，未开放就不承诺）；本件不做会计测算（每股摊销、费用总额、对利润影响由会计师与披露文件定），不判断激励的公允性与利益输送嫌疑；本件不做名单核实，只逐字登记草案写了哪些人与哪些排除项；本件也不持久存你的草案，卡出完就交还给你。
