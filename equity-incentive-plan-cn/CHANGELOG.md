# 更新日志

### 0.1.0 — 2026-11-04（本枚首次建包：A股股权激励计划草案的八项条款逐字卡，两条取证腿、五道机检与中英双技能面随包）
- 选题来路与它的弱处（写在顶条不藏）：既有套件里没有把**一份激励草案读成条款卡**的交付形状——全包现读「股权激励」只命中事件面与清单面（`catalyst-calendar` 的事件分类表把激励列为「授予登记日／归属日／行权窗口开启·截止日」这类**日期事件**；`watchlist-digest-cn` 的激励腿明写「只取与推进变化相关字段，不整表搬」；`tear-sheet` 与 `cn-earnings-note` 各只有一行事件或数据通道条目），「限制性股票」「股票期权」在两面包内零命中。搜索面的可复现据是一词的含词计数（盘上现读：该词前十结果里含词 8／10），本枚不以任何名次、下载量或转化为承诺，首版能力只到「一份草案的八项条款读成逐字卡」。
- 与其它几件的分工（切割句写进定位）：**事件日期与行权窗口**在 `catalyst-calendar`，**清单里这项计划推进到哪一步**在 `watchlist-digest-cn`，公告清单在 `announcement-daily-cn`，定增与再融资方案在 `placement-terms-cn`，可转债条款在 `convertible-bond-terms-cn`；本件只管一份激励草案的条款。
- 产出契约（激励卡五段，缺一即退回）：头部申报（计划名与来路层级／八项齐缺申报／本次是否发起过解析腿）→ 八项逐字速读（形制＝`- 项名：原句逐字 锚：<来源定位>`）→ 口径对照（草案与摘要或调整公告两句并列、各挂各锚）→ 缺数清单 → 待人工。八项名目与每行的原句、锚由随包机检按行判，不靠约定。
- 本枚独有的一格：**授予价格按规则判、不靠措辞**——「授予价格与定价方法」一项，凡不写「未检索到」的，机检先把项行拆成字段（名目／书名号原句／锚／句体），判据域只取该项自己的原句，先剥日期（草案公告日、授予日、登记日一律从取数域剔除），再要求同一段里既给出价格原值（每股 N 元／N 元）或落在定价语境的百分比与折扣（不低于·均价·折扣·定价·比例），又带本项定价语（授予价格·行权价格·均价·定价·每股）；「参考市价 30 元」是市价不是授予价、「解除限售比例 40%」是解锁比例不是定价——**别项的数与日期都不顶定价账**；反向判兜底：剥日期后没有合格段又没写「未检索到」即发，空泛语（届时公告／由董事会确定／另行约定／按有关规定执行／待定／以…为准）只决定发红那句话的措辞，换同义词换不掉判据。这条由随包机检的 EIP-PRICE 判，判法写在件里。
- 红线形状：每股摊销费用、行权盈亏、稀释比例、对当期业绩影响、是否构成利好一律 `[待人工]`；不判效力（本次计划是否有效、审议是否违规、授予登记是否成立属人工与监管认定位）；不接代办与名单核实，也不提供绕开审议或规避披露的做法。EIP-LINE 分三道：定式禁词族、「主题词＋判断语气同段」、「裁定前缀＋效力判断」——机构名里的「会」（股东大会、董事会、监事会）先从语气域洗掉，所以「尚需股东大会审议」「名单以股东大会批准为准」这类正常登记句不误红，而「解锁条件会达成」「摊薄将影响收益」「本次激励计划无效」发红。
- 两条取证腿：草案全文与配套公告原文在数据腿上；草案正文常达数十页、对象名单表与考核说明表藏在附件里，那一路在解析腿上。两条都写成可选并各自带代价——不装也出卡骨架，代价是名单表与考核细则只能停在「未检索到」。指路只给指针、不复述开通步骤。
- 名形制：`displayName` 取「股权激励条款速读」＝意图词落在词首＋名短；目录名与 frontmatter `name` 同值 `equity-incentive-plan-cn`，`slug` 为 `cue-equity-incentive-plan-cn`，`SKILL.md` 的 H1 随 displayName 走同一短形。
- 随包机检：`scripts/check_eip_card.py` 五道——五段齐与八项名目行级在场、每项原句与锚、红线三道、齐缺申报恰一枚且与清单对账、授予价格按规则判；零网络。`--selftest` 直接吃 `scripts/fixtures/` 那两份样例（好样须过、坏样五道齐发并逐条点名行号），钉阈按**整族**各钉一档（届时公告、协商确定、市价冒充、解锁比例冒充、公告日期冒充、裸判断句、自裁效力句……发红句把被剥的日期、落空候选与取数域首段一并点名当证据），另带对照样证明**带日期与括注约束的合格定价句、机构名里的「会」、草案原句里的判断措辞都不误伤**；枚数由自测自报，临时件建在一次性目录里、退出时自清。
