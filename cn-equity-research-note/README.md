# 个股深度研究·逐条挂源

给一个股票代码或公司名称，在**财报还没出来**的那一段，产出一份五节齐的研究初稿：业务拆解、竞争位、驱动因子、风险清单、关键数字表。每个数字与每条判断，行末都挂「」原句、〔锚〕与 `[S#]`；来源行带可点链接与检索日。

**不出评级、不出目标价、不预测股价、不写看好/看空。** 比率只认原句，要自己算的必须单列并交代分子分母出处。

---

## 一、打开就干：三步

1. **定主体与截至日**，收齐这家公司的材料：年报/招股书/募集资金公告/行业研究/公告原文。
2. **每节抄事实，连原句一起抄**：一句发现 = 一行，行末挂 `「原句」〔锚：页/节/表〕[S#]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_note.py 你的研究稿.md
python3 scripts/check_note.py --selftest      # 内置 11 条夹具自检
```

退码 `0` 全过、`1` 有发条、`3` 读不到文件或空稿。

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把材料放进工作区，走用户直供那条路。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `ER-FORM` | 形制 | 头部四件自标在第一个 `## ` 之前；`主体：` 与 `截至日：YYYY-MM-DD` 在场；六节齐且按序；四节各至少一条发现行；关键数字表有表头（含原句/锚/来源三列）与数据行 | 五节缺一节；关键数字表没写；某节只有小标题没有发现行 |
| `ER-ANCHOR` | 原句与锚 | 每条发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾；来源行齐 `[S#]`＋可点 URL＋检索日；正文引用的每个 `[S#]` 都要在来源节登记 | 只挂 `[S#]` 没抄原句；来源行只有标题没有链接；正文引用了 `[S9]` 但来源节没这行 |
| `ER-REDLINE` | 红线 | 评级、目标价、目标市值、股价预测、跑赢跑输、严重低估高估、必涨必跌、看好/看空，零命中 | 「给予买入评级」「目标价 58 元」「股价将翻倍」 |
| `ER-NOSELF` | 不得自算 | 百分数必须能在同一行原句里逐字找到；否则标 `〔自算〕` 并同时给出分子与分母各自的 `[S#]` | 毛利率自己除出来却写成原句；标了自算但分母没出处 |
| `ER-SCOPE` | 边界 | 已出财报语境 → 改走 `cn-earnings-note`；问题驱动语境 → 改走 `cn-research-brief`；研报结论转述 → 本件不收 | 稿子里写「本节覆盖四期差异与科目勾稽」 |

## 三、一条发现长什么样

```markdown
- 数控机床 2025 年实现营业收入 42.6 亿元，占主营业务收入 68.30%「数控机床产品实现营业收入 426,000.00 万元，占主营业务收入的 68.30%」〔锚：2025 年年报·第 46 页·营业收入构成表〕[S1]
```

- **「」原句**：从来源里**连续**摘一段，不改写、不拼接。
- **〔锚：…〕**：这句在来源里的位置——页码、章节号、表格名、段落序号之一。
- **`[S#]`**：与文末来源节那行对上。

要自己算的，长这样（分子分母各自挂源）：

```markdown
- 机床业务收入约为功能部件的 2.15 倍〔自算〕分子＝数控机床 426,000.00 万元 [S1]｜分母＝功能部件 198,000.00 万元 [S1]
```

## 四、三种行不挂原句（设计如此，不是漏网）

| 行 | 为什么不挂 |
|---|---|
| `未取到 …` | 它缺的就是那份材料，只要求挂 `[S#]` 指向你查过的那一处 |
| `[待人工]` | 判断位交付给人的那个位置，本来就没有原句可挂 |
| 非百分数的自算（如「约为 2.15 倍」） | 不强制标 `〔自算〕`，但标了就要交代分子分母 |

`[待人工]` **只豁免它自己那一句**。同一行后面再接「建议买入」，照样红。

## 五、和另外两枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 财报**还没出**，要给这家公司做一份研究 | **本件** |
| 财报**已经出了**，要逐数点评四期差异与科目勾稽 | `cn-earnings-note` |
| 你有一串具体问题，要多源找答案 | `cn-research-brief` |
| 想把研报原文抓下来、搬它的结论 | 本件不做——本件的观点必须能回到句子 |

## 六、跑夹具

```bash
bash scripts/fixtures/run_fixtures.sh
```

三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐行替换做正反对照（该红的红、该不红的不红）。零网络、零计费，产物只落临时目录，跑完即删。

末行自报「档数=3｜不合=N｜不可判=N」；退码 `0` 全过、`1` 有不合、`3` 取值域故障。

## 七、素材从哪来

- **用户直供**：手头的公告 PDF、研报、网页，走 `+parse` 解析。
- **通道取证**：配 `CUE_API_KEY` 后可走公告检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **零通道降级**：什么材料都没有时，出一张有形状的骨架——五节都在、每节一条「未取到（骨架）」占位。骨架过不了机检是设计，不是待补的疏漏。

本件不发请求、不代付费，消耗以服务端返回为准。
