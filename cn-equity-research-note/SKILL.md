# 个股深度研究·逐条挂源

**定位**：把「这家公司还没出财报的这一段」变成「一份每条都能回到一处原句的研究稿」。观点不稀缺，**稀缺的是每条观点与每个数字都能回到那一句原文**。
**不是**决议，不是荐股，不是研报搬运，也不会自己发布。

## 0. 什么时候用 / 不用

| 你要 | 用什么 |
|---|---|
| 财报真空期的个股研究：业务怎么拆、竞争位在哪、驱动是什么、风险有哪些、关键数字多少 | **本 skill** |
| 已出财报的点评：四期差异、科目勾稽、指引与兑现对照 | `cn-earnings-note` |
| 带着一串问题去多源找答案（「它海外收入占比多少」） | `cn-research-brief` |
| 抓研报原文、摘研报结论 | 不做——本件要的是**能回到句子**，不是转述 |
| 评级、目标价、买卖时点、股价走势 | 不做——红线，见 §4 道三 |

**三枚包的分界（用户靠这三句分清）：**

- `cn-earnings-note` = **已出财报**的点评，输入必须有财报，做的是披露后的逐数核对。本件**不要求财报**，做的是**预期期**的个股研究。
- `cn-research-brief` = **问题驱动**（你问什么它答什么），产出是问题清单的答案集。本件是**标的主键驱动**：给代码/名称，出一份结构化的公司研究。
- 研报客/研报查询助手那类 = **抓研报原文**。本件是把研报当来源之一，但**观点必须能回到句子**，不搬研报结论。

## 1. 输入契约

开工前问齐（缺什么问什么，≤5 问、逐条带默认值）：

- **主体**：股票代码或公司全称（默认：用户上一轮提到的那家；无则问）
- **截至日**：研究观察的截止日，默认今天；来源行的检索日以实际搜到为准，不以截至日代填
- **关注点**（可选）：如「重点看产能与客户结构」
- **素材**（可选）：公告 PDF、研报、网页、纪要 —— 走 `+parse`；没有不阻塞
- **口径提示**（可选）：港股/A股/美股，默认按代码判断并在稿首标注

## 2. 五节形制（缺一即发）

一份合格的稿子必须有且仅有这五节，顺序固定：

| # | 节 | 最小要求 |
|---|---|---|
| 1 | 业务拆解 | 收入/利润从哪里来，按产品线或分部拆；拆到几条业务由来源说话，不硬凑五段 |
| 2 | 竞争位 | 份额、对手、壁垒、定价权，各条挂原句；**没有份额原句就不写份额** |
| 3 | 驱动因子 | 未来 6–24 个月影响业绩的变量，逐条写「变量 + 传导 + 可观测指标」 |
| 4 | 风险清单 | 逐条写「风险 + 触发条件 + 已披露的应对」；没披露应对就写未取到 |
| 5 | 关键数字表 | 一张表，每行一个数字，列：指标 / 数值 / 口径与期间 / 原句 / 锚 / [S#] |

节内每条发现按 `-` 列表行写，行末挂三元组（见 §3）。判断句同样要挂——**「判断也要有出处」是本件区别于速览的地方**。

## 3. 原句与锚（道二的形状）

每个数字与每条判断，行末必须是：

```
- 发现正文……「原文里连续的一段字」〔锚：页/节/表位置〕[S3]
```

- **原句**：用「」包住，从来源里**连续**摘录，不改写、不拼接、不加省略号再接；长句可截取但必须是连续片段。
- **锚**：`〔锚：…〕`，指向该句在来源里的位置（页码、章节号、表格名、段落序号之一）。PDF 无页码就写章节名，网页写小节标题。
- **编号**：`[S#]` 与 §5 来源行一一对应。
- 一个发现由多句支撑就挂多个三元组，不合并成一句假原句。

## 4. 五道码（机检，零网络）

判据以 `scripts/check_note.py` 现值为准，本节是口径说明：

1. **道一 形制 `E-FORMAT`**：五节齐、顺序对、每节至少一条发现行；关键数字表在场且有表头；稿首主体与截至日在场。
2. **道二 原句与锚 `E-ANCHOR`**：每条 `-` 发现行末有 `「…」〔锚：…〕[S#]` 三元组；编号在 §5 有对应行；来源行同时带 URL 与检索日 `YYYY-MM-DD`。
3. **道三 红线 `E-BANWORD`**：评级（买入/增持/推荐/跑赢）、目标价、股价预测（将涨/见底/翻倍）、看好/看空类断言零命中；转述他人的评级须带引号与来源且标 `[待人工]`，否则同样红。
4. **道四 不得自算 `E-SELFCALC`**：所有比率（毛利率、市占率、增速、渗透率…）只认原句。行内出现比率数字但原句里没有同一数值，且未标 `〔自算〕` 并交代分子分母出处的，发红；标了 `〔自算〕` 但缺分子或分母来源的，同样发红。
5. **道五 边界 `E-SCOPE`**：稿内出现「已出财报」「财报点评」「四期差异」等已披露语境时，点名改走 `cn-earnings-note`；出现「问题清单」「逐问作答」时点名走 `cn-research-brief`。

## 5. 来源节

```
## 来源
[S1] 标题 | URL | 检索日 2026-11-09 | 类型：公告/研报/新闻/官网
```

- URL 必须是可点的原文地址，不写「见某某研报」；拿不到 URL 就在 §风险清单的未取到里点名，不进来源节。
- 检索日是**实际检索那天**，不是来源发布日；两者可并列写。
- 研报只作为来源之一，引用其**原文句子**，不写「XX证券认为……」这类结论转述。

## 6. 零通道 / 缺料

- 没有任何素材时，出一张**有形状的骨架**：五节在场、每节一条「未取到（骨架）」占位、来源节空；骨架**过不了机检是设计**，不是待补的疏漏。
- 单节缺料：该节写「未取到：<缺什么>」，并在稿末汇总；不得用「约」「左右」把空白填圆。
