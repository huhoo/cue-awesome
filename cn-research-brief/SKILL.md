# 中文多源研究速览（设计权威）

**定位**：把「一堆中文来源」变成「一份能被人逐条核对的速览」。要点不稀缺，**稀缺的是每条要点都能回到一处带检索日的来源**。
**不是**决议，不是荐股，不是单源的转述，也不会自己发布。

## 0. 是什么 / 不是什么
| 是 | 不是 |
|---|---|
| 多源逐条挂源：每条发现行末一个 `[S#]`，第四节一对一可回查 | 不是摘要器：只有一处来源时它不该被用（那是一篇转述） |
| 来源行必须同时带 URL 与检索日（多源速览的时效以检索日为凭） | 不是时间不写的「最新消息」：日期缺位机检直接发红 |
| 未取到与口径单独成节，逐条点名 | 不是把空白填圆：没取到的要么点名要么不写 |
| 判断位一律 `[待人工]` | 不是评级器：目标价／买卖／走势类断言零产出，命中即红 |
| 无通道时出一张有形状的骨架，红在结论占位那一行 | 不是把骨架当交付：结论位留占位是设计，不是待补的疏漏 |

## 1. 输入
- 一批来源：网页 URL、公告／报道原文、经解析得到的文档（`parsed-doc`）；或你手上已有的材料。
- 或一个问题：本件先把它拆成可逐条核对的发现位，再等来源填。
- 主体与检索窗口由你给；本件不替你选主体，也不替你定时间范围。

## 2. 工作流（四步，每步都可停）
1. **收源**：逐条登记来源，一行一条，标题＋URL＋检索日（`YYYY-MM-DD`）——日期是取数那一刻的日期，不是文章发布日期。
2. **摘条**：每条发现一行，只写来源里确实载着的话；行末挂该来源的编号 `[S#]`。跨源不一致时两条都留、不合并、不取平均。
3. **点名**：任何「没取到／没检索到」写进第三节并逐条列出——正文写了未取到而第三节没有它，机检发红。
4. **过机检**：`python3 -B scripts/check_brief.py <速览.md>`，按详行的 `E-*` 码逐条改。机检过完仍只是**草稿**：结论位要不要填、怎么填，由人定。

## 3. 输出契约（四节，机检按此判）
1. `## 1、一句话结论`：一句实句；写成占位会被判红。
2. `## 2、逐条发现`：每条一行、行末一个 `[S#]`；数值照来源写，不用「约／左右」打底。
3. `## 3、未取到与口径`：未取到的逐条点名＋口径说明（谁给的数、什么口径）。
4. `## 4、来源`：一行一源，`- [S#] 标题（URL ｜检索日 YYYY-MM-DD）`。
头部另有四件自标：AI 整理初稿／请回原文核对／不构成投资建议／判断位 [待人工]，逐字在位。

## 4. 通道与降级（两条路都真跑过）
- **主路＝深研通道**：多源取证与逐条出处来自通道那条腿（`cue-research` 深研／`cue-omni-reader` 解析）。实连判据照仓内既有面写：装好 skill ≠ 已配凭据 ≠ 通道已连——带 key 实连且 `tools/list` 有返回才证那把 key 被接受。命令与三层自查见 `README.md` 的「首次开通」那一节。
- **降级＝零通道**：本件仍能跑 `scripts/make_outline.py`，把已有来源清单排成一张待填骨架；代价同句写清——**缺的正是多源取证与逐条出处那一层，所以骨架只会有形状、不会有权衡后的结论**（结论位留占位，机检按设计发 `E-FORMAT`）。骨架不是速览，别把它当交付。

## 5. 红线（机检守，不由人守）
- 评级／目标价／建仓清仓／必涨必跌／稳赚无风险／跑赢大盘一类断言零命中；要提及就同行挂 `[待人工]`。
- 改数词（约／左右／大概）不得替数字打底；数值只照来源写，口径不齐就落第三节。
- 没有锚的要点不进第二节；对不上来源的锚发 `E-ANCHOR`。
- 本件不发请求、不代付费：解析与深研的消耗以服务端返回为准，本件不代估也不代付。

## 6. 最小可复跑链（零网络、零计费）
```bash
python3 -B scripts/make_outline.py --sources scripts/fixtures/sources.jsonl --out 我的骨架.md
python3 -B scripts/check_brief.py 我的骨架.md            # 期望发 E-FORMAT：结论位仍是占位＝骨架不是交付
python3 -B scripts/check_brief.py scripts/fixtures/good-brief.md   # 期望 PASS：四节齐、逐条挂源、判断词零命中
python3 -B scripts/check_brief.py --selftest                    # 好样须过、四枚坏样须各发它该发的那一道
bash scripts/fixtures/run_fixtures.sh                            # 离线三档一次跑完，末行自报档数与不合枚数
```

## 7. 边界
- 本件只对「这一批来源被逐条挂实地排成一份速览」负责，且只对形制负责：内容对不对要人回原文核。
- 单一来源的场景不要用本件——那是一篇转述；多源互校才是它的用途。
- 需要逐数核口径的深度财报点评走姊妹件；需要成体系的投决讨论稿走投决备忘录那一件；本件只出速览。
