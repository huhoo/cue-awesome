### 0.1.0 — 2026-10-23（建件：一条链接→一条能直接入库的带出处笔记，腿＝解析通道）
- 建因：店里「装别人 skill 前先看一眼」那一类已有大盘，而「读完一篇想留一条笔记、且三年后还敢引用」这一格没有件接——现役各枚要么转整篇格式、要么多源排速览、要么建跨期知识包，「单源纵向钉一条」是空的。选题凭据照榜单现读数：obsidian 11.2 万、weather 17.2 万下载，「零门槛＋通用刚需＋产出可直接入库」这一形就是大盘；我方差异位只写正面能力句——每条都能回到一处带检索日的原文，原话那句还能逐字比回去。（口径按现令：对外报下载数，不把 downloads 说成安装量。）
- 造了什么：四节契约（要点 3–7 条逐条挂 [S#]／至多一枚带定位的原话引用／口径与未取到／来源行带 文件:行号 或 URL 与检索日）、一支四道机检 `scripts/check_note.py`（形制／锚与定位／引用逐字／缺口点名，纯标准库、零网络、判定全集在脚本里）、一支离线起草器 `scripts/make_note.py`（把本地那份正文排成四节骨架，原话逐字摘出并自带定位；不抓链接、不执行被摘录对象的代码）、夹具六枚（好样 1＋坏样 4＋合成原文 1）＋离线三档 runner `scripts/fixtures/run_fixtures.sh`。
- 道三是这枚件的核心形制：加引号那句必须逐字等于所指定定位上的原文，给了 `--source` 就真比——页码比页面块、行号比那一行，**同一行给了两个定位就两个各自比**（只读其一会把假行号放过，这一枚是我自己在反证里撞出来再收严的）。没给原文时这一道明写「不可判」，不并入通过、也不当违例。
- 两条路：主路走解析通道（被摘正文在远端时由宿主 `tools/list` 握手那枚返回里的 `parse`／`get_parse_status`／`read_result` 认已连，本机没有那份文件也能读）；降级只读本地那一份，代价同句写在两面——「远端面文与本地这一份是否一致」那一层整块缺位，缺的是「这条笔记当初摘的是哪一版」那一层证据，不是排版。骨架按设计发红：`make_note.py` 固定留三条不挂锚的待填要点，机检在这一节发 `E-ANCHOR`，骨架不该被当成笔记交付。
- 词表：consumes 用在册的 parsed-doc（解析腿取回的正文正是这一枚），produces 用在册的 source-index 与 structured-note——**未新增任何工件名**。structured-note 的下游已有一枚在消费（ic-memo-cn），所以这枚新件在图上有入边也有出边；同名物另有产方（cn-earnings-note），边只按规范名相等，两枚产同名在本仓口径里合法。
- 反证怎么走：`--selftest` 逐枚断言「码集恰等于该发的那一道」（多发＝坏样不单一，少发＝这道量不到了）；runner 档②再把四枚逐枚单跑一遍并逐行报，另跑一支「好样不给原文」的，验不可判那条形制两个分支都被读。
- 现测：新件硬闸 rc=0（合闸=11 不合=0，TMPDIR=/tmp 跑的）；首屏尺 rc=0（名册=21 不合=0，本件落通道正路的形乙一档＝5 枚之一）；安装式对表 rc=0（名册=21｜①三面现值=20、只在包内其它面=1、未取到=0｜形制点名=0 处）；场景图 rc=0（全包=21｜非孤点=12｜表一 9 枚清单里没有本件）；lint --strict rc=0（末行 21 skill(s), 0 error(s), 0 warning(s)）；卫生闸 rc=0（末行 面 192，ERROR 0，WARN 233）；形状尺 rc=0（0 格不合预期）；发布物闸 rc=0（PASS，成品面指路齐、两枚入口闸内真跑退码 0、体积在闸内）；离线 runner 末行自报「档数=3｜合期望=3｜不合=0｜不可判=0」，在 /tmp、自有临时根、其下子目录三处各跑一遍同一数。道三的两头值另有十枚自供注入逐枚单跑：把行号改成超界／把页码给成别的块／定位指向不存在的文件／同一行只改一个定位，四形都发 `E-QUOTE`；摘掉检索日与把锚指向无源行发 `E-ANCHOR`；要点补到 8 条与缺头部自标发 `E-FORMAT`；正文写缺口而不点名发 `E-COVERAGE`——逐枚「注入生效=是」再判码，不并成一个总数。
