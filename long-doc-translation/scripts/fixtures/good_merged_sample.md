# 产物形态样例：一部合成三篇稿合完的「译著主稿.md」

**这枚文件是什么**：本包四步链（`overlap_check.py` → `qa_check.py` → `dedup_boundary.py` → `merge_build.py`）跑包内好样夹具 `scripts/fixtures/good/` 三片后，`merge_build.py` 落盘的那份主稿原样，一行没改、一字没补——给还没用过的读者看「交回来的东西长什么样」：篇标题、原书页码单独成行、正文、各片脚注、书末新术语总表。
**里面的人物、机构、书名、页码全是合成的**（那部"德文书"与 001/002/003 片都是虚构样件）；本页不含任何真实个人、机构或文件。
**自证整条链（一条命令）**：`python3 -B scripts/check_translation.py --selftest`（零网络、纯标准库；一档就是把这三片走完整条链再逐项断言）。它验的是形制，临时根跑完即删——**这份主稿本体它不留在盘上**，所以下面这四条才是拿到这个文件的走法。
**复跑这份文件本体（四步链，连取根、断言与铺夹具共七行；临时根用 `mktemp -d` 现取一枚唯一名，同机多会话也不互撞，取不到就当场停手，跑完自己删）**：

```bash
RUN="$(mktemp -d "${TMPDIR:-/tmp}/long-doc-translation-sample-XXXXXX")" || { echo "取不到临时根，停手"; exit 1; }
test -n "$RUN" && test -d "$RUN" || { echo "临时根空或不在，停手"; exit 1; }
cp -r scripts/fixtures/good "$RUN/good"
python3 -B scripts/overlap_check.py "$RUN/good"
python3 -B scripts/qa_check.py "$RUN/good" --expect 3
python3 -B scripts/dedup_boundary.py "$RUN/good"
python3 -B scripts/merge_build.py "$RUN/good" "$RUN/merged/译著主稿"
```

**这七行各打什么**（现读逐条，退码全 0）：第 1 行取临时根、第 2 行断言它非空且在场、第 3 行铺夹具，都不打字；取不到临时根时当场停手并退 1，不会带着空路径往下跑。第 4 到第 7 行是四步链：`overlap_check` 9 行、`qa_check` 27 行、`dedup_boundary` 3 行（默认 dry-run，不改盘）、`merge_build` 7 行——先一行 `[提醒] 缺少依赖：pypinyin, markdown`，再报主稿落点。产物只有面文所说那一枚：`"$RUN/merged/译著主稿.md"`，现读 3805 字节；行长有两种口径，两种都给你——`wc -l` 数到 101 行（全文 1553 字符，含首尾空行与末换行），去掉首尾空白后是 99 行、1550 字符，下面这段正文就是按后一种口径贴的，逐字对拍差异 0 行。第 7 行那个参数是**不带扩展名的输出前缀**，`merge_build.py` 自己在后面接 `.md`；把它写成 `译著主稿.md` 会另出一枚 `译著主稿.md.md`，不是这份。同前缀的 `.html` 阅读版只在 `markdown` 依赖在场时才跟着出，这台机器缺，所以那七行里只有跳过提醒、没有第二枚产物。
**为什么正文看着像元话**：夹具正文写的是每一行要满足哪条门禁（句式独一、页边码单独成行、残句照译加省略号、存疑多一条译注），它验证的是流程与形制，不是这部虚构书的内容价值；真稿的形制与此完全一致，只是正文是你自己的译文。
