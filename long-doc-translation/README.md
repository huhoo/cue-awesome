# long-doc-translation

**本文件为中文主面；英文版是同目录下的 `README.en.md`（仓库内查阅用——渠道页不解析相对链接，这里不做可点切换）。**

把一部几百页的外文专著，译成**可交付、可核查、术语统一**的中文全稿。

## 一句话

不是「翻译一段文字」，而是让 100+ 个翻译单元在体例与用词上保持一致，合并后不出现重复、断裂、未译残留。

## 流水线

解析 → 清洗切片 → 建体例与术语表 → 并行分批翻译 → 多维质检 → 合并交付带目录的阅读版

## 适用

- 300 页以上的学术专著、古籍、档案、译著（德 / 英 / 法 / 日等）
- 需要术语全书统一、脚注保留、存疑可追溯

## 依赖

- `python3` + `markdown` + `pypinyin`（核心脚本完全离线运行）
- omni-reader（可选：阶段一「解析」把 PDF / 图片转成文本）

## 脚本（`scripts/`）

`init_project.py` · `dedup_boundary.py` · `overlap_check.py` · `qa_check.py` · `merge_build.py` · `build_reader.py` · `_common.py`

#### 两档上手：简单一档与复杂一档

- **简单一档（单篇、文字层完好、术语要求不严）**：`python scripts/init_project.py <项目目录>` 建骨架，把原文放进 `chunks/` 的上游目录，按 RUNBOOK 走完解析→清洗切片→翻译→合并→三道质检。几十页、单人完成时按 `SKILL.md` 的规模路由走**轻量模式**（`--scale light`）；路由表同时明写：只译几段（< 10 页）**不要用本件**——配置开销大于收益。
- **复杂一档（分栏、图表注、扫描件、需全书术语统一）**：先过解析（优先 omni-reader 一类 OCR 通道），再按原书结构（篇章/页码区间，每片段有且仅有一个归属）切片；随后 `overlap_check.py`（翻译**前**必跑，父集/子集各译一遍会让同段出现两次）→ `dedup_boundary.py`（清相邻片段边界重叠 1–2 段）→ `qa_check.py`（合并前完整性与体例）。实测规模只有一本：Dilthey《施莱尔马赫的生平·第 2 卷》德文 800+ 页、141 片段、边界接缝 32 处——**耗时本包未实测，不给小时数**，规模按片段数与批次数估；分栏与图表按文本片段处理，图内文字层薄则可能漏，未译残留、重复段、页边码连续性三类缺口由三道质检报出（判据与阈值见上条 grep 现值）。

闸分两性质：**包内固定闸**（缺目录即报错退出、片段数对账、TOC 层级、页码连续算法）与**项目配置域**（页边码正则、OCR 错字表、体例三节命名、跳过范围、分组模式与各阈值默认值）。README 与 `SKILL.md`、`references/qa-checklist.md` 里的数字都是镜像与常见例，**不作穷尽断言**——以脚本现值为准。

## 常见问题与反模式（你想这么用 → 本件不接，因为 → 替代去向）

只重组已审清的硬规则、路由表与陷阱文档，不新增承诺；判据与阈值的**全集以脚本现值为准**（上一条 grep）。

| 你想 | 本件接不接，为什么不接 | 替代去向 |
|---|---|---|
| 只译十几段/几页材料，也走这条流水线 | **不建议**。规模路由明写：< 10 页配置开销大于收益 | 直接译；本件治的是「几百页 + 术语全书统一 + 可核查」 |
| 要排版级双语对照出版物 | **不做**。产出是单语主稿 + 阅读版 HTML | 超出范围那一行写在这张表里；对照排版另找工具 |
| 拿扫描图直接切片 | **不接**。没有文字层就没有可校正文 | 先过解析/OCR 出文字层；有对照外文版优先用它 |
| 相邻片段边界重叠先不管，翻完再查重 | **反模式**。父集/子集各译一遍会整段重复，且合并后最难看 | 翻译**前**跑 `overlap_check.py`；已发生的用 `dedup_boundary.py` 清边界 |
| OCR 错字表按全局替换一把梭 | **反模式**。批量替换会误伤译注（那是我们自己写的文字） | 错字映射限定作用域；误伤形状见 `references/pitfalls.md` 陷阱 2 |
| 用字节数当内容长度判重复/规模 | **反模式**。字符数与字节数混用会误判同一段为重复 | 统一按字符数；形状差异见陷阱 4 |
| 子代理并行译完直接合并交稿 | **不接**。并行是允许的，未校验不是 | 每批回来先过质检再合并（`parallel-translation.md` 的批次纪律 + 陷阱 5） |
| 缺 `markdown` 依赖也要出 HTML | **出不了**。主稿 .md 仍可生成，HTML 会失败 | 脚本缺依赖时会提醒安装命令并说明降级后果，不静默出错 |

## 出错了怎么办（症状 → 原因 → 恢复动作）

按各脚本**当前实际出口**写：本件所有脚本不抛 traceback；缺参或路径不存在时打印 `[出错] <原因>` 加若干行
`→ · <修复建议>`，退出码 1（实测：目录不存在一律退 1 并提示查路径/先跑 `init_project`，不会「打印 0 个片段再给一排全绿」）；不带参数运行则打印该脚本的用法块。

| 症状 | 原因 | 恢复动作 |
|---|---|---|
| `[出错] 目录不存在：<路径>` + 三行 `→ ·` 建议 | 路径写错、相对路径相对的是命令行而不是项目目录，或项目还没建 | 按建议逐条排：查拼写与当前目录、含空格加引号、未建项目先 `python scripts/init_project.py <项目目录>` |
| 不带参数运行只打出用法（如 `python qa_check.py`） | 这是**设计**：缺参数按错误退 1，而不是崩 | 看用法块里的必传项；带路径与 `--expect` 复跑 |
| 合并后同一段出现两次（或相邻片段边界重复 1–2 句） | 滑动窗口切片造成父子集重叠，各译一遍 | 翻前 `overlap_check.py`，翻后 `dedup_boundary.py`，再合并；接缝数按实测形状对账 |
| 译注/自写文字里冒出奇怪词 | OCR 错字映射全局替换误伤 | 把映射限定在原文作用域，重跑清洗；已污染的译注手工回校 |
| 页边码 `[S. XXX]` 断裂或不连续 | 切片边界与页码接缝 | 按 `qa_check.py` 报的位置补码；接缝与疑点逐条判（阈值以脚本现值为准） |
| 某片段被跳过却没痕迹 | 跳过范围（前言/附录/图表页）配置与实际结构不符 | 核对项目配置域里的跳过清单与分组模式；该域按项目改，不是包内固定闸 |

## 怎么开口（触发示例：三条正例 + 一条反例）

- **正例（整本委托）**：「把这本 300 页的德文专著译成中文全稿，术语要全书统一，出可核查的主稿和阅读版 HTML」
  ——主场景，走完整流水线；`--expect` 给个预期片段数，三道质检按它对账。
- **正例（复杂输入：扫描件 + 分栏 + 分批并行）**：「底本是 `~/book/dilthey-v2.pdf`，扫描版、有分栏和图注，
  按章切批、每个子代理只译一章、章内不许改结构；合并前先跑重叠检测，接缝处宁可留〔承前页〕标记也别吞掉」
  ——命中复杂一档：解析→按原书结构切片→`overlap_check` →逐章译回→`dedup_boundary` → `qa_check` → 合并；
  耗时未实测，按片段数与批次数估，降级点见上一条两档。
- **正例（几十页档案，只要一份主稿）**：「这 80 页英文档案译成中文，页边码保留，注释里的原文不动」
  ——几十页、单人、术语要求不严时按规模路由走**轻量模式**（`--scale light`）；页边码与残句形状仍按硬规则保留。
- **反例（相邻需求，本件不接）**：「就这一页会议纪要翻成英文，今晚要」→ 规模路由明写 < 10 页不要用本件；
  「这本译稿要做成对照排版的印本」→ 超出范围（本件只出单语主稿 + 阅读版 HTML）；
  「顺手判断这段史料真伪」→ 属考证/深研，另走别的件。
