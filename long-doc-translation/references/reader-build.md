# 增强阅读版（build_reader.py）

> 本文件是 SKILL.md §六· 的完整版。`merge_build.py` 产出「能看」的基础 HTML；`build_reader.py` 产出读者真正用得顺手的增强版。

两者**共用同一份 `merge_build` 逻辑**（脚注上标换算、页码锚点、pypinyin 术语排序、存疑抽取），不在 reader 里另写一份，避免两份实现漂移。

## 能力

- **脚注双向跳转**：正文上标 `⁷` 点击跳到注文，注文编号点击返回正文（按片段隔离编号，仅链接可配对项，避免死链）。
- **全文搜索**：TreeWalker 遍历文本节点，高亮命中 + 上/下一处 + 快捷键 `/` 聚焦、`n`/`p` 切换、`Esc` 清除。
- **原书页码跳转**：输入 `537` → 定位〔S. 537〕；无精确页时落最近页并提示。
- **目录高亮**：`IntersectionObserver` 随滚动高亮当前章，层级可折叠。
- **阅读设置（localStorage 记忆）**：字号 `A−/A＋`（13–32px）、行宽、`大字` 老年友好模式（字号 ≥ 23px + 行距 2.2 + 加宽 + 放大顶栏控件）、**主题循环 日间 ▸ 护眼 ▸ 夜间**（护眼 = 柔和豆沙绿降低眩光，夜间 = 深色）。

## 关键工程决策（下次直接照做，别再摸索）

1. **单文件自包含**：CSS / JS 全部内联，不引外部 CDN / 字体 / 图片 → 一个 `.html` 离线可用、可直接微信 / 邮件发给任何人。文件名用中文无妨。
2. **术语表按拼音排序**：用 `pypinyin.lazy_pinyin` 对中文主词排序，西文条目按拉丁字母排并置于末尾；**不要**按 Unicode 码点排（中文会乱序）。
3. **页边码正则要宽**：`〔S\.\s*(\d{1,3}|[IVXLCDM]{1,8})(?:\s*(?:续|末|f{1,2}))?\s*〕` —— 同时覆盖阿拉伯数字（正文）与罗马数字（前处理 / 目次），并兼容 OCR 变体「… 续 / 末」。
4. **脚注 id 唯一**：同一编号在正文多次引用时，用 `n-{name}-{n}-{k}` 计数后缀避免 `id` 重复；正文未实际引用某编号（OCR 脱落）时注文不生成返回链接，避免死链。
5. **中文默认字号 18px 起**，正文用衬线（宋体 / 思源宋体），强调用 `**粗体**` 对应原版 Sperrdruck。

## 用法

```bash
python merge_build.py [chunks_dir] [out_prefix]   # 先出主稿
python build_reader.py                            # 再出增强阅读版
```
路径用环境变量 `LB_BASE` 指定工作根（默认当前目录）；输出 `output/译著阅读版.html`。

## 依赖与降级

| 依赖 | 用途 | 缺失时 |
|---|---|---|
| `markdown` | 主稿 → HTML | **主稿 .md 仍生成，HTML 跳过**（脚本明确提示安装命令） |
| `pypinyin` | 术语表按拼音排序 | 术语改按 Unicode 排序（中文会乱序），其余功能不受影响 |

脚本缺依赖时会明确提醒并说明降级后果，**不会静默出错**。
