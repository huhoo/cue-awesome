# 并行翻译策略

> 本文件是 SKILL.md §四 的完整版。核心约束：**批次严禁重叠，每片段有且仅有一个写者**。

## 1. 分片原则

按原书结构（篇章 / 页码区间）划分批次，**每片段有且仅有一个写者**，批次严禁重叠。
重叠的代价不是"多译一遍"那么简单——合并后整段重复极难在通读时发现（见 `pitfalls.md` 陷阱 1）。

## 2. 主线程 + 子代理

主线程译一批（保证体例样板），同时派子代理译其他批。子代理提示词**必须包含**：

1. 必读 `TRANSLATOR_BRIEF.md` + `glossary/DE-EN-ZH.md` + **1 篇紧邻的已译样本**（保证风格衔接）；
2. 明确的残句接续说明（上一片末尾残句 + 本片起首如何拼接）；
3. 「只写分配给你的文件，不要改动任何其他文件」。

## 3. 频率限制（429）

限制期内主线程手动逐片译；恢复后改小批量并行验证可用再放大。

## 4. 子代理产出验收（必做）

- 查空文件 / 占位文件（`< 15 行`）；
- 抽查每个子代理至少 1 篇译文的**头 25 行**，确认体例正确（页边码、承前页、脚注、粗体）；
- **读子代理的自述**：它们常自报问题（如「024 与 023 内容近乎全同」），这是发现整段重复的关键线索。

## 5. 顺序不可颠倒

**阶段 3（建体例与术语表）必须在阶段 4（翻译）之前**。
边译边定体例 = 全书体例漂移，后期返工量巨大。
