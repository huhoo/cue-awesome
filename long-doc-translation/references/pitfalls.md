# 五大陷阱（实战踩过，代价最高）

> 本文件是 SKILL.md §三 的完整版。每个陷阱都写明：怎么发现、怎么修、怎么预防。

## 陷阱 1：切片窗口重叠 → 译文整段重复（最隐蔽、危害最大）

长文本按字符数或页面滑动窗口切片时，**相邻片段边界会重叠**。
实战案例：024 是 023 的**子集窗口**，两者各译一遍 → 12 页内容在合并稿里出现两次；022 还逾界译入属 023 的 8 页。

- **检测**：从每个译文提取页边码 `〔S. N〕` 的首尾，比较相邻片段 `本片首 ≤ 上片尾` 即重叠。
  ```bash
  python scripts/overlap_check.py output/chunks
  ```
- **修复**：保留**超集**那一片为正本；把子集的**独有内容**（术语条目、独有注解）并入超集；子集移入 `output/chunks/_redundant/`（不参与合并，可恢复）。
- **预防**：切片时显式记录每片起止页码，杜绝滑动窗口重叠；若工具强制重叠，切片后先跑 `overlap_check.py` 再开工翻译。

### 1b. 句级边界重复（更常见、更易漏）

即使不是整段子集，相邻片段也常在边界重叠 **1–2 句**——A 片末尾译了，B 片开头又译一遍（实战 8 处）。页码级检测看不出来，要靠 `qa_check.py` 的【6】重复行检测发现。

```bash
python scripts/dedup_boundary.py <chunks_dir>           # dry-run，只报告
python scripts/dedup_boundary.py <chunks_dir> --apply   # 确认后修复
```

策略：保留 A 的完整译文，删 B 开头的重复段；若重复行**带页边码**，只保留页边码、删句子（页码是核校锚点，不能丢）。

**⚠ 删除前必须排除「结构性重复」**：源文本身可能有文字相同的两处**不同成分**——如著作**纲要条目**的「I. xxx」与正文中舒展字体的**正式节标题**「I. xxx」（实战 052 即此，两处各自独立，读了源文才敢判定）。
**判据：回查源文 .txt 确认该句是否真出现两次**，不可见重复就删。

### 1c. 检测脚本自身的静默失效（v1.3.0 修复）

「报告全绿」不等于「真的检查过」。已发现并修复的两种静默失效模式：

| 失效模式 | 现象 | v1.3.0 的处理 |
|---|---|---|
| `overlap_check.py` 分组退化 | 文件名不匹配 `部_篇_编号`（如纯数字 `001.md`）时，旧版让**每个文件自成一组** → 组内仅 1 片 → 一次相邻比较都没发生，却打印「✅ 未发现重叠」 | 退化为统一组做全序列比较；无文件匹配命名模式时打印提醒；**实际比较次数为 0 且片段数 > 1 时改为告警并 exit 3**（不再假绿） |
| `dedup_boundary.py` 短行阈值 | `MINLEN = 15`：短于 15 字符的行不参与重复判定 | 保留阈值（短句误判率高），但已在本文档与 `qa-checklist.md` 写明——**短句重复需人工看边界** |

**使用原则**：看到告警行（命名模式提醒 / 「仅 1 片，无相邻片可比较」/ exit 3）时，先按提示处理再放行，不要只看最后一行 ✅。

## 陷阱 2：OCR 错字批量替换误伤译注

译注里常写「原文 `ζ.B.` 应为 `z.B.`」——**这是正确内容**，全局替换会把纠错说明一起改掉。

- **解法**：逐行判定该行是否位于 `#### 原注/译注/新术语` 区内，只替换**区外（正文）**的错字。见脚本 `note_flags()` 逻辑。
- 常见错字映射（德文，按实际底本扩充）：`Sdiell→Schell`、`Erkentnis→Erkenntnis`、`ζ.B.→z.B.`、`Audi→Auch`、`Venunflsystematik→Vernunftsystematik`、`§SO→§50`；上标数字易错（`2e→26`、`2»→29`、`18` 拆成 `¹⁸/¹⁹`），需据页底注文校正归位。

## 陷阱 3：合并后跨片段标题重复

各片段为自洽常重标章名（如「第二章（续）」）→ 目录里同一章出现几十次。

- **解法**：按**同级标题**比较去重（不能用「前一个标题」，中间会夹 `###`/`####` 子标题），且**排除 `#### 原注/译注/新术语`**（level 4 本就每片重复，必须保留）。

## 陷阱 4：字符数 vs 字节数混淆 → 误判内容重复

`wc -c` 是**字节**（UTF-8 中文 ×3），`len(str)` 是**字符**。228 万字节 ≈ 76 万字符，看着像「重复了 3 倍」其实正常。**对比体量时统一口径**。

实战实测：95.8 万字符 / 228 万字节，1 字符 ≈ 2.4 字节（正文夹大量德文引文、数字与标点，**不能**按「中文 3 字节」折算）。

## 陷阱 5：子代理产出未校验

- 必查空文件 / 占位文件（如 `< 15 行`）；
- 抽查每个子代理至少 1 篇译文的**头 25 行**，确认体例正确（页边码、承前页、脚注、粗体）；
- 子代理常**自报问题**（如「024 与 023 内容近乎全同」）——这些自述是发现陷阱 1 的关键线索，**务必读子代理的回报**。
