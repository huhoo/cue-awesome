# 质检清单与阈值口径

> 本文件是 SKILL.md §五 的完整版，含脚本判定阈值——阈值不知道，就分不清「真没问题」和「根本没查」。

## 跑法

```bash
python scripts/qa_check.py output/chunks                 # 自动计数
python scripts/qa_check.py output/chunks --expect 141    # 指定预期片段数
```

## 七项检查

| # | 检查项 | 合格标准 |
|---|---|---|
| 1 | 片段完整性 | 译文片段数 == 切片数（或差异有 `_redundant` 解释） |
| 2 | 体例三节 | 每个片段含 `#### 原注` / `#### 译注` / `#### 新术语` |
| 3 | 未译残留 | 正文无「> 60 字符且无中文」的整行外文（书目 / 广告页除外，应保留原文） |
| 4 | OCR 残痕 | **正文区**错字数 == 0（注释区豁免） |
| 5 | 页边码连续 | 全稿页码无断档（罗马 / 阿拉伯分段各自连续） |
| 6 | 重复段 | 正文关键句出现次数 == 1（术语表 / 附录内重复属正常） |
| 7 | 目录干净 | HTML TOC 仅含 2–3 级标题，无 `原注/译注` 杂项 |

## 脚本阈值（CONFIG 区可改）

| 脚本 | 参数 | 默认 | 含义 / 影响 |
|---|---|---|---|
| `qa_check.py` | 未译残留判定 | 行长 > 60 字符且无中文 | 更短的外文行不报（多为专名、引文片段） |
| `qa_check.py` | 占位文件判定 | 行数 < 15 | 疑似未译 / 占位，需人工看 |
| `qa_check.py` | 页边码断档分级 | 缺 1–3 页 = 正常接缝；> 3 页 = 断档 | 接缝不阻断交付，断档要查 |
| `dedup_boundary.py` | `MINLEN` | 15 | **短于 15 字符的行不参与重复判定**——短句边界重复要靠人工 |
| `dedup_boundary.py` | `SCAN_HEAD` | 60 | 只扫描 B 片开头 60 行（重复只可能出现在开头） |
| `overlap_check.py` | `GROUP_RE` | `^([A-Za-z0-9]+_[A-Za-z0-9]+)_` | 按「部_篇」分组；**不匹配时退化为全序列比较**（v1.3.0 起） |
| `overlap_check.py` | `SKIP_REVERSED` | True | 首页 > 尾页视为索引 / 引用型，跳过比较 |

## 页边码正则（别写窄）

```
〔S\.\s*(\d{1,3}|[IVXLCDM]{1,8})(?:\s*(?:续|末|f{1,2}))?\s*〕
```
同时覆盖阿拉伯数字（正文）与罗马数字（前处理 / 目次），并兼容 OCR 变体「… 续 / 末」。

## 修复动作对照

| 报告项 | 修复 |
|---|---|
| 【2】体例三节缺失 | 文件末尾补 `#### 新术语` + `（无）`；缺原注则插在译注节之前 |
| 【3】未译残留 | 确认是否书目 / 广告页（应保留原文），否则补译 |
| 【4】正文 OCR 残痕 | 按错字映射表替换，**只改正文区**（注释区的纠错说明要保留，见 pitfalls 陷阱 2） |
| 【6】重复段 | `dedup_boundary.py`，先 dry-run；删除前排除结构性重复 |
| 【7】空文件 | 重译或确认该片本就无内容 |

## 交付基线（实战实测，可作同类项目预期）

合并后实际修掉的问题：
- 整段重复 2 处（022/023、023/024，子集窗口，约 20 页冗余）；
- 句级边界重复 8 处（每处 1–2 句，源切片边界重叠）；
- 体例三节缺失 11 个文件（多为缺「新术语」节，补「（无）」即可）；
- 正文 OCR 残痕 5 处（`ζ.B.` → `z.B.`）。

## 已知轻微接缝（如实列在交付说明里）

切片边界不可避免会有 1–3 页的页码接缝（实战 32 处），以及 > 3 页的疑似断档（12 处，多为原书图表页或无页边码页）。**逐处强改代价高、收益低**，建议交付说明中如实列出，交由使用者据底本核对。
