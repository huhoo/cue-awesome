# 股东回报八项名目与要素

## 一、八项名目与要素

| 项名 | 要读到什么才算取到 | 真实公告里的别名 |
|---|---|---|
| 分红方案与每股派息 | 每股（或每 10 股）派发的现金红利金额，含税/税后口径 | 利润分配方案、权益分派方案、分红派息方案 |
| 分红总额与分红率 | 本次现金分红总额；分红率（占归母净利润比例）只登记不换算 | 现金分红总额、派息总额、分红比例 |
| 股权登记日与除权除息日 | 两个日期，缺一即缺 | 登记日、除息日、除权除息日 |
| 回购方案与回购规模 | 拟回购股份数量或回购资金总额（二者其一即可） | 股份回购方案、回购股份方案 |
| 回购价格区间与资金来源 | 回购价格上限（或区间）与资金来源 | 回购价格、价格上限、自有资金/自筹资金 |
| 回购用途与注销安排 | 回购来的股份干什么：注销、员工持股、可转债 | 回购股份用途、注销安排 |
| 减持计划与减持主体 | 谁在减、减多少、什么方式、什么期间 | 股份减持计划、股东减持计划 |
| 质押与解押情况 | 质押/解押的股数与主体 | 股权质押、解除质押、股份质押 |

## 二、两格数字的四类顶替写法

机检 `SR-VALUE` 只认本项自己的名词，下面四类写法会被判缺：

1. **参照数顶替**：`公司总股本 5.00 亿股` 不是派息值；`前 20 个交易日交易均价 11.80 元/股` 不是回购价格上限。
2. **比率顶替**：`本次分红占归母净利润的 25%` 的 25% 是比率，不是分红总额。
3. **分母顶替**：`每 10 股派 3.50 元` 的 10 是分母，不是派息值（机检先掩分母再判）。
4. **日期顶替**：`2026 年 6 月 12 日` 是登记日，不是任何金额。

## 三、与员工持股条款速读的切割线

| 维度 | 本件（股东回报） | 员工持股条款速读 |
|---|---|---|
| 面向对象 | 全体股东 | 参与计划的员工 |
| 公告类型 | 权益分派、回购、减持、质押 | 员工持股计划草案 |
| 核心数值 | 每股派息、分红总额、回购规模、回购价格 | 受让价格、受让规模、锁定期 |
| 判断边界 | 不判回报水平与股价影响 | 不判参与建议与税务 |

## 四、与本套件其它枚的分工线

- 与「公告速读」类：本件只碰股东行为四组，其它公告类型不接。
- 与「财报速读」类：本件的分红率只登记公告自己写的比例，不自己用净利润反算。
- 与「笔记类」：本件产出 `structured-note`，可被下游笔记与备忘录类消费。

### 与 `event-brief-cn`（公告事件速读卡）的切割线

这一条要写清楚，因为两枚的射程**有交叠**，不是「现役完全没有」：

| 维度 | 本件 | `event-brief-cn` |
|---|---|---|
| 一份公告 | 只接股东行为四组（分红／回购／减持／质押） | 接十类临时公告（回购、增减持、业绩预告、重大合同、分红送转、停复牌、处罚问询、股权变动、资产减值、其他） |
| 一份卡 | **八项并列**，四组股东行为同卡 | **单选一类**（机检 `E-FORMAT` 明判「类型勾选 N 处（规格：单选）」，勾两类即红） |
| 数值归属 | 短语结构体机器：本格名词 vs 参照数族，`每 N 股` 分母掩码 | 无数字归属机器（`NUM_CELLS`／`build_phrases` 零命中），关键数只要求逐字带锚 |
| 齐缺对账 | 头部「共八项·缺 N 项」与「未检索到」项数对账 | 无齐缺对账 |
| 用途 | 一家公司四组股东行为并到一张卡上看 | 一份公告先看讲什么、影响链候选、同类对照 |

**所以分工是**：问「这一份公告讲什么」→ `event-brief-cn`；问「这家公司分红回购减持质押各是什么情况」→ 本件。
两枚的 triggers 有交叠（`event-brief-cn` 已含「回购公告／增减持」），交叠处按**问法**分：
单份公告速读走那一枚，多组股东行为并卡走本件。

## 五、书名号豁免的射程

项行的书名号内若是**纯引注**，该段不进红线判据域。四个条件同时满足才算纯引注：

1. 该行有 `锚：`；
2. 书名号外侧只剩引注标签（来源名词、报道动词、定位词、引号标记）或什么都不剩——**说明／注不算引注标签**；
3. 书名号内若有 `短标签：`，该短标签自己也得是引注标签；
4. 书名号内不得出现本件自指（本件／本卡／本速读／笔者）。

自指按**前一字类**认，不按子串：前一字是非汉字（句首、标点、引号、数字）或在虚词表内才算；
`样本件`／`基本件`／`成本件`／`副本件` 这类复合词尾不算；`本 件`／`本　件`／`本\t件` 经空白归一后算。

**已知覆盖缺口（如实写）**：前一字不在虚词表内的写法（`通过本件判断`／`围绕本件`／`经过本件`／`仍本件认为`）
检测不到，会保持绿。这是首版已知缺口，不是设计意图。
