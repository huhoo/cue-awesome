# 股东回报全景卡

把一份 A 股股东回报公告（权益分派实施公告、回购方案、减持计划、质押公告）拆成**八项逐字卡**：
每项只登记公告自己写的原句与锚，不评价、不预测、不代办。

**切割句**：本件只做「公告说了什么」的逐字登记与缺项点名；**回报水平好不好、股价会怎么走、该不该买卖，一律不判**。

## 0. 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 八项股东行为的原句登记卡 | 投资建议或买卖评级 |
| 每项挂锚，可回原文核对 | 回报水平／股息率高低的评价 |
| 缺项进缺数清单，缺几项报几项 | 用参照数（净利润、总股本、交易均价）顶替本项数值 |
| 分红／回购／减持／质押四组并列 | 只挑好看的那一组写 |

## 1. 触发场景

- 用户给一份权益分派实施公告，问「这次分红到底怎么算、每股多少、什么时候登记」。
- 用户给一份回购方案，问「回购多少、什么价、回购来干什么」。
- 用户给一份减持或质押公告，问「谁在减、减多少、质押了多少」。
- 用户一次给多份，要把同一家公司的股东行为并到一张卡上看。

## 2. 取数纪律

1. **只登记原句**：每项的书名号里放公告原文，不放转述、不放概括。
2. **每项必挂锚**：锚写清出处（公告第几节、第几页、哪张表），锚值不得为空。
3. **缺就写缺**：取不到写「未检索到」，并在缺数清单点名缺什么、要回哪份文件核对；**不许写「无该项」**。
4. **齐缺对账**：头部「共八项·缺 N 项」只写一处，N 必须等于速读段里「未检索到」的项数。
5. **数值只认本项自己的名词**：`每 10 股派 3.50 元` 里的 10 是分母不是派息值；`占归母净利润的 25%` 里的 25% 是比率不是分红总额。
6. **比率与送转只登记不结算**：分红率、股息率、转增送股比例照原句抄，不换算成金额。
7. **判断留人工**：回报水平、股价影响、减持是否利空、质押风险，全部进「待人工」。

## 3. 输出契约（股东回报卡五段）

```
## 一、头部申报
- 文件：<公司> <公告名>｜来路：官方原文／用户直供｜附件腿：已发起／未发起
- 共八项·缺 N 项

## 二、八项逐字速读
- 分红方案与每股派息：「<原句>」 锚：<出处>
- 分红总额与分红率：「<原句>」 锚：<出处>
- 股权登记日与除权除息日：「<原句>」 锚：<出处>
- 回购方案与回购规模：「<原句>」 锚：<出处>
- 回购价格区间与资金来源：「<原句>」 锚：<出处>
- 回购用途与注销安排：「<原句>」 锚：<出处>
- 减持计划与减持主体：「<原句>」 锚：<出处>
- 质押与解押情况：「<原句>」 锚：<出处>

## 三、口径对照
- 本卡以<哪份>原文为准；<第二处披露>是否取到，两份齐不齐，口径判不判。

## 四、缺数清单
- 缺 N 项：<名目>——<缺什么>，需回<哪份文件>核对。

## 五、待人工
- [待人工] <回报水平／股价影响／减持利空／质押风险> 全部留人工；本件不接代办。
```

八项名目在真实公告里有别名（「利润分配方案」「权益分派方案」「股份回购方案」「股份减持计划」等），
卡面写哪个别名都认，机检按 canonical 名归位。

## 4. 数据通道（以 live catalog 现值为准）

真实任务走通道正路：先看目录，再按工具名取原文与附件正文。

```bash
curl -s https://cuecue.cn/api/mcp-catalog | head -c 2000
```

拿到端点后按 MCP 协议发 `tools/list`，确认 `parse` / `get_parse_status` / `read_result` 三枚在场，
再用 `parse` 把公告 URL 或本地路径交给通道，`get_parse_status` 轮询，`read_result` 取正文与表格。

**零 key 降级**：没有 `CUE_API_KEY` 时本件只走用户直供的公告正文与本地文件，
代价是**取不到渠道侧的披露原文与附件正文解析**，锚只能落在用户给的那份上，跨文件核对做不了。

## 5. 合规红线（随套件）

- 不评价回报水平（分红率高低、回购力度够不够、股息率划不划算）。
- 不预测股价与市值影响（回购能否提振股价、减持是否利空）。
- 不给买卖建议（买入／卖出／增持／减持／持有）。
- 不代拟公告、不代算税、不代客申报。
- 不碰内幕信息，不给绕开审议或规避披露的做法。
- 不裁断效力（方案是否有效、是否违规、是否构成承诺）。

## 6. 快速流程（用户视角）

1. 把公告（URL 或本地文件）交给本件。
2. 本件按八项逐字登记，每项挂原句与锚。
3. 取不到的进缺数清单，点名要回哪份文件。
4. 判断类问题全部进「待人工」，本件不接。

## 7. 机检

```bash
python3 -B scripts/check_sh_return_card.py <卡面.md>     # 五道码逐条发红，全过则 PASS
python3 -B scripts/check_sh_return_card.py --selftest    # 好样须过、坏样五道齐发
bash scripts/fixtures/run_fixtures.sh                    # 离线样例三档（零网络零计费）
```

五道码：`SR-STRUCT` 五段齐且八项行级在场／`SR-QUOTE` 原句与锚不得为空／
`SR-LINE` 红线断言三道／`SR-COUNT` 齐缺申报恰一枚且与「未检索到」对账／
`SR-VALUE` 两格数字按短语结构体归属。
