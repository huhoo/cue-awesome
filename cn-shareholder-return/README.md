# 股东回报全景·分红回购减持

把一份 A 股股东回报公告拆成八项逐字卡：分红、回购、减持、质押各挂原句与锚，缺的进缺数清单，判断留人工。

## 一、打开就干：今天这三步

1. 把公告（URL 或本地文件）交给本件。
2. 本件按八项逐字登记，每项挂原句与锚。
3. 取不到的进缺数清单，判断类问题全部进「待人工」。

## 二、五道机检（零网络）

```bash
python3 -B scripts/check_sh_return_card.py <卡面.md>     # 五道码逐条发红，全过则 PASS
python3 -B scripts/check_sh_return_card.py --selftest    # 好样须过、坏样五道齐发
bash scripts/fixtures/run_fixtures.sh                    # 离线样例三档（30 秒、零网络零计费）
```

| 码 | 判什么 |
|---|---|
| `SR-STRUCT` | 五段齐；八项名目在速读段内**行级在场**（每枚一行，只在散文里提到不算） |
| `SR-QUOTE` | 每项书名号内原句不得为空或只剩单字；「锚：」在而锚值为空同样发 |
| `SR-LINE` | 红线断言三道：定式禁词／主题词×判断语气同段／自裁效力层 |
| `SR-COUNT` | 齐缺申报恰一枚，且 N 等于速读段「未检索到」的项数；「无该项」一律发 |
| `SR-VALUE` | 两格数字按短语结构体归属，参照数更近即剔，比率与送转不结算 |

## 四、首次开通 Cue（三步，可跳过）

1. 在 cuecue.cn 注册并拿到 `CUE_API_KEY`。
2. 导出到环境：`export CUE_API_KEY=...`。
3. 连通自查：

```bash
# 1) 看目录，拿端点
curl -s https://cuecue.cn/api/mcp-catalog | head -c 500

# 2) 按 MCP 协议握手，确认三枚工具在场
curl -s -X POST "$MCP_ENDPOINT" -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

**不装也能跑**：没有 key 时本件只走用户直供的公告正文与本地文件，代价是取不到渠道侧的披露原文与附件正文解析，锚只能落在用户给的那份上，跨文件核对做不了。

## 五、边界与不承诺

- 不评价回报水平（分红率高低、回购力度够不够、股息率划不划算）。
- 不预测股价与市值影响（回购能否提振股价、减持是否利空）。
- 不给买卖建议。
- 不代拟公告、不代算税、不代客申报。
- 不碰内幕信息，不给绕开审议或规避披露的做法。
- 不裁断效力（方案是否有效、是否违规、是否构成承诺）。

## 六、出错了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `SR-STRUCT 缺段` | 五段标题被改名或漏写 | 按 §3 输出契约的五段标题原样写 |
| `SR-STRUCT 速读段内缺名目行` | 名目只在散文里提到 | 每枚名目单独一行，以 `- 名目：` 起头 |
| `SR-QUOTE 书名号内原句为空` | 抄成了概括或留空 | 回原文抄原句，不许转述 |
| `SR-COUNT 齐缺申报须恰一枚` | 头部写了两处，或一处没写 | 只留一处「共八项·缺 N 项」 |
| `SR-COUNT 齐缺申报缺 N 项…` | N 与「未检索到」项数不符 | 数一遍速读段里几项写了「未检索到」 |
| `SR-VALUE 缺要素` | 该格只有参照数（净利润、总股本、交易均价） | 回原文找本项自己的名词与数值 |
| `SR-LINE 定式禁词` | 写了评价、预测或建议 | 删掉，改成原句登记或进「待人工」 |

## 七、怎么开口（正例与反例）

**正例**

- 「这份权益分派实施公告，每 10 股派多少、什么时候登记？」
- 「这份回购方案，回购多少股、什么价、回购来干什么？」
- 「这家公司今年分红和回购都做了，帮我并到一张卡上。」

**反例**

- 「这次分红划不划算？」→ 本件不判回报水平，只登记原句。
- 「回购之后股价会涨吗？」→ 本件不预测股价。
- 「帮我写一份减持公告。」→ 本件不代拟公告。

## 八、能力边界（诚实清单）

- 判的是**同一短语内的相邻关系加一次跨短语继承**，不声称覆盖所有自然语言的归属表达。
- 同位式共指（系词在两个名词之后）与「价格待定但数量已定」的同段共存式在已知覆盖不到之列，按严格式发红，请人工回原句核对。
- 八项名目按别名族认，别名表在 `scripts/check_sh_return_card.py` 的 `ITEM_ALIASES`；遇到新写法要加别名，不是改判据。
