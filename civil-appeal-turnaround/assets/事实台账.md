## 五、自认识别记录

| 陈述原文 | 情形 | 定性 | 可用写法 |
|---|---|---|---|
| | 明确答"对" | 自认 | "明确答以'对'，构成承认" |
| | 面对询问径行答以他事 | 默认 | "未作任何否认，径行答以……，以默认方式承认" |
| | 表示需向公司核实 | 表明由其持有 | "该陈述表明其处存有……（据此申请责令提交）" |
| | 表示不知情、不认可（金额） | 不等于否认归属 | "其所称不认可，针对的是债务本身，并非对行为归属的否认" |
