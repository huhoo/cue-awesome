# 07 · 脱敏实例：一份走通全流程的样本

> 本实例已脱敏：当事人、企业、项目名称、案号、联系方式均已替换或概括。保留的是**流程与判断**，不是案情。

> **按门牌读**：`Phase 0 / Phase 6` → **todo**（`05`）｜`Phase 1` → **盘点**（`01`，含三面归置）｜`Phase 2 / Phase 5` → **搜集**（`02` + `05` §八 §九）｜`Phase 3` → **盘点**后半段（`03`）｜`Phase 4` → **查证**（`04`）。
> 下文沿用 Phase 编号是为了与判决书到文书的时间顺序一致；若要按四个动词推进，用上表换算即可。

## 背景

购房人经一名经纪人员促成购房，该人员承诺返还佣金 20 万元（约为其所得佣金的一半）。购房完成后未兑现。购房人起诉该经纪人员所属的经纪机构。

- 一审：**被告缺席、一名第三人（大型经纪机构）到庭并有律师**、另一名第三人（行为人本人）缺席
- 结果：**驳回全部诉讼请求**
- 判决推理：协议无签章 → 不成立书面合意 → 行为人的承诺"属于以自己或他人名义作出" → 不能证明表见代理 → 无证据证明公司追认 → 驳回

## Phase 0 · 收口

| 动作 | 结论 |
|---|---|
| 确认送达日 | 落款日次日起算 15 日，得死线日期 |
| 保全状态 | 已保全 20 万元，但一审驳回后面临解冻 → **《继续保全申请书》列为最高优先级** |
| 代理人现状 | 决定自行诉讼 → 必须书面解除委托、变更送达地址、**删除上诉状中律师署名行** |

## Phase 1 · 逆向工程：五层根因

| 层级 | 发现 | 在判决中的痕迹 |
|---|---|---|
| **框架层** ★ | 争点被框为"行为人有没有代理权"，按此框架举证责任在原告，而所需证据（授权书、劳动合同、社保）**全部在被告手中且被告缺席** | "本院认为"首句即框定"以自己或他人名义" |
| **法律层** | 判决仅适用无权代理条款；**职务代理、表见代理、以行为追认三条路径一条未审** | 判决末尾条文清单可作比对 |
| **证据层** | 三个决定性事实未入视野：①行为人携带公司公章到场——**"公章"在认定与说理部分出现 0 次**；②录音中"用公司账户打给你""不是某公司的账户，就是我们公司的小公司的账户"——**摘录至前一句即打省略号**；③对方股东的三项自认与离职时间——只认定了其中一项 | 关键词出现次数统计 |
| **程序层** | 判决自己写了"不利后果由其自行承担"，但驳回理由全是被上诉人才会提的抗辩；未责令被告提交其掌握的招用记录 | 判决第 5 页 |
| **庭审层** | 唯一到庭的第三人当庭说了三句对自己不利的话（与被告有合作、被告是推荐方、卷宗某页载有双方均已认可行为人为被告员工），**判决照录了陈述，说理部分只字未提** | 判决第 3 页 vs 第 5 页 |

**结论：这不是"证据不足"，而是"框架被框错 + 三条路径漏审 + 关键事实未入视野"。**

## Phase 2 · 逐字比对（节选）

| 证据 | 原始材料 | 判决摘录 | 差异类型 | 影响 |
|---|---|---|---|---|
| 通话录音 A | "……您到时候给我一个卡号，**然后公司我用公司账户打给你**" | "……您到时候给我一个卡号……" | **截断** | 付款主体归属 |
| 通话录音 A | "不是某公司总部的账户，就是我们公司的小公司的账户" | 未出现 | **省略** | 直接排除"以他人名义"中的他人 |
| 通话录音 B | "（问：他是你们的房产经理吗）他离职了有半个月了" | "称其原系公司职员，已经离职" | **割裂** | 只认定"已离职"，未认定"原系公司职员"与默认 |
| 通话录音 B | （问：对方也给你们打钱了吧）"对" | 未出现 | **省略** | 已收取款项 = 以行为追认 |

**关键判断**：判决疑似只接触到转文本节选 → 二审动作＝提交**带原页码的完整转文本** + **申请当庭播放原始载体** + 申请开庭审理。

## Phase 3 · 阶梯

```
第一层　职务代理（主攻，不需新证据）
   ↓ "纵使二审法院认为……"
第二层　表见代理（备位，不需新证据）
   ↓
第三层　以行为作出的追认（需调取款项凭证）
   ↓
第四层　利益归属 / 不当得利（需释明）
```

| 层级 | 关键论据 | 等级 | 判决漏了什么 |
|---|---|---|---|
| ① 职务代理 | 协议甲方为公司（**判决已认定**）、公章、股东自认、第三人指认、**离职时间晚于办案时间约四个月** | A + B | 完全未审，条文清单中没有 |
| ② 表见代理 | 公章＝最强外观；**公开查询渠道实测为零 → 相对人无从核实**；可归责性＝公章由其交付 + 未依法建立业务记录 | A + B | 只一句"不能证明"，三项要件一项未审 |
| ③ 以行为追认 | 股东对"对方也给你们打钱了"答"对"（诉前录音） | B | 款项到账事实只字未提 |
| ④ 利益归属 | 二难：若基于合作协议取得 → 即证明其为执行工作任务；若无依据取得 → 无法律上原因且违规 | C（需凭证） | 未就法律关系性质作为焦点审理 |

## Phase 4 · 台账与更正机制

**一处真实教训**：案涉项目有四个指称（备案名／最早推广名／后改推广名／庭审简称）。其中"最早推广名"的定性经历了三版演变：

1. 初版误记为"曾用名"
2. 二版误定为"另一楼盘"，并据此构建了一整段"跨项目引流 → 只有渠道机构人员才会多盘作业"的论证
3. 三版经当事人纠正 + 网络核实（多个房产平台载明"别名"关系、同一开发商、同一预售证）确认为**同一项目的最早推广名**

**处置**：

- 全库检索四种指称的所有表述形式，逐处更正
- 在更正处留痕："前一版结论已作废"
- **连带推翻**依赖"另一楼盘"定性的整段论证，改写为"以案涉项目名义公开招揽"
- 红线清单新增："禁止再出现跨项目／跨盘／他盘字样"
- 调证申请的检索口径由两个名称升级为**三个名称同时检索**

**教训**：若不更正，那段论证一旦进入上诉状，对方一句话即可击破，并连带损害全案可信度。

## Phase 5-6 · 文书与待办

- 上诉状新增**总述**（一页内：一个争点 + 判决自认的四项事实 + 三项致命错误）
- 修正形式硬伤：理由编号重复与跳号、代理人署名、第三人的"证人"表述改为"传唤当事人到庭接受询问"
- 配套文书与上诉状**同日递交**，继续保全另交一审承办法官
- 待办按 T+0／T+1~3／T+4~7／死线 重排，钱 > 期限 > 证据

## 该案最值得复用的一句话

> **先用不需新证据的层级把"撤销原判"拿下，再用需新证据的层级把"查清事实"做实。**
