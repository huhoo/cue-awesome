# 01 · 判决逆向工程

> **门牌锚点**：动词 **盘点** · Phase 1（后半段 Phase 3 见 `03`） · 落点 `assets/判决书拆解表.md` + `assets/败诉三面表.md`
> **读到哪为止**：本节只解决「败在哪」；归置完三面即转 `03` 重铺阶梯。查证等级（A/B/C）从第一条起就挂，细则见 `04`。

## 一、为什么"证据不足"通常是假象

判决书写"现有证据不能证明……"时，通常不是当事人在客观上没有证据，而是发生了下列情形之一：

| 情形 | 特征 | 识别方法 |
|---|---|---|
| **框架被框错** | 争点被表述为一个需要由弱势方举证的问题，而所需证据全在对方手里 | 见第二节判据 |
| **法律路径被漏审** | 判决援引的条文远少于本案应适用的条文 | 比对适用条文清单 |
| **关键事实未进入视野** | 起诉状/证据里有，但"本院认定"和"本院认为"里没有 | 见 `02` 逐字比对 |
| **证据被反向使用** | 用一方自行提交材料中的片段，反过来否定该方 | 检查驳回理由的材料来源 |
| **举证责任未反转** | 应由对方或用人单位举证的事项，判由弱势方举证不能 | 检查是否有法定举证责任倒置规则 |

## 二、框架层错误：本案最致命也最隐蔽的错误

### 判据

**把判决的推导链写出来，然后问一个问题：按这个框架，谁应当举证？所需的证据在谁手里？**

若答案是"弱势方举证，且证据全部由对方单方控制"，则框架极可能被框错。此时**在框架内补证据是徒劳的**，二审必须重新定义争点。

### 实例（脱敏）

原框架：

> 协议无签章 → 不成立书面合意 → 行为人的承诺"属于以自己或他人名义作出" → 需证明**表见代理**或**追认** → 不能证明 → 驳回

问题在于：一旦争点变成"行为人有没有代理权"，举证责任就落在原告身上，而代理权的直接证据（授权委托书、劳动合同、社保记录）**全部在被告手中，且被告缺席不提交**。

而当事人手里有的——公章、公司协议模板、对方股东自认、到庭第三人自认——**不是"代理权"证据，而是"行为归属"证据**。拿代理权的尺子去量归属的证据，量出来必然是"不足"。

重构后的争点：

> 不是"行为人有没有代理权"，而是"**这个以法人名义作出的行为，其后果应否归属于该法人**"。

这两个问题的举证责任分配完全不同。

### 重构清单

| 原框架表述 | 可重构为 |
|---|---|
| 某人是否有代理权 | 该行为的后果应否归属于某主体 |
| 合同是否成立（书面形式） | 当事人之间是否存在合意（含口头与其他形式） |
| 某形式要件是否具备 | 欠缺形式要件是否影响实质权利义务 |
| 原告是否尽到注意义务 | 相对人的信赖是否合理、有无可供核实的渠道 |
| 是否经过追认 | 是否存在以行为作出的追认 |

## 三、五层根因模型

按下列顺序逐层排查，从最致命到最表层。每一层都要给出"在判决中的痕迹"，否则不算成立。

| 层级 | 排查问题 | 典型痕迹 |
|---|---|---|
| **框架层** | 争点被表述成了什么？按此表述谁举证？证据在谁手里？ | 判决"本院认为"的首句即框定 |
| **法律层** | 应适用的条文，判决适用了几条？ | 判决末尾"依照……之规定"的条文清单 |
| **证据层** | 哪些关键事实在起诉状/证据里有，但在"本院认定"里没有？ | 关键词在判决中的出现次数（如"公章"在认定部分为 0） |
| **程序层** | 缺席/举证责任/释明/调证，哪一项应当发生而未发生？ | 判决是否提及释明、调证、责令提交 |
| **庭审层** | 到庭当事人的陈述，哪些进了裁判理由、哪些没有？ | 判决"当事人述称"部分 vs "本院认为"部分 |

### 归置：五层根因 → 三面表

**五层根因是诊断，三面表是处置分类，二者不是并列关系**：先用五层模型查出根因，再把每条根因归到一面。归错面的代价很大——把面一当理由写会稀释篇幅，把面三当"证据不足"去补证据则完全打偏。

| 面 | 含义 | 处置 |
|---|---|---|
| **面一 · 天然不利** | 实体规则或举证规则本身对己方不利，换谁代理都一样 | **放下**，不写进上诉状，不再投入取证 |
| **面二 · 操作失误** | 一审己方**可控而未做**的事：未申请调证、未申请鉴定、关键人员未到庭、只交片段未交完整件、请求权基础只铺一条 | **二审可以重打**，构成上诉理由的主体 |
| **面三 · 裁判层错误** | 判决自身的问题：认定基本事实不清、遗漏审查、适用条文不完整、程序违法 | **攻击判决本身**，对应「撤销原判、发回重审」 |

**归属判据（一句话）**：*这条根因，换一个代理人在一审做到位，结果会不会不同？*

- **会不同** → 面二（一审没做到位，二审补做）
- **不会不同，问题出在判决自己的推理或程序** → 面三
- **无论怎么做都不会不同** → 面一，放下

**两条硬纪律：**

1. **面二与面三都不依赖新证据**——面二靠的是"二审把一审没做的做了"，面三靠的是判决文本自身可见的缺陷（用判决第几页对第几页说话）。这与 `03` 阶梯"前两层不许依赖新证据"是同一条判据，不是巧合。确需新证据的条目，单独标"待取证"放在后面，**不进主攻层**。
2. **面一不写**。把它写出来会让法官在几十条理由里找不到真正致命的那几条；它唯一的作用是提醒你别在上面花钱。

**填表动作**：五层根因逐层排查后，同一轮填 `assets/判决书拆解表.md`（诊断）与 `assets/败诉三面表.md`（处置），两表共用同一批编号，方便来回对照。

## 四、还原推导链的操作

1. 摘录判决"本院认定如下"的每一句，编号。
2. 摘录"本院认为"的每一句，编号。
3. 用箭头连接，形成：**事实认定 → 法律定性 → 条文适用 → 结论**。
4. 在每个箭头上标注：这一步跳过了什么？
5. 找出"跳跃最大"的那一步——那通常就是攻击点。

**示例（脱敏）：**

```
[认定1] 协议载明甲方为被告公司  ──┐
[认定2] 行为人作出返款承诺      ──┼─→ [定性] 属于以自己或他人名义  ← ★跳跃：认定1的"甲方为公司"被跳过
[认定3] 股东称其原系公司职员    ──┘                                  ↓
                                                            [适用] 无权代理未经追认
                                                                    ↓
                                                                [结论] 驳回
```

**跳跃点即攻击点**：判决自己认定了"甲方为公司"，却在定性时说"以自己或他人名义"——那么"他人"只能是被诉主体本身。

## 五、20 项拆解清单

逐项核对，填入 `assets/判决书拆解表.md`。

**主体与程序**

1. 审判组织是否合法（独任/合议、是否适用简易程序）
2. 各当事人出庭情况（谁到庭、谁缺席）
3. 缺席的法律后果是否被写明、是否实际适用
4. 有无第三人，其诉讼地位与陈述内容
5. 送达与期限有无异常

**事实认定**

6. 起诉状中主张的关键事实，是否全部出现在"本院认定"中（逐条比对）
7. 哪些事实在"原告诉称"里被照录，却在"本院认定"里消失
8. 各项证据的认证情况（有无逐个认证）
9. 有无对证据真实性、合法性、关联性的评价
10. 有无"对当事人无异议的证据予以确认"的表述——若有，哪些证据属于此类

**证据摘录**

11. 每份书证/录音的摘录是否完整
12. 有无省略号截断（见 `02`）
13. 有无只采信同一陈述中的一句
14. 有无以一方自提交材料的片段否定该方

**法律适用**

15. 援引条文清单
16. 应适用而未适用的条文（逐条列出并说明作用）
17. 有无对请求权基础的审查
18. 有无对备位路径的审查

**程序与释明**

19. 有无释明补充举证、有无指定举证期限
20. 有无依申请或依职权调查收集证据

## 六、阅卷待核实清单（不属于判决错误，但影响论证力度）

以下事项**必须从卷宗核实后才能主张**，不得推断。未核实前在文件中标注"待核实，不得写入文书"：

- 一审是否书面主张过某条请求权基础
- 一审是否提交过完整的证据材料（如完整转文本、完整录音）
- 一审是否书面申请过法院调查取证
- 一审是否申请过证人出庭或当事人到庭
- 庭审笔录中己方有无不利自认、其内容是什么

## 七、表述模板

### 框架层错误

> 一审判决将本案争点界定为"……"。依该界定，举证责任落于上诉人，而所需证据（……）全部由被上诉人单方控制，被上诉人经合法传唤无正当理由拒不到庭，未提交任何证据。**在此框架下，上诉人无论提交多少证据均无法满足其要求，该争点界定本身即导致举证责任分配失衡。**
>
> 本案的正确争点应为"……"。

### 法律路径漏审

> 一审判决适用《……》第××条作出否定评价（**递交前核对条号**），**未对第××条（……）的适用进行任何审查**。后者系……的特别/一般规定，在……情形下应当优先/一并适用。仅适用前者而不适用后者，属于适用法律不完整导致的结论错误。

### 跳跃式认定

> 一审判决一方面认定"……"（判决第×页），另一方面又认定"……"（判决第×页）。**两项认定不能并存**：若前者成立，则后者中的"他人"只能指被上诉人本身。一审判决对其自身认定事实之间的冲突未作说明，属于认定基本事实不清。
