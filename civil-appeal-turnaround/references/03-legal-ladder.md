# 03 · 责任归属阶梯

> **门牌锚点**：动词 **盘点**（后半段） · Phase 3 · 落点 `assets/法律阶梯表.md`
> **读到哪为止**：本节只排阶梯的**层级与要件**，不产文书。每层的证据要挂 A/B/C 等级——见 `04`；排完转 `06` 文书化。上承 `01` §归置：三面表里归到面二、面三的根因，在这里落成主攻／备位／兜底。

## 一、为什么必须铺阶梯

单点押注单一请求权基础的失败模式是：**一旦二审法院不认可该路径，全线失守，无任何退路。**

阶梯式布局的价值：

- 二审法院在任何一层找到依据，都能支持撤销原判或改判；
- 上诉状呈现出"多层审查"的结构，本身就强化了"一审只审了一层"的印象；
- 备位路径的写作成本极低（多数材料是共用的），但边际收益很高。

## 二、阶梯的结构

```
第一层　主攻：最契合本案事实、且不需新证据的路径
   ↓ 退一步（"纵使二审法院认为……"）
第二层　备位：同样不需新证据，但证明标准或要件不同的路径
   ↓ 再退一步
第三层　需新证据支撑：依赖尚待调取的材料的路径
   ↓ 兜底
第四层　需法院释明变更：法律关系性质不同的路径
```

**设计判据：**

| 判据 | 要求 |
|---|---|
| 前两层必须**不依赖任何新证据** | 只建立在 A 级（判决已认定）与 B 级（在案已提交未认定）证据上 |
| 每层必须给出**独立的构成要件清单** | 不能只是换个说法重复上一层 |
| 每层必须注明**判决漏了什么** | 否则无法构成"适用法律错误" |
| 依赖新证据的层次必须注明**取证路径** | 调取/责令提交/自行取得，以及形式要件 |

## 三、逐层填写规范

| 字段 | 填写要求 |
|---|---|
| **路径名称** | 法律条文 + 法理名称（如"职务代理"），条号标注"递交前核对" |
| **构成要件** | 逐项列出，不得省略 |
| **本案已有证据** | 每项标注 A/B/C 等级 |
| **缺什么 / 怎么补** | 缺如属对方控制，注明"申请责令提交 + 拒不提交的后果" |
| **判决漏了什么** | 明确写出：完全未审／只一句带过／未审查任何要件 |
| **该层结论** | 一句话：成立／需补证／备位 |

## 四、常见阶梯范式（按案型）

### 范式 A · 行为归属类（某人行为后果是否归属某组织）

1. **职务代理**（执行工作任务的人员，职权范围内，以组织名义）——不以书面劳动合同或社保为要件
2. **表见代理**（权利外观 + 相对人善意无过失 + 被代理人可归责）
3. **以行为作出的追认**（接受履行 / 开始履行）
4. **利益归属**（该组织实际取得了交易所生利益，与"非其人员"的抗辩不能并存）

**第 4 层的二难写法：**

> 若该组织系基于与行为人之间的业务归属或合作协议取得该利益，则该协议本身即证明行为人系为其执行工作任务；
> 若其并无任何依据而取得该利益，则其取得无法律上原因，且表明其允许他人以本机构名义从事业务，违反相关管理规定，应对善意相对人承担相应责任。
>
> **两种结论均应由该组织承担责任。**

### 范式 B · 合同成立类（未签署书面合同）

1. **口头或其他形式订立的合同**（形式自由原则）
2. **以实际履行成立的合同**（一方履行、对方接受）
3. **缔约过失 / 信赖利益**
4. **不当得利**

### 范式 C · 款项归属类（钱给了谁）

1. **合同约定**
2. **事实上的利益归属**
3. **不当得利**
4. **第三人代为履行 / 指示交付的查明**

## 五、表见代理三层要件的对应写法（示例）

| 要件 | 本案证据 | 写法要点 |
|---|---|---|
| **权利外观** | 公章、组织协议模板、负责人自认、到庭第三人指认 | 强调"公章系对外意思表示的最强凭证，其保管与使用受严格控制" |
| **相对人善意无过失** | 相对人曾要求以组织名义签署、公对公支付；**且客观上不存在可供核实的公开渠道** | 若已实测公开查询渠道为零，直接写明"依对方主张的核实路径实际查询结果为零，该抗辩不能成立" |
| **可归责性** | 公章由其交付；其未建立法定业务记录、未签订劳动合同、未缴纳社保 | "该举证障碍系其自身违反法定义务所致，不得据此免责" |

## 六、表述模板

### 层间衔接

> 退一步而言，纵使二审法院认为在案证据尚不足以认定【第一层】，依《……》第××条（**递交前核对条号**），【第二层】亦成立。一审判决以"现有证据不能证明……"一语带过，**未审查该项请求的任何一项构成要件**，适用法律错误、认定基本事实不清。

### 需新证据层

> 关于【某事实】，相关证据由【某主体】单方控制，上诉人客观上无从自行取得。上诉人已依《民事诉讼法》第××条第 2 款（**递交前核对条号**）申请二审法院调取，并已依【其他法定途径】向该主体提出查阅、复制申请。
>
> **上诉人特别说明：无论该笔款项系由 A 直接支付予 B，还是经由 C 支付予 B，均不影响下列认定的成立……**

> ⚠️ **禁止预断**：不得写"款项系经 C 支付给 B"这类单一路径表述。一旦对方否认（如 C 当庭称未收到），全案可信度受损。统一使用**开放式/择一**表述。

### 兜底层（需释明）

> 若二审法院认为上诉人所主张的法律关系性质不能成立，则依《最高人民法院关于民事诉讼证据规定》第××条（**递交前核对条号**），人民法院应当将法律关系性质作为焦点问题进行审理。一审法院未将此作为焦点问题审理，未作任何释明，径行以证据不足驳回全部诉讼请求，致使上诉人丧失了在同一诉讼程序中主张备位请求权的机会，属于违反释明义务，程序违法。
