# 04 · 事实台账、出处等级与更正机制

> **门牌锚点**：动词 **查证** · Phase 4（**贯穿全程**：Phase 1-3 每产出一条论断就挂等级，不是最后才做） · 落点 `assets/事实台账.md` + 红线清单
> **读到哪为止**：本节不产文书，只决定「哪些能写、写到什么程度、哪些不能写」。文书怎么写见 `06`。

## 一、出处等级（A/B/C）

**所有事实论断必须标注等级，禁止混用。**

| 等级 | 定义 | 可用于 | 典型来源 |
|---|---|---|---|
| **A** | **判决已认定的事实** | 直接作为论证起点，无需再举证 | 判决"本院认定如下"部分 |
| **B** | **在案已提交但未经判决认定的事实** | 可主张"已提交未审查"，构成认定事实不清 | 起诉状、庭审笔录、一审证据中已有但判决未提的内容 |
| **C** | **待调取或待核实的事实** | **只能**作为申请调取/责令提交的对象，**不得**作为已证事实写入论证 | 需向第三方调取的材料、待阅卷核实的事项、传闻 |

**最容易犯的错误：把 C 当 A 用。** 典型场景：

- 把"销售口头告知的款项流向"当作已证事实写进文书 → 应写"**须以调取的书面凭证为准**"
- 把"网络检索到的项目信息"当作已证事实 → 应写"**待以官方来源核对**"
- 把"对方当事人的陈述"当作自认 → 应区分"明确承认"与"未作否认"

## 二、事实台账结构

填入 `assets/事实台账.md`，每行一条事实：

| 字段 | 说明 |
|---|---|
| 编号 | 便于交叉引用 |
| 事实内容 | 一句话，客观描述，不带评价 |
| 来源 | 具体文件名 + 页码/时间点 |
| 等级 | A / B / C |
| 已用于哪些文书 | 便于同步更新 |
| 纪律备注 | 表述限制（如"只能写区间""不得写明确承认"） |

## 三、定性更正机制（本技能最重要的工程纪律）

**背景教训**：在一起真实案件中，某项目名称的定性经历了三版演变——先被误记为"曾用名"，后被误定为"另一楼盘"并据此构建了一整段"跨项目引流"论证，最后才确认为"同一项目的最早推广名"。**若未及时全库更正，那段建立在错误定性上的论证一旦写进上诉状，会被对方一击即破。**

### 更正流程（强制）

1. **确认新定性**：必须有可核验来源（官方查询结果、当事人确认 + 可核验佐证）。
2. **检索全库**：对该事实的所有表述方式（含别名、简称、误记形式）执行全局检索。
3. **逐处更正**：包括上诉状、配套文书、主控清单、所有分析文件、日志。
4. **留痕**：在每一处更正位置写明"前一版结论已作废"及作废理由，不得静默修改。
5. **更新纪律清单**：把被推翻的表述加入红线（如"禁止再出现某字样"）。
6. **同步复核受影响的其他论证**：定性变更往往会连带推翻依赖它的推论，必须逐条复查。

### 检索提示

定性变更常涉及多种表述形式，检索时须穷举：

- 全称 / 简称 / 别名 / 曾用名
- 同音误识别词（转文本常见）
- 依赖该定性构建的推论性词汇（如"跨项目""跨盘""他盘"）

## 四、红线清单（每案必建）

按下列类别逐条列出，交付前逐条自检：

| 类别 | 典型红线 |
|---|---|
| **未核实不得写** | 款项流向的具体路径、对方是否收到款项、某人的具体身份归属 |
| **不得精确化** | 时间点只有约数时，只能写区间或"约"（如"约某月下旬""晚于某日约四个月"） |
| **不得升级表述** | "未作否认"不得写成"明确承认"；"线索"不得写成"自认" |
| **不得预断主体** | 涉及多方可能的，用开放式/择一表述 |
| **未保全不得引用** | 社交平台主页、即时消息记录，未做录屏/时间戳前不得展开内容 |
| **不得引入未知事实** | 引用第三方信息时，只用它证明当前这一件事，不展开其背景 |
| **不得混线** | 投诉、追责、情绪性内容不得进入诉讼文书 |
| **脱敏** | 身份证号、手机号、住址、账号在交付文件中留占位符 |

## 五、时间类事实的特殊规则

| 情形 | 正确写法 |
|---|---|
| 只有约数（"半个月""几个月"） | 写"约某月某旬"或"区间【某日，某日】"，不得精确到日 |
| 由两个方向推算得出 | **双向夹逼**：上游锚点 + 下游锚点，写"可锁定于【A，B】之间" |
| 依赖通话详单等客观书证 | 标注"以客观书证为准"，书证取得前不得主张精确日期 |
| 与法律要件相关的时间（如离职时间 vs 行为时间） | 强调"**以行为时为断**"，并写明相隔期间 |

## 六、自认的识别与写法

| 情形 | 定性 | 写法 |
|---|---|---|
| 明确回答"对""是的" | 自认 | "明确答以'对'，构成承认" |
| 面对询问不作否认、径行回答另一问题 | 默认 | "**未作任何否认**，径行答以……，**以默认方式承认**" |
| 表示需向公司核实 | 表明材料由其持有 | "该陈述表明其处存有……（据此申请责令提交）" |
| 表示"不知情、不认可"（针对金额） | **不等于**否认代理权 | "其所称不认可，针对的是债务本身，并非对行为归属的否认，二者系不同法律概念" |

## 七、交付前自检

- [ ] 台账中每条事实是否都有来源与等级？
- [ ] 论证中是否存在把 C 级当 A 级使用的句子？
- [ ] 所有定性更正是否已在全库执行并留痕？
- [ ] 红线清单是否已建立并逐条自检？
- [ ] 时间表述是否都符合约数/区间规则？
- [ ] 敏感信息是否已脱敏？
