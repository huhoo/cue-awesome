# 05 · 自行诉讼操作（不委托律师）

> ⚠️ 本章全部内容均为**操作常识性提示**，具体期限、金额、渠道须以受理法院的现行规定与通知为准，并在递交前电话确认。

> **门牌锚点**：动词 **todo** · Phase 0 与 Phase 6 · 落点 主控清单（前提确认表 + 待办表）
> **注意**：本章**跨两个动词**——§八 §九（调证申请写法、取证路径）属「搜集」；§十二（最小外包）属「查证」的外延。其余属「todo」。

## 一、优先级：钱 > 期限 > 证据

| 战线 | 事项 | 说明 |
|---|---|---|
| **A. 保全** | 继续保全 | **上诉不自动延续保全**。一审驳回后保全基础被否定，对方随时可申请解冻，款项可能当天转走 |
| **B. 上诉期** | 递交上诉状 | 民事判决 15 日，自**送达次日**起算，**不可恢复** |
| **C. 取证** | 调证、责令提交、新证据 | 重要，但排在 A、B 之后 |

**顺序不可颠倒。保全没保住，赢了也拿不到钱；期限过了，一切归零。**

## 二、期限

| 事项 | 期限 | 起算 |
|---|---|---|
| 上诉期 | 15 日 | 判决书**送达之日**次日起算 |
| 上诉费缴纳 | 通常为收到交费通知后 7 日内 | 逾期按**自动撤回上诉**处理 |
| 保全期限 | 银行存款一般为一年 | 届满前申请续行保全 |

**第一步永远是：确认判决书的实际送达方式与送达日期**（电子送达／邮寄签收／现场领取）。若由代理律师代收，自其次日起算——**这就是"解除委托后必须变更送达地址"的原因**。

## 三、递交渠道（最易出错）

| 文书 | 递交对象 |
|---|---|
| **上诉状** | **原审（一审）法院**，由原审法院随卷移送二审法院。**不要直接寄二审法院**——未立案时二审法院无卷宗，材料易搁置 |
| 上诉状副本份数 | 按对方当事人人数 + 1 份 |
| 各项申请（调证、责令提交、到庭询问、新证据清单） | **随上诉状同日递交**，随卷一并移送 |
| **继续保全申请书** | **同时**递交：一份随上诉状，一份直接交一审承办法官（保全由一审法院实施，解冻申请也先到一审法院） |

**同日递交的理由**：若申请未随上诉状一并提交，二审法院很可能书面审理、不开庭，当事人将丧失补充证据与当庭陈述的机会。

## 四、上诉费

- 上诉费标准通常与一审案件受理费相同，具体以缴费通知为准。
- 缴费通知送达后须在指定期限内缴纳（常见为 7 日）。
- 逾期未缴 → 按自动撤回上诉处理。
- 符合缓减免条件的，可在递交上诉状时一并申请。

## 五、不需要律师也能做的事

下列均为**当事人的诉讼权利**，不要求律师资格：

| 事项 | 依据（递交前核对条号） |
|---|---|
| 查阅、复制本案材料（阅卷） | 民事诉讼法关于当事人查阅复制的规定 |
| 申请法院调查收集证据 | 民事诉讼法第 67 条第 2 款 |
| 申请证据保全 | 民事诉讼法关于证据保全的规定 |
| 申请财产保全及续行保全 | 民事诉讼法关于保全的规定 |
| 申请证人出庭 | 民事诉讼法关于证人出庭的规定 |
| 本人出庭陈述、辩论 | — |
| 委托近亲属或工作人员为诉讼代理人 | 民事诉讼法关于委托代理人的规定 |

## 六、解除律师委托后的必办事项

1. **书面通知法院解除/变更委托代理**（否则法院仍向原律师送达，期限照常计算而当事人收不到）。
2. **书面变更送达地址**为本人地址与联系方式。
3. **取回全部材料并签收**：判决书原件、**证据原始载体**（录音手机、聊天记录手机）、全部证据材料、庭审笔录、保全裁定及担保材料、委托代理合同与发票。
4. **删除上诉状中代理律师的署名行**——否则二审仍向该律师送达。

## 七、程序资格核查（不得想当然）

| 问题 | 核查要点 |
|---|---|
| **第三人是当事人，能否作证人？** | 证人须为**当事人以外**的人。第三人属当事人，**不能作证人**。正确路径：申请**传唤其本人到庭接受询问**（司法解释关于"人民法院认为有必要的，可以要求当事人本人到庭，就案件有关事实接受询问"的规定，条号递交前核对），其陈述属**当事人陈述** |
| **二审能否增加诉讼请求？** | 原则上二审增加独立诉请，只能调解，调解不成告知另行起诉（条号递交前核对）。**备位主张与新增独立诉请不同，须区分** |
| **二审能否追加被告？** | 同上，一般走不通；正确时机是发回重审后（重审适用一审程序） |
| **逾期证据能否采纳？** | 与案件基本事实有关的逾期证据，**人民法院应当采纳**（条号递交前核对），但须书面说明理由 |
| **一审已提交的证据，二审再主张其中未被审查的部分** | 不属于新证据，应表述为"**已提交但一审未予审查、未予认定**" |

## 八、调取证据申请的写法要点

1. **写明被调查人与材料名称**，材料须具体（如"佣金结算单、付款凭证及发票，**其上载明的收款方全称**"）。
2. **写明证据由对方或第三方单方控制**，当事人客观上无从取得。
3. **不预断内容**：如"申请人不预断收款主体，请求以被调查人处实际存档的付款凭证为准"。
4. **穷举检索口径**：若标的可能存在多个名称（备案名、推广名、曾用名），**要求以全部名称检索**，避免因名称差异遗漏。
5. **写明拒不提交的后果**：请求依证据规定关于"控制证据无正当理由拒不提交"的条款，推定对方主张成立（条号递交前核对）。
6. **一并请求证据保全**：对可能灭失的材料（如电话回访录音，行业惯例保存期有限）。

## 九、取证的两条并行路径

对由第三方（如交易相对方、开发商、平台）持有的材料：

| 路径 | 依据 | 优点 | 形式要求 |
|---|---|---|---|
| **法定查阅复制权**（如个人信息查阅复制） | 个人信息保护法相关规定 | 不需法院，速度快 | 书面申请、留痕；答复期限法定 |
| **申请法院调取** | 民事诉讼法第 67 条第 2 款 | 有强制力 | 形式问题由法院解决 |

**两条路同时走，不要只走一条。**

第三方主动提供的单位证明材料，若要作为证据使用，须满足：**单位负责人 + 制作证明材料的人员签名或盖章，并加盖单位印章**（条号递交前核对）；必要时请求法院通知制作人出庭说明。

## 十、阅卷优先目标

阅卷时按下列顺序核查：

1. **对方或第三人当庭指认的页码**（如"证据 X 第某页载有……"）——这类指认往往价值最高，必须核对原文。
2. 己方一审**是否提交过完整材料**（完整转文本、完整录音）。
3. 己方一审**是否书面主张过某请求权基础**。
4. 己方一审**是否书面申请过调查取证**。
5. 庭审笔录中己方的**不利自认**及其上下文。

## 十一、行政投诉线的定位

- 行政投诉的目的是**取证与施压**，不是替代诉讼。
- 行政周期通常 30–60 日，**赶不上二审**，故仅可在文书中写明"已投诉举报，结果将作为补充证据提交"。
- 投诉材料**必须明确列出"请求责令提交哪些材料"**，而非笼统请求查处。
- 投诉主体名称须写工商登记**全称**。

## 十二、最小外包：单点付费核验，不是重回全委托

本技能的默认是你自己指挥。两种情形值得再掏一次钱：**标的金额大**；或**程序资格存疑**——是否算二审新证据、能否在二审增加诉请、当事人能否作证（见 §七，这类问题不得由流程替你判断）。

做法是**一次要点核验**，不是重新委托：

1. **带什么**：只带 `事实台账.md` 与 `复核报告.md` 的『序：一句话结论』『二、扭转路径』两节。不带全部卷宗——带得越多，钱花在重读材料上，而不是核你要核的那几点。
2. **问什么**：把要问的写成**三个具体问题**，请对方只核这三点。例如：
   - 本案持 X 材料主张第××条（**递交前核对条号**），是否可能被认定为二审新证据？
   - 二审能否增加诉讼请求；若不能，发回重审后是否可以？
   - 原一审第三人能否以当事人身份到庭接受询问，还是必须走证人路径？
3. **怎么用**：核完**仍由你更正、由你递交**。外部意见一律标注"待核"，**不直接顶替你在台账里定的事实等级**（`04` §一）——第三方意见是 C 级，入卷或经官方来源核对后方可升级。

**边界**：这是买判断题，不是买代理权。对方一旦要求接手全部文书与递交，就回到了你一审已经付过一次钱的位置。

**确认这道闸同样适用**：约咨询、付费、递交都是不可逆动作——先复述「对象 + 后果 + 时点」，再等一次明确回应；「好的」「嗯」「行」不构成确认。事情没有做成，就不说「已经帮您约好了」这类完成时话术。
