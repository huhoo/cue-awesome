# 02 · 证据逐字比对协议

> **门牌锚点**：动词 **搜集** · Phase 2 · 落点 `assets/证据比对表.md`
> **读到哪为止**：本节只负责把「判决写的」与「材料原本的」之间的差异找出来并定表述。差异一旦成立，下一步是把它变成三份申请（调取证据／责令提交／二审新证据清单），写法见 `05` §八 §九。

## 一、目的

判决书对证据的摘录，往往决定了法官实际"看见"了什么。**逐字对照判决摘录与原始材料，找出差异，是二审最省力、最难被反驳的攻击点**——因为它不需要新证据，只需要指出"判决自己漏了什么"。

## 二、三类差异

| 类型 | 定义 | 典型痕迹 | 攻击价值 |
|---|---|---|---|
| **截断** | 摘录至某句即以省略号收尾，后续内容未录 | "……您到时候给我一个卡号……" | ★★★★★ 最明显，一眼可见 |
| **省略** | 整段内容在判决中完全未出现 | 关键句在判决中检索为 0 次 | ★★★★★ |
| **割裂** | 同一陈述中包含两项事实，只采信其中一项 | "原系公司职员，已经离职"→ 只认定"已离职" | ★★★★ 需指出两项不可分 |

### 截断的识别方法

1. 找到判决摘录中最后一个省略号。
2. 回到原始材料，定位该句在原录音/文本中的位置。
3. **读它后面紧跟着的 1–3 句**——判决停在这里，通常意味着后面是它不想处理的内容。
4. 把被截断的内容完整摘录，并说明它影响哪个要件。

### 关键词出现次数法

对每一个关键概念（如"公章""公司账户""离职""佣金"），分别统计它在下列三处的出现次数：

| 位置 | 出现次数 |
|---|---|
| 起诉状 / 原告诉称部分 | |
| 本院认定 | |
| 本院认为 | |

**若在"原告诉称"中出现、在"本院认为"中为 0，即为高价值攻击点。** 判决照录了你的主张却不予认定，又不说明理由——这正是"认定基本事实不清"的标准形态。

## 三、比对表结构

填入 `assets/证据比对表.md`，每行一份证据：

| 证据 | 原始材料内容（逐字） | 判决摘录内容（逐字） | 差异类型 | 影响的要件 | 上诉状中的写法 |
|---|---|---|---|---|---|

## 四、常见陷阱（务必自检）

| 陷阱 | 说明 | 自检方法 |
|---|---|---|
| **把己方原因造成的缺失说成对方的错** | 若一审只提交了片段转文本，判决摘录不全可能是己方所致 | 阅卷核实"是否提交过完整版"；未核实前不主张 |
| **把未提交的证据说成已提交** | 二审新证据与一审已提交证据的法律后果完全不同 | 严格区分：一审已提交＝"已提交未审查"；一审未提交＝"新证据"，需说明逾期理由 |
| **把推断当成原文** | 转文本识别错误的词（如同音误识别）不得直接引用 | 未辨清的词标注"待辨"，不得写入文书 |
| **把对方陈述说成自认** | 自认有严格构成要件 | 区分"明确承认"与"未作否认"；后者写"未作否认，构成默认"而非"明确承认" |
| **引用未保全的第三方内容** | 社交平台主页随时可注销 | 未做录屏/时间戳前，不在文书中展开其内容 |

## 五、表述模板

### 截断

> 一审判决第×页在摘录该份录音时，仅记至"……"即以省略号截断，**对紧随其后的"……"整句未予摘录**；对"……""……"等内容，则完全未予提及。
>
> 该部分内容系行为人本人对行为主体归属的直接说明，其证明力明显高于微信备注、佩戴工牌等外部外观证据。**一审判决既未采信，亦未说明不予采信的理由。**

### 省略

> 上诉人在一审起诉状中明确陈述：……。一审判决在复述原告诉称部分时原文照录了该陈述，但在"本院认定如下"和"本院认为"两部分中，**该事实未作任何认定，亦未说明不予认定的理由**。

### 割裂

> 同一陈述中包含两项事实：①……；②……。**一审判决采信了②，却对同一陈述中①这一自认不予认定，且未说明不予认定的理由**，属于对同一份证据作选择性采信。

### 反向使用

> 一审判决据以否定上诉人主张的三项依据——……、……、……——**均系上诉人一方自行形成、自行提交的材料**。本案被上诉人未到庭、未答辩、未提交任何证据，在案不存在任何一份来自被上诉人一方的证据。**一审判决以上诉人单方材料的片段，反过来否定上诉人的主张，属于对证据的反向使用。**

## 六、从比对结果倒推二审动作

| 发现 | 二审动作 |
|---|---|
| 疑似只接触到转文本片段 | 提交**带原页码的完整转文本** + **申请当庭播放原始载体** + 申请开庭审理 |
| 关键事实只在起诉状中出现 | 在上诉状中单列一项理由，指其"照录而不认定" |
| 录音中存在同音误识别的词 | 标注"待辨"，不得写入文书；必要时申请鉴定或当庭播放 |
| 己方一审未提交完整材料 | **不得**主张判决遗漏；改为二审补交并说明逾期理由（与基本事实有关的逾期证据应当采纳） |

## 七、原始载体规则

- 录音、聊天记录的**原始载体必须保留**（手机本身），仅导出音频或截图不满足要求。
- 二审申请当庭播放时，须携带原始载体并说明其保管经过。
- 转文本必须**保留原页码**，以便与卷宗中对方指认的页码对应。
