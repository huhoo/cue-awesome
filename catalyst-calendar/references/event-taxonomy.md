# 事件分类学（catalyst-calendar）

日历条目的类型、主源与锚要求。表为骨、判例为肉：**任何条目先过「已有披露在场或法定推导」二选一，再进本表归位**。

## 1. 六类总表

| 类 | 例 | 主源 | 锚要求 |
|---|---|---|---|
| 回购 | 方案到期日 / 进度节点（1%、2%）/ 实施窗口开启 | `buyback` 域直查 | 公告索引号或域 ref |
| 激励 | 授予登记日 / 归属日 / 行权窗口开止 / 考核目标披露年 | `esop` 域 | 同上 |
| 解禁减持 | 解禁日+规模（披露口径）/ 减持计划进展与到期 | `disclosure_cn`；原表缺口时 cue-research ≤1 | 披露原文锚；research 件标 L3（见 §3.3） |
| 监管 | 问询函回复期限 / 警示整改期限 | `regulatory_cn` | 函件号 |
| 分红 | 股东大会通过日 / 派息登记日 / 除权日 | `disclosure_cn` | 公告索引号 |
| 法定 | 定期报告与快报的法定期限（推导） | `statute` 锚 + 规则式推导 | 法条引用（当场取回，不写死） |

不在六类内的「事件」（宏观数据、行业会议、传闻）一律不入表。

## 2. 判例（实跑形状，美的/雨虹两役可溯）

### 2.1 同一公告多事件如何拆行

一条公告承载多个可盯日期时**按事件拆行，每行独立带锚**（同一索引号重复是特性不是冗余——每行须自足）。判例形：

- 美的 2026-08-29《中期利润分配方案（董事会通过，待股东会）》（AN202608281828644258）→ 拆两行：
  「股东会审议（日期：待定→状态=待排期，锚=本公告）」「通过后的派息登记日/除权日（未披露→**不入表**，届时新公告到场才入，见 §2.4）」；
- 回购方案公告（金额区间+价格上限+期限 360 天，AN202603301820871252）→ 「实施截止日（可推导：公告日+360 天，锚=公告）」单行入表；金额/价格上限是属性不是事件，进「事件」列括注，不单列成行；
- 变更类公告（amendment）单独成行且**原方案行不删**：状态列原方案改「已变更→指向变更公告锚」，两行并存读得出方案演化（台账 D4 同构）。

### 2.2 窗口外余档注法

窗口内到期/发生的必要上下文（如回购方案起点在窗口前）：条目**同行末列注**「窗口外余档（YYYY-MM-DD，早于/晚于窗口 YYYY-MM-DD 端）」，日期仍全格式；机检④只放带此注的条目。无注而窗外=FAIL（这是日期幻觉的高发口）。

### 2.3 research 件 L3 标注

解禁/减持原表经 cue-research 取得时：来源锚=`conv_id + 落盘文件路径`（同 expectation-pool 引用纪律），状态列加「L3·待人工核」后缀；**日历组装前逐条过披露域在场核查（L1 前置，同预期池 D-5 纪律）**——只在深研稿里出现、披露面查无的日期不入表。同指标平台/来源分歧时双条并列不仲裁，两条都带各自锚。

### 2.4 「未披露」与「未检索到」的分野（承姊妹件三档措辞）

- 法定期限类：法条在场即可推导入表（锚=statute），这不是「未披露」；
- 公司尚未公告的日程（如除权日待方案通过）：**不是条目**，只在台账挂「待场」记号，新公告到场才建行；
- 域面查了没有：标「未检索到」，日历该节留一行说明本类无在场事件——**空日历合法，编造日历违法**。

## 3. 类型速判常见坑

- 「定期报告披露」条目优先取公司自己的《预约披露时间公告》（disclosure_cn 在场时锚它），法定截止日是**下限兜底**不是首选——两者都在时排两行（预约日+法定期限），读者自见余量；
- 员工持股计划「届满/终止」是事件行（雨虹 AN202606221823739181 型），归属日与终止日不同源时分开带锚；
- 减持「预披露→实施中→完成」是同一计划的三行（各带各公告索引号），合并成一行会吞掉状态变化。
