# 事件分类学 v2（catalyst-calendar）

日历条目的入类闸、类型枚举与判例。本文件按契约 §v2-A 重写（对抗审两项落位）——
**v1 六类表为纲的写法作废**，纲改为「入类第一闸」：类型只是闸门之后的归位标签。

---

## 1. 入类第一闸（每条目先过二选一，否则根本不入日历）

① **已有披露在场且含明确 `YYYY-MM-DD`**——公告/函件原文写得出的完整日期，锚=公告索引号/函件号/URL；
或 ② **statute 规则推导且适用条件在锚内可判**——当场取回的法条原文含可判定的适用条件（主体类别、报告期类型），
条件不满足即拒推。**快报期限无适用条件者不推**（v1 危险项，已删）。
法定锚值规格（v3 写死）：`statute:<法名>第N条(<要点短引>)`——名称+条号+短引三件齐，禁裸串；sources 对应行 `kind=statute` 且 ref 可复核。

**明令禁止**：
- **任何日期算术**：「公告日+360 天→截止日」这类推算全线撤权（v1 判例越权，评审实锤：起算日/自然日或交易日/含首尾/变更覆盖全未定义）。公告原文明写完整截止日的，取原文日期、锚=该公告；公告未写的，**没有这一行**；
- 事后追记项冒充前瞻事件（见 §3「已发生动态」附注区）；
- 年粒度/月粒度指标强配一个日（会诱导补造某一天）。

## 2. 类型枚举与主源锚型（闸门之后才归位；「类型×必配锚型」为机检封闭枚举）

| 类型 | 例（均有明确日期才可入） | 主源 | 必配锚型 |
|---|---|---|---|
| 回购 | 方案期限截止日（公告明写）/ 实施窗口开启日 | `buyback` 域直查 | 公告索引号或域 ref |
| 激励 | 授予登记日 / 归属日 / 行权窗口开启·截止日 | `esop` 域 | 同上 |
| 解禁减持 | 解禁日+规模（披露口径）/ 减持计划进展与到期 | `disclosure_cn`；原表缺口时 cue-research ≤1 | 披露原文锚；research 件 L3（§4.3） |
| 监管 | 问询函回复期限 / 警示整改期限 | `regulatory_cn` | 函件号 `〔〕` 规范式 |
| 分红 | 派息登记日 / 除权日 / 股东大会通过的分红议案实施日 | `disclosure_cn` | 公告索引号 |
| 法定 | 定期报告法定披露期限（条件可判的推导） | `statute` + 规则式推导 | **必 statute 规格串** `statute:<法名>第N条(<要点短引>)`（当场取回，禁裸串/不写死） |
| 股东大会 | 全部议案类会议（年度/临时），股权登记日、现场会议日 | `disclosure_cn` | 公告索引号 |
| 说明会 | 业绩说明会 / 投资者说明会（召开日） | `disclosure_cn` | 公告索引号 |
| 风险警示状态变更 | 退市风险警示、其他风险警示（ST/*ST）**实施或撤销生效日** | `disclosure_cn` | 公告索引号 |
| 停复牌 | 停牌 / 复牌**生效日** | `disclosure_cn` | 公告索引号 |

v1→v2 三项处置（评审定案）：**回购进度节点（1%、2%）**无事前日期、属事后追记→移出日历，见 §3 附注区；
**考核目标披露年**年粒度→降为激励行的属性列（「事件」列括注，不占独立行）；**快报法定期限**无条件者不推。

不在上表内的事件（宏观数据、行业会议、传闻、券商点评里的「预计」）一律不入。

## 3. 「已发生动态」附注区（不占日历行）

回购做到 1%/2%、减持实施中进度这类**无事前日期、发生即成过去**的披露动态：归入 calendar.md 末「已发生动态」附注区，
每条带公告锚+发生日，供读日历的人了解背景；**绝不回填成前瞻行**。此区不是第七类，是叙述区。

## 4. 判例（实跑形状可溯；v2 重写版）

### 4.1 同一公告多事件拆行
一条公告承载多个可盯日期时**按事件拆行，每行独立带锚**（同一索引号重复是特性不是冗余——每行须自足）。
- 美的 2026-08-29《中期利润分配方案（董事会通过，待股东会）》（AN202608281828644258）→ 拆两行：
  「股东大会审议该议案」（日期=会议通知/会议日本身在场才入，锚=本方案公告+后续会议公告）与「登记日/除权日」
  （**未披露则不入**，届时新公告到场才建行）；
- 变更类公告（amendment）单独成行且**原方案行不删**：原方案状态「已变更→指向变更公告锚」，两行并存读得出方案演化。
- 回购方案公告含「期限 360 天」字样而无截止日 → **无行**（§1 算术禁令）；公告原文写明「截至 YYYY-MM-DD」→ 一行，锚=该公告。

### 4.2 窗口外余档：独立列，不挪锚（v3 列位定案）
六列形制第 5 列专职余档：值=空，或 `窗口外余档(YYYY-MM-DD，早于/晚于窗口端)`；**来源锚列永远末列纯锚**——
v2「同行末列注」写法让注和锚挤一格（B5 歧义源头），已废。机检对窗外条目查余档列空置，空置即 FAIL；
余档列有值而锚列为空的裸注同样 FAIL——注与锚各归各列，互不顶替。

### 4.3 research 件 L3 标注
解禁/减持原表经 cue-research 取得：锚=`conv_id+落盘路径`，状态列加「L3·待人工核」；
**入历前逐条过披露域在场核查（L1 前置，同预期池 D-5 纪律）**——只在深研稿出现、披露面查无的日期不入表。
来源分歧双条并列不仲裁，各带各锚。

### 4.4 补类归位判例（v2 新增）
- **停复牌**：「复牌生效日 YYYY-MM-DD」入「停复牌」类（锚=停牌/复牌公告索引号），不并入重大事项杂项；
- **风险警示生效**：ST/*ST 实施与撤销各有「生效日期」，入「风险警示状态变更」类；只有「被实施」公告而无明确生效日的，
  按 §1 闸一处理——公告日≠生效日，查无生效日即不入行，附注区记一句；
- **说明会**：「业绩说明会拟于 YYYY-MM-DD 召开」入「说明会」类（雨虹型通知公告 AN202604161821273798 形制）；
  纪要到手属素材层，不改日历行状态之外的任何事。

## 5. 类型速判坑

- 「定期报告披露」条目优先取公司自己的《预约披露时间公告》（在场时锚它），法定截止日为**下限兜底**——两者都在排两行；
- 员工持股计划「届满/终止」是事件行（带各自主源公告锚），归属日与终止日不同源分开带；
- 减持「预披露→实施中→完成」三行各带各公告索引号，合并会吞掉状态变化；
- 分红类与股东大会类交叉时（分红议案交股东会）：**议案在股东大会类，实施日（登记/除权）在分红类**，两行两锚不互替。
