# 新材料加入后，别把不同口径当成一个答案

此例来自 2026-09-28 的**新解析与完整任务运行**，不是旧结果回放。资料为微软 FY2026 Q3/Q4 公开披露；详见[实测记录](../../references/live-verification.md)。

| 用户问什么 | 简报先提醒什么 | 对实际工作有什么帮助 |
|---|---|---|
| Q4 Microsoft 365 Commercial cloud 增长多少？ | 报告口径 14%；调整上年比较基数后 16%。须保留调整解释。 | 写财报点评或竞品简报时，避免把两个数字混用。 |
| Q4 净利润是多少？ | GAAP 35,766 百万美元；non-GAAP 35,286 百万美元，附 OpenAI 投资调整定义。 | 查证时能回到对应表头、数据行和脚注。 |
| 加入 Q4 后，Q3 的记录还在吗？ | 11 条旧断言保留，新加入 10 个事实范围。 | 下一次更新可以继续使用同一个知识包。 |
| 新披露证明某因素导致 Azure 增长吗？ | 没有抽取到相应因果证据，明确保留缺口。 | 不把可能的解释写成已披露事实。 |

简报可搜索，按新增/冲突筛选，并逐条展开原文摘录。完整数据留在知识包中；不必先理解图数据库或本体建模术语。

Source: [Q3 release](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q3/press-release-webcast), [Q4 release](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast).
