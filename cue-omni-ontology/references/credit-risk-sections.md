# 信用风险抽取：固定章节集

适用：上市公司年报信用恶化 / 贷后复核等任务。

**不要**再按关键词临时抽大约 12 页。宿主应读取同目录 `credit-risk-sections.json`，按下列固定章节整节纳入抽取范围（节过长可截断，但须在 `extraction-notes.md` 写明）。

| 章节 ID | 中文名 | 典型位置 |
|---------|--------|----------|
| audit_opinion | 审计意见 | 审计报告全文（含关键审计事项、非标意见段） |
| mda | 管理层讨论与分析 | 经营情况讨论与分析 / 风险因素 |
| guarantees | 担保 | 重要事项中的对外担保；附注承诺及或有事项 |
| borrowings | 借款 | 附注：短期/长期借款、一年内到期负债、应付债券 |
| related_party | 关联方 | 关联方及关联交易；资金占用披露 |
| litigation | 诉讼 | 重大诉讼仲裁；或有事项 |
| impairment | 减值 | 商誉/应收/存货等减值与坏账；信用减值损失 |
| going_concern | 持续经营 | 编制基础中的持续经营；审计意见强调事项 |

机器可读字段与 `sec_labels` 映射见 `credit-risk-sections.json`。其它主题任务仍可自选章节；仅信用风险任务强制本清单。
