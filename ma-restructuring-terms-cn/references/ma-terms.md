# 并购重组条款速查（本件内部参照）

这一页是出卡时的对照清单，不替代报告书原文；判据全集以 `scripts/check_ma_card.py` 的自测行为准，本页只写人读得懂的形制。

## 一、八项名目与要素

| 项名 | 要读到什么才算取到 |
|---|---|
| 交易概况与方式 | 交易形式（发行股份购买资产／现金购买／吸收合并／要约收购）、是否构成重大资产重组、是否构成重组上市、标的与主业关系 |
| 交易对方与关联关系 | 交易对方名单或范围、持股比例、是否构成关联交易、是否一致行动人、业绩补偿义务人身份 |
| 标的资产与权属 | 标的名称与范围（股权或资产）、权属状态（质押·查封·冻结·出资瑕疵）、审计与评估基准日、过渡期损益归属 |
| 定价方法与交易对价 | 评估方法（收益法／市场法／资产基础法）与定价方法、评估值与增值额或增值率、交易对价金额、定价公允性说明的原文位置 |
| 支付方式与股份发行 | 发行价格（每股 N 元）与定价依据、发行数量（N 股或 N 万股）、现金对价金额与占比、募集配套资金的安排与上限 |
| 业绩承诺与补偿安排 | 承诺年度、承诺净利润数或承诺指标、补偿方式（股份补偿／现金补偿／先股份后现金）、补偿计算公式、减值测试补偿与回购注销安排 |
| 锁定期与减持限制 | 自股份上市起 N 个月内不得转让、分档锁定（控股股东与财务投资者不同）、锁定期的例外与解除条件 |
| 审批程序与披露义务 | 是否需要股东大会批准、关联董事与关联股东回避、交易所审核与证监会注册环节、是否申请豁免要约、后续披露与持续督导义务 |

## 二、三格数字的四类顶替写法（都不算给了原值）

1. **空泛指代**：「交易对价以评估机构出具的报告为准」「具体发行数量另行协商确定」「业绩承诺数以最终协议为准」「届时披露」——机检按该要素没有合格候选处理，没取到就写「未检索到」；
2. **参照数冒充**：账面价值、经审计净资产、**审计值·审计价·审计数·审计结果**（审计类按词族收，不止「审计后的净资产」一种写法）、可比公司市盈率或市净率、停牌前收盘价与均价、发行前总股本、已实现净利润与同比增长率、募集配套资金上限——这些数各归各的口径，**不顶本格账**；**别格**元素的名词才算参照数（对价的数不顶承诺净利润的账），同格两元素之间不互为参照数——它们都是本格名词，归谁靠最近邻定；两元素只拿到一枚数时靠共指系词才算齐备（见上一节）。评价词后接「性·度·论」任一名词后缀（合理性·公允性·充分性·合理度·公允度…）都不在禁用之列——那是被说明的对象，不是断言；这一份后缀排除只写一次，定式表与主题×语气两支共用。同句里出现两个数时各判各的：「交易对方承诺净利润不低于 5,000 万元，标的 2024 年已实现净利润 4,200 万元」里 5,000 万元算承诺数、4,200 万元不算；
3. **单位与枚举造成的错认**：「每股」是单位不是所有者，「面值每股 1 元」这类写法仍归面值；分年度枚举（「2026 年、2027 年、2028 年净利润分别不低于…」）里的顿号不算归属边界，所有者看同一短语内的相邻关系；
4. **别格的数与日期**：日期（评估基准日、审计基准日、上市日）在判据域里先剥掉；交易对价的数不顶发行数量的账，评估值不顶承诺净利润的账，承诺数也不顶对价。

**这一格判到哪一层（射程照实写）**：机检吃的是「数与其限定名词在同一短语内的相邻关系，加一次跨短语的孤立数继承」，不声称覆盖所有自然语言的归属表达；省略主语究竟指谁属整句语义，机检不解析，这类归属人工回原句核对。判不到而文件确实没写，走「未检索到」这条合法出口——它是答案，不是失败。

## 四、卡面写作五条

2. **两要素各自的落点**：num 元素要一枚归自己的候选，term 元素（补偿安排）要自己的安排用词且**同句无空泛语**——「补偿金额待定」只说还没定，与「以股份补偿」这种具体安排不同，前者发后者过；但两者**同段共存**时（「补偿金额待定但未达标以股份补偿」）机检按整段未定判、也发——这格属已知覆盖不到，写成「补偿金额待定；未达标以股份补偿」这样分号或句号切开就读得到。
1. **每格两要素**：三格里「X 与 Y」是两组同时给——评估值与交易对价各要一枚合格候选、发行价格与发行数量各要一枚、承诺净利润要有数而补偿安排要有它自己的安排用词；只给一枚仍算缺，真没写就写「未检索到」。唯一的例外是共指：同一短语里两个本格名词之间夹着「即为·即·为·是·等于·均为·都是」而短语里只有一枚数，该数同时满足两元素（「评估值即为交易对价 86,000 万元」）；系词必须**肯定**——两名词之间带否定形（不是·并非·不视为·不等同·未·无）时不算同值句，那枚数只归最近的名词、另一元素仍要自己的落点（「评估值不是交易对价 86,000 万元」照发）；系词不在场，严格式也不动。式样范围也照实写：机检只认**系词式**（系词在两个名词之间），「评估值与交易对价均为 86,000 万元」这类**同位式**不识别、照发，属已知覆盖不到，人工回原句核对。
3. **项名一行起头**：`- 项名：原句逐字 锚：<来源定位>`，八行齐；没取到的写 `- 项名：未检索到（缺数清单已点名）`，不省行、不写「无该项」；
4. **层级标明**：预案、决议摘要、独立财务顾问核查意见、媒体转手件都要在头部申报里写清来路层级，转手件另注「未与报告书核对」；
5. **两处不齐就不判**：只拿到一处披露时，口径对照那一节照实写「本次两份未齐，口径不判」，不把预案与报告书的数字混成一句，也不做取舍判断。
