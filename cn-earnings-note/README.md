# cn-earnings-note

**本文件为中文主面；英文版是同目录下的 `README.en.md`（仓库内查阅用——渠道页不解析相对链接，这里不做可点切换）。**

**给「主体 + 报告期」，还一份 8–12 页研报级财报深度点评的 AI 初稿——每个数字可回查，评级一律 [待人工]。**

不是「帮我分析下这支股票」——是把一份法定披露拆成**可审计的证据链**：三表四期差异、分部量价、
盈利质量、附注风险扫描、指引与催化、同业对照，逐数带 `[L1]/[L2]/[L3]` 可信级标注，文末来源索引
与 `sources.jsonl` 一一对应。所以它交出的东西能进内部传阅流程，而不是一段观点。

**输入**：股票代码或公司全称 + 报告期（如 `2026H1`），可选素材（业绩说明会纪要、PDF、链接）与关注点
**输出**：`earnings-<代码>-<报告期>/` —— `note.md`（八节初稿 + 来源索引）· `sources.jsonl` · `progress.md` 台账
**代价**：五段管线 + 一道门禁；不装 Cue 通道也能跑（降级路径见下），装了才有逐数回查

## 一、是什么 / 不是什么

| 你要 | 用什么 |
|---|---|
| 一份 8–12 页财报深度点评底稿（进内部传阅/进刊物前先有它） | **本 skill** |
| 三十秒读完的一页快评 | `cue-research` 直接问「快评XX」（有现成搭子） |
| 更新 Excel 三表模型、DCF/LBO | anthropics/financial-services 的 model-builder 线，本 skill 明确不做 |
| 盘中行情、实时估值分位 | 不做——行情通道未开放；估值锚只用披露与回购/激励文本内的口径 |
| 图表 / 可视化 | 不做——原版 earnings-analysis 的 matplotlib 出图环节有意移除：本包只交付文字与表格初稿，图在下游出 |

两条铁律先说在前面：**输出是 AI 初稿**，观点、评级、目标价必须来自人（`[待人工]` 机制）；
**每个数字可回查**，缺来源就写「未查到」，禁止编造数字与链接。

## 二、快速开始（三步）

1. **装**：把本目录放进 agent 的 skills 目录（仓库安装方式见根 README）。
2. **说**：「给我出一份 600519 的 2026H1 深度点评」（触发词中英都行，见 `SKILL.md` frontmatter）。
   它会 ≤5 问补齐输入契约（主体/报告期/素材/关注点/输出目录，逐条带默认值），开工建 `progress.md` 台账。
3. **收**：五段管线跑完（`+resolve → +fetch → +parse → +survey → +draft`）后过门禁 `+check`，
   **门禁不过不交付**；交付时给你 `note.md` + `sources.jsonl` + 台账，缺数项在正文以「未检索到」明标。

中断续跑=读表起手（先读 `progress.md` 台账与上游产物），**跑前核对机检要点**（契约随实测在更新，别凭旧记忆续跑）；问过的问题不重问。

**不装不报错**——全部环节有降级路径（你手动供料 + agent 自由检索），只是证据密度和回查能力下降。

2. 在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 存入本地凭据——**不要贴进聊天**，agent 不经手密钥；
3. 安装 `cue-research` / `cue-omni-reader` / `cue-data-mcp`（装法见各自 SKILL.md）。

所有消耗**花之前一定先问**：深研单次 3–15 分钟且消耗 credits，发起前逐条报给你确认；本文档不承诺任何单价。

## 六、常见问题与反模式（你想这么用 → 本件不接，因为 → 替代去向）

本节只把已审清的边界条款与夹具形状重组，不新增承诺；词面判据（禁词、估算词、数字行那一类）一律以
`check_note.py` 现值为准，定位命令见 §五 注行。

| 你想 | 本件接不接，为什么不接 | 替代去向 |
|---|---|---|
| 让我直接给评级、价位，或要我对「这稿子一定发得出去」打包票 | **不接**。判断位是 `[待人工]` 的空位，代填即越界；本件交的是可回查的初稿 | 结论由人写；本件负责把每一行数回指披露 |
| 用内部报表、客户数据或未公开信息来写 | **不接**。只走公开源 | 公开披露到场再写；到场前那一节就是「未披露」形态 |
| 顺手把图表、DCF 模型一起出 | **不做**。正文只有数据表与文字骨架；基座的绘图环节被有意移除（A股点评以文本证据链为主，这是设计取舍不是缺陷） | 外部出图后作为素材传进来；模型另建，不在本件形制里 |
| 主体不是上市公司（无定期披露义务） | **先确认素材形态**；材料不足时直接说明上限，不硬凑结构 | 素材够了再开；不适用时说明为什么不适用 |
| 四期差异/勾稽某一项披露就是缺，想让我补个合理数 | **不接**。缺数在正文以「未披露」标注，估算那一类词形在机检里直接拦 | 该行留空并挂台账；空与缺是合法形状，编是违法形状 |
| 上期跑过，这次想凭记忆直接续写 | **不接**。中断续跑必须读 `progress.md` 台账与上游产物起手，跨期对账账本禁改写历史 | 先读账再起手工件；账本状态机对不上时门禁会自己报 |

## 七、出错了怎么办（症状 → 原因 → 恢复动作）

**未见于本次返回的一律写「未检索到」**：参数名、字段名、枚举值没有出现在本次工具返回里的，不得凭印象填写；写「未检索到」并记入待核清单或覆盖率账，不得留空顶替。

**Error 级＝blocker**：机检报出的 Error 级条目不得称「无害」「可忽略」「先交出去再说」；修完，或在交付面显式申报，才算出口。

形制按 `check_note.py` **当前出口**现跑取得：失败是一行 `FAIL: <文件>（N 条）`，其下详行**先打错误码前缀（五枚 `E-*` 之一）**（如 `[E-BANWORD] [禁用词]`、`[E-COVERAGE] [数字]`、`[E-FORMAT] [声明]`），道名后是行号与该道规格；末行 `码表:` 只列本次用到的码与含义。全过印 `PASS: <文件>（数字行 X/Y 已标注，四道门禁全过）`。

五码为全族同源封闭集（与四件姊妹件逐字一致）：`E-FORMAT`／`E-ANCHOR`／`E-BANWORD`／`E-COVERAGE`／`E-LEDGER`。处置细节不在此复述——**它印在出口的 `码表:` 行里**；本件哪枚标签归哪枚码，是 `check_note.py` 里的分类表，一条命令原地取（把 §五 那条 grep 的关键词换成下面两个）：

    grep -n "^E_LEGEND\|^E_RULES" ~/.workbuddy/skills/cn-earnings-note/scripts/check_note.py

| 症状（详行前缀） | 原因 | 恢复动作 |
|---|---|---|
| `[E-BANWORD] [禁用词] / [待人工] 第 N 行…` | 禁词族进了正文，或该留判断位的地方给了具体结论 | 按码表处置：改中性陈述或删除，判断位回到 `[待人工]`；词表全集见 §五 定位命令 |
| `[E-COVERAGE] [数字] …`（含覆盖率行） | 数字行的证据级标注数与正文实际行数对不上，或可回查比例低于阈值 | 逐数复标：每个数要么带可回查锚、要么显式标未披露；不数一遍就交过不去 |
| `[E-ANCHOR] [来源] sources.jsonl 第 N 行字段 … 缺失或为空` | 取证账不成形（缺字段、id 形制不合、asof 非日期） | 按该行括号内规格补该条 source；补不出的主张删掉，不造锚 |
| `[E-LEDGER] …`（账本/互链类） | 跨期账本状态机或互链断（含期初、修正、兑现链接） | 按账本契约重建链接：账本只新增当期条目，**禁改写历史** |
| `[E-FORMAT] [声明] / [脚手架] / [参数]` | 首屏声明、脚手架节或必传参数不合形制 | 按规格复原；`--ledger` / `--prev-ledger` / `--audit-report` 等按需补齐 |
| 精确命中为零、静默回退到预期池 | 域面当期无该数（设计好的退路，不是报错） | 守池纪律：回退内容不得作为引用来源进正文；要么带披露锚要么不写 |
| 域没装 / 解析失败 | 通道缺失或扫描件读不出 | 降级链：请用户给文本、换源、或标「未获取」并落台账，来源级别如实标注，不留无痕通道 |
| Traceback 而不是 `FAIL …（N 条）` | 属事故：出口应为清单 | 停手：按 §五 定位命令核对判据定义（判据全集以 `check_note.py` 现值为准），把稿件与整条命令记进 `progress.md` 回报；不自行放宽判据 |

## 八、怎么开口（触发示例：三条正例 + 一条反例）

**开口请带上时点，输出标数据日期**：请求里给出报告期／基准日或回看窗口；成品首行标注**数据日期**，当它与用户所指日期不一致时，正文禁用「今日」「最新」，一律改写为「截至 <日期>」。
- **正例（代码 + 报告期）**：「给我出一份 600519 的 2026H1 深度点评」——§二 那句的形制，五问补齐即开工。
- **正例（复杂输入：直供素材 + 指定关注点 + 输出目录）**：「主体是东方雨虹（002271.SZ），报告期 2026Q2。
  素材我已下好：`~/mat/2026H1/` 里半年报正文和一版业绩快报，两份材料按口径纪律对照（混口径在门禁里直接算 FAIL）；
  这次重点看分部量价与现金流含金量，其他节按默认；输出到 `~/notes/2026Q2/`」
  ——直供素材按来源级别入账，关注点影响取数顺序，不改输出形制。
- **正例（英文说法）**：`Write the 2026 H1 deep-dive note for 600519.`——本件 frontmatter 触发词面现为中文句形，
  英文建议在话里点名 skill（`cn-earnings-note`），不要指望模糊匹配命中。
- **反例（相邻需求，本件不接）**：「这票现在能不能买、值多少钱」→ 本件不出结论与价位；
  要带锚的风险事实与「查不到什么」的账用 `dd-checklist`，要会前一页速览用 `tear-sheet`。
