# cn-earnings-note

**[中文](README.md) · [English](README.en.md)**

**给「主体 + 报告期」，还一份 8–12 页研报级财报深度点评的 AI 初稿——每个数字可回查，评级一律 [待人工]。**

不是「帮我分析下这支股票」——是把一份法定披露拆成**可审计的证据链**：三表四期差异、分部量价、
盈利质量、附注风险扫描、指引与催化、同业对照，逐数带 `[L1]/[L2]/[L3]` 可信级标注，文末来源索引
与 `sources.jsonl` 一一对应。所以它交出的东西能进内部传阅流程，而不是一段观点。

**输入**：股票代码或公司全称 + 报告期（如 `2026H1`），可选素材（业绩说明会纪要、PDF、链接）与关注点
**输出**：`earnings-<代码>-<报告期>/` —— `note.md`（八节初稿 + 来源索引）· `sources.jsonl` · `progress.md` 台账
**代价**：五段管线 + 一道门禁；不装 Cue 通道也能跑（降级路径见下），装了才有逐数回查

---

## 一、是什么 / 不是什么

| 你要 | 用什么 |
|---|---|
| 一份 8–12 页财报深度点评底稿（进内部传阅/进刊物前先有它） | **本 skill** |
| 三十秒读完的一页快评 | `cue-research` 直接问「快评XX」（有现成搭子） |
| 更新 Excel 三表模型、DCF/LBO | anthropics/financial-services 的 model-builder 线，本 skill 明确不做 |
| 盘中行情、实时估值分位 | 不做——行情通道未开放；估值锚只用披露与回购/激励文本内的口径 |
| 图表 / 可视化 | 不做——原版 earnings-analysis 的 matplotlib 出图环节有意移除：本包只交付文字与表格初稿，图在下游出 |

两条铁律先说在前面：**输出是 AI 初稿**，观点、评级、目标价必须来自人（`[待人工]` 机制）；
**每个数字可回查**，缺来源就写「未查到」，禁止编造数字与链接。

## 二、快速开始（三步）

1. **装**：把本目录放进 agent 的 skills 目录（仓库安装方式见根 README）。
2. **说**：「给我出一份 600519 的 2026H1 深度点评」（触发词中英都行，见 `SKILL.md` frontmatter）。
   它会 ≤5 问补齐输入契约（主体/报告期/素材/关注点/输出目录，逐条带默认值），开工建 `progress.md` 台账。
3. **收**：五段管线跑完（`+resolve → +fetch → +parse → +survey → +draft`）后过门禁 `+check`，
   **门禁不过不交付**；交付时给你 `note.md` + `sources.jsonl` + 台账，缺数项在正文以「未检索到」明标。

中断续跑=读表起手（先读 `progress.md` 台账与上游产物），**跑前核对机检要点**（契约随实测在更新，别凭旧记忆续跑）；问过的问题不重问。

## 三、首次开通 Cue（三步，可跳过）

取证骨架是 Cue 三通道：结构化披露（data-mcp）+ 原文解析（omni）+ 横向深研（cue-research）。
**不装不报错**——全部环节有降级路径（你手动供料 + agent 自由检索），只是证据密度和回查能力下降。

1. 注册 <https://cuecue.cn>（新账号注册送 500、每日 10，以服务端为准）；
2. 在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 存入本地凭据——**不要贴进聊天**，agent 不经手密钥；
3. 安装 `cue-research` / `cue-omni-reader` / `cue-data-mcp`（装法见各自 SKILL.md）。

所有消耗**花之前一定先问**：深研单次 3–15 分钟且消耗 credits，发起前逐条报给你确认；本文档不承诺任何单价。
