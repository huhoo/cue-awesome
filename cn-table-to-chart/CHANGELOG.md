# 更新日志

### 0.1.0 — 2026-10-26（建件：一张表→图规格＋读表要点，数逐字回那一格，图型由人不代选）
- 建因：现役名册里没有一枚以「表→形状」为产物——全仓 24 枚的 SKILL frontmatter 现扫，提到图规格／作图／chart 的只有本枚 1 枚（=自己）。相邻的三枚各管一件事：转换那枚改格式、财报点评那枚出文稿、数值包那枚核跨期变化，都没有「这张图立不立得住」这一层。腿天然咬合两条：表在扫描件、云盘 PDF、披露照片里时靠解析通道取正文（逐字带页码与行号正是那条腿的价值）；算的那一层沿用既有分工——宿主算数、件核一致性，本件一个数都不算。
- 造了什么：四节契约（①图的规格四件：图型／横轴／纵轴／序列，每件都得是人选过的，待核位不算填过 ②读表要点 3–10 条，每条一个数用「」括出、行末一枚 `[S#]`、带页码或 `文件:行号` ③图的限度与未取到四类逐类在位：缺格与空值／合并格与跨列表头／单位与口径／表外推与未读到，每类要么给位置要么写未见到 ④来源与解析日）、一支五道机检 `scripts/check_chart.py`（形制与条数带／锚与定位／数逐字回表／四类限度点名／投资与评级断言零命中，纯标准库、零网络、判定全集在脚本里）、一支离线采集器 `scripts/collect_chart.py`（把表里的数逐字搬进第二节并自带两枚定位，规格与限度留待核位，不代选图型、不代人算数）、夹具九枚（合成表一枚＋好样一枚＋坏样七枚）＋离线三档 runner。
- 三条硬边界（三面都写，机检兜）：不据图给投资建议——目标价、评级动作、可投与否一类**单靠词就发条，不要求情态词在场**；不承诺数值精度外的结论——换了说法的判断同拦，最高级／比较级形态与投资结论对象词落在同一语义段即发条，语义段按段落切、续行并入上一段，换行不算躲开；评级与目标价一律 `[待人工]`，且要挂在那个语义段里才放行。引号里的表内原文不算作者表态（先剥引号再判）。现读逐面命中行数（口径＝忽略大小写的 re.search 逐面数行，四支式子与原始输出同在证据 01：investment advice|投资建议／评级|目标价|rating|target price／不代人算|不代做算术|computes none|never does arithmetic／逐字|verbatim）：投资建议 SKILL 5／README 2／README.en 2 行，评级与目标价 4／4／4 行，不代人算数 3／2／3 行，逐字回表 9／11／8 行。
- 五道里最硬的是道三那一形：同一行既给页码又给行号时两个定位各自比，只读其一会把假的那枚放过；造数、造页码、行号超界三支靶各发 `E-QUOTE`。道一新增的那一格是把「图型没人选」钉成红——骨架按设计在道一与道四两道齐发（`E-FORMAT`＋`E-COVERAGE`），runner 档③的期望就按这两道写，不为了让它只发一道去削判据。
- 两条路：主路走解析通道（已连判据＝宿主 `tools/list` 握手返回里认得到 `parse`／`get_parse_status`／`read_result`，本机没有那份文件也能读）；降级只读手上那份，代价同句写在两面——扫描与照片那一侧的表读不进来，缺的是那一格的逐字正文，不是排版。「手里这份是不是出数那一版」这一格两条路都不判：本件不读版本标记、不对披露链，基准版由人指定并对齐（这句与三面里通道口径同形，不留机器核不了的强句）。
- 解析日那一格照着已定的形走：日期必须挂在「解析日」标签下且是日历上存在的一天；机检只核这两件，核不了那天是否真是取回当天——这句话在本件里对着实现读过：采集器只有 `re.fullmatch` 形制式、机检只有 `DATE_RE.search` 在场式，都没加日历存在性之外的判据，所以面文只写到这里。
- 词表：**未新增任何工件名**。consumes 用在册的 parsed-doc（产方 1 枚、消方现扫 10 枚含本件）；produces 用在册的 validated-numerics（本件加入后产方 2 枚、消方 0）与 source-index（产方 13 枚、消方 0）。两处如实报：①多枚产同名在本仓口径里合法，边只按规范名相等；②本件两项 produces 图上出度为 0，入边由 parsed-doc 来，所以它不在表一孤点清单内——为把数字做漂亮去接一条不存在的关系是造假边，不用。
- 反证怎么跑：`--selftest` 与 runner 档②都逐枚断言「码集恰等于该发的那一道」，并多打两列——落笔与否、**靶位（第 N 行／判据段名）**；段名取不到即记不合，这是「说某判据不判别之前先证靶落在它扫的那一段里」的落地。仓外自供注入 21 枚逐枚单跑（红组 17／正控 4）：解析日标签换成出具日、日子不存在、无标签、末尾没挂锚、两枚定位一起摘 各发 `E-ANCHOR`；数被改位、页码造一枚没有的页、行号超界 各发 `E-QUOTE`；规格一件被删、图型退回待核、要点掉到带下 各发 `E-FORMAT`；整类删掉、半句点名、别处报未读到而第三节零未见 各发 `E-COVERAGE`；裸断言「这家可投」、目标价、换了说法且拆在相邻两行的判断 各发 `E-ADVICE`；四枚正控（同段挂 [待人工]、引号内表内原文、描述式比较无结论对象词、好样原样）全部退码 0 无发码。
