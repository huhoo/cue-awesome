# Runbook — 《区域观察》

> 每期跑完更新一次。它的价值是让第 N 期不必重踩第 N-1 期的坑，也为下一期给出可信的成本预期。
> 第 1 期记录来自 2026-09-17 的首次真实生成（第 22 期）。

## 踩坑记录

| 现象 | 根因 | 应对 |
|---|---|---|
| 法规动态条目写到 340–450 字 | 按 U1 硬指标（180–260 字）写会砍掉关键数字，于是一路写长 | 目标定 **≤320 字**：既在上期实测区间（81–392）内，又保得住文号与核心数字。写完后必须 `--stats` 量一遍 |
| 长文章整篇塞进一个 `article` 页 | 一个 page = 一个 A4 div，内容超出会溢出页边界 | **已由 `--autoflow` 解决**：直接把整篇 blocks 塞进一个 article 页，渲染器按估算高度自动续页、加「（续）」标记。不用手切 |
| 目录页码与正文对不上 | 分隔页、封面不占正文页码 | **已由 `anchor` 解决**：给栏目/文章页写 `anchor`，TOC 条目用 `{"ref":"a1"}`，渲染时自动换成真实页码。本期实测 11 条全部对齐 |
| 续页重复显示栏目标题 | `fields.section` 每页都写 | 自动分页已处理：续页只显示 `「…（续）」` |
| **白字白底，页码/目录页码/编委会/分隔页标题全隐形** | spec 的 `meta` 是 `#FFFFFF`（原刊压在深色图上），新刊无底图时照抄就看不见 | 渲染器自动按「本页有无底图」切换 `--folio-c` 等变量；无封面图/分隔图时画 `cover-fallback` / `divider-full`。**交稿前仍须逐页肉眼过一遍** |
| **篇幅只有样例三成** | UnitPattern 只写了单条字数，没写「每栏多少条」 | `scale_baseline` 进 spec，`--stats` 算达成率，<60% 直接 FAIL |
| 封底联系方式 / 编辑部名单只能留占位 | 样例抽取只拿到办公室**名称**，拿不到电话 | 首次开工就向行政与市场部要一份，填进 `sources.md` 第一节 |

## 第 22 期（2026 年第 3 期）补记

### 交付从两版变三件套

```bash
python3 scripts/build_draft.py    --spec assets/stylespec.json --content content.json --out build --stats
python3 scripts/export_pdf.py     --spec assets/stylespec.json --content content.json --out build/draft.pdf
python3 scripts/export_editable.py --spec assets/stylespec.json --content content.json --out editable
python3 scripts/check_freshness.py --content content.json --issue-date <付印日> --window 6
```

**PDF 不能指望浏览器打印。** 第 22 期 HTML 内容完整（64 页 4 万字），
用户端打开却是空白——预览器与企业策略都能拦住 mm 定位的 CSS。
`export_pdf.py` 用 PyMuPDF 自绘，同一份 content.json 出同样的 64 页、551KB。

### 分页漏算会让正文被裁掉

`.page` 是 `overflow:hidden`，估算少了不报错，直接把超出部分吃掉。第 22 期查出三类漏算：

| 漏算项 | 影响 |
|---|---|
| 条目 meta 行（约 6.5mm/条） | 条目密集的页底部被裁 |
| 栏目页头部 fields（kicker / 栏目名 / 导语 / 标题 / 署名 / 摘要 / 题图） | 文章首页溢出 |
| 导语段 | 同上 |

现在 `expand_pages()` 用 `head_height_mm()` 扣掉头部高度，`unit_height_mm()` 计入 meta。
**改动后页数会从 57 回到 64**——不是内容变多，是原来挤爆页的东西重新有了位置。

### 中文不许「数字与汉字之间」加空格 + 不许两端对齐

稿子写「2026 年 4 月 10 日」，排版引擎把空格当断词点，
`justify` 时每个空格被拉到极限，一行字散成横向摊开的碎块（PDF 实测如此）。

- `inline()` 统一收紧为「2026年4月10日」，英文前后空格保留；
- PDF 正文改左对齐；
- 结构字段（meta 的「2026.04.10 香港金融管理局」）用 `esc()`，间隔空格保留。

### 时效是硬门禁

`check_freshness.py` 抓到的真问题：第 22 期初稿收录区间跨 13 个月，
还收了 2025 年 8 月生效的可持续披露准则（应属上上期），
而栏目导语自己写着「本期收录 2026 年 4 月至 9 月」——自相矛盾。

处理：删 3 条、并入 1 条、补写 9/16 香港首个五年规划（原先整期漏掉最大新闻），
保留 1 条写理由的豁免。终态 ERROR 0 / WARN 0 / INFO 18（待付印当天复核）。
