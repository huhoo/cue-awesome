# UnitPattern — 本机刊的可复用内容原子

> **开工第一问是篇幅量级，不是选题。** 样刊 91 页 / 56,133 字（PyMuPDF 实测），
> 每页中位 646 字。落成内容前先按下面的「篇幅基线」定目标页数与条数，
> 写完用 `build_draft.py --stats` 验达成率，低于 60% 直接判不合格、回去补。

## 篇幅基线（第 21 期实测，已写进 assets/stylespec.json 的 scale_baseline）

| 指标 | 目标 | 第 22 期实测 |
|---|---|---|
| 页数 | 91 | 59（64.8%） |
| 启明观察篇数 | 6 | 6（100%） |
| 正文总字数 | 56,000 | 34,054（60.8%） |
| 法规动态分区 | 3 个（港澳 / 海南 / 广东），每区 4–6 页 | 3 个，各 7–9 页 |
| 业绩快讯 | 8 则 | 8 则 |
| 启明新闻 | 3 则 | 3 则 |

> **这一份才是 +draft 阶段真正的生产指令。** StyleSpec 决定长什么样，UnitPattern 决定写什么、写多长、怎么收尾。
> 每个 unit 都配了「结构示例」，生成新内容时按 slot 套写，不要自由创作。

## U1 法规动态条目

**出现位置**：栏目「01 法规动态」，网格 A，每页约 2 条；每个分区（港澳 / 海南 / 广东）首页带一张通栏 Banner 图。

```
slot_1  地区前缀 ＋ 标题        「<地区>：<事件短标题>」      8–28 字，semibold，黑
slot_2  导语                    「<YYYY年M月D日>，<发布主体>…」  20–45 字
slot_3  要点正文                背景 + 主要修订 + 适用范围      3–6 句
slot_4  影响评价                「该<文件>对<x、y、z>具有<意义>」  1 句，30–60 字
slot_5  CTA                     「阅读原文」右对齐，主色
```

**硬指标**（2026-09-17 据第 22 期实测修订）：

- 整条 180–320 字（含 slot_4 影响评价）；
- **每个分区 8–13 条**，每个分区占 4–6 页 —— 只写 3 条会让整册篇幅掉到基线的三成；
- 标题**必须**带地区全称前缀；结尾**必须**有 slot_5；
- `meta` 行（日期 + 发布主体）**建议每条都写**，小字排在标题下，是法规动态区别于一般新闻稿的版面特征。

**地区前缀白名单**：香港 / 澳门 / 海南 / 广东 / 深圳（前海）/ 广州 / 佛山 / 中山 / 江门 / 横琴 / 前海 / 南沙。不得自造简称。

**结构示例**（实体为虚构合成，仅示意 slot 用法）
> 香港：金管局批出首批稳定币发行人牌照
> 2026 年 4 月 10 日，香港金融管理局宣布金融管理专员根据《稳定币条例》向 持有人 A 有限公司 和持有人 B 银行有限公司批出稳定币发行人牌照，牌照同日生效。两名持牌人拟在完成技术平台测试、风险管理措施和人力资源等准备工作后，于未来数月启动业务。金管局同时提示公众，应通过持牌稳定币发行人登记册核验相关主体，并仅通过受监管渠道取得或使用稳定币。首批牌照的发出标志香港稳定币监管制度进入落地实施阶段，对跨境支付、本地支付、代币化资产交易和可编程支付应用均具有制度基础意义。
> 阅读原文

## U2 深度文章

**出现位置**：栏目「02 深度观察」，网格 B，每篇首页带 175×78mm 主图。

```
slot_1  主标题                  15.5pt semibold 主色，可跨两行，多用「：<副题>」句式
slot_2  日期 ＋ 作者              「2026.04.30 韦思远 黄启明」右对齐，#404040
slot_3  导语小标题＋开场          semibold 主色的小起段，点明为什么现在要谈这件事
slot_4  分节标题                 「第一部分：…」「第二部分：…」或「一、…」「二、…」
slot_5  正文段落                 10.4pt，行距 22pt，段落间不空行
slot_6  要点列表                 「• xxx：xxx」，缩进一行
slot_7  结语 + 服务转化           「<展望句>」＋「我们随时准备为您提供<服务范围>的全流程护航」
slot_8  致谢（可选）              「*感谢实习生<姓名>对本文的贡献」
```

**硬指标**：单篇 3,000–8,000 字、4–10 页；必须有 slot_4 的分节结构（≥3 节）；多数篇带 slot_7 的服务转化段。

**结构示例**（实体为虚构合成，仅示意 slot 用法）
> 解码机遇：香港联接基金 ETF 设立全攻略—打通中国内地市场的双引擎（QFII / Stock Connect）
> 2026.04.30 韦思远 黄启明 李悦宁 刘知远 周静仪
> 前言：站在资本的十字路口
> 随着中国内地资本市场双向开放的不断深化，香港作为超级联系人的角色愈发关键。……
> 第五部分：战略优势—为何选择联接基金模式？
> • 传统劣势：香港上市的 A 股 ETF 多由香港团队管理，难以深入把握内地市场动态。
> • 联接优势：直接投资于内地「主基金」，该主基金由内地资深团队管理……

## U3 业绩快讯

```
slot_1  标题  「<主体> + 助力 + <客户/项目> + <结果动作>」 一句式，15–45 字
slot_2  项目事实   时间 / 主体 / 标的 / 金额 / 上市地
slot_3  服务范围   「启明提供了全程法律服务，包括：(i)…(ii)…(iii)…」
slot_4  客户评价   「启明团队<形容词>的工作态度……获得了客户及各个中介机构的认可」
slot_5  合作回顾   「近年来，启明与<x>在多个项目紧密合作。<时间轴列举>」
slot_6  展望祝福   四字词组起手（云程发轫、万里可期）
slot_7  团队署名   「本项目牵头合伙人为 A 律师及 B 律师，承办合伙人为 C 律师。」
```

**硬指标**：每则 1 页，必配大图（签约 / 上市 / 团队照）；slot_7 **逐则必有**且格式固定。
**条件件**：内容涉及基金 / 证券 / 收益时，末尾追加「重要提示：投资涉及风险……」免责声明块。

**结构示例**（实体为虚构合成，仅示意 slot 用法）
> 云程发轫，万里可期。启明与瑞泰国际一同分享这份喜悦与荣耀，衷心祝愿瑞泰中美科技 50 ETF 上市后表现卓越，再创辉煌。
> 本项目牵头合伙人为韩立平律师及韦思远律师，承办合伙人为韦思远律师。

## U4 新闻 / 人事

```
slot_1  标题        「合伙人 A 连续四年应邀参与<x>」「诚挚欢迎 A、B 加入<x>」
slot_2  事件事实    时间 + 地点 + 场合 + 参与者
slot_3  人物发言    直接引述 + 间接转述
slot_4  资历背书    榜单入选 / 获奖 / 学术兼职，逐条列举，带年份与机构全称
slot_5  能力背书    「团队以体系化的创新实践引领行业发展」+ 标杆案例清单
slot_6  抒情收尾    四字串 + 展望句
```

**硬指标**：不带「阅读原文」CTA（这是与 U1 最直观的区别）；每则 1–2 页，必配现场照或人物肖像。

## U5 固定件（每期必带 / 条件必带）

| 固定件 | 周期 | 备注 |
|---|---|---|
| 封面：期号 + 年月 + 年份大字 | 每期换数字与底图 | 编排位置与字号固定 |
| 第三方评价引言页 | 可沿用，可换来源 | 客户评价或行业评级机构的公开评语 |
| 编辑部名单 + 责编 + 邮箱 | 每期核对 | 人员变动高频区 |
| 目录 CONTENTS | 每期重排 | 页码**必须**指向各分隔页 |
| 四张栏目分隔页 | 每期可换新图 | 构图与文字位置固定 |
| 页眉刊名 + logo + 页码 | 固定 | logo 需矢量源文件 |
| 封底：各办公室联系方式 | 每期核对 | 电话 / 传真 / 邮箱分行列，7.5pt |
| 「重要提示：投资涉及风险…」 | **条件**：涉金融产品时 | 整段照搬，不可改写 |

## 调性守则

- **人称**：动态类纯第三人称客观陈述；文章与新闻可在服务转化段用「我们」。
- **句长**：30–60 字长句为主，书面语，不用感叹号堆叠，不用网络化口语。
- **指称**：文件必须写全称并带文号或令号 + 书名号《》；首次出现的英文概念要「中文（English）」并列。
- **数字**：日期用「2026 年 4 月 10 日」，文章题头日期用「2026.04.30」；其余一律阿拉伯数字。
- **禁用**：「最」字式绝对化表述、未经转述的收益承诺、未经核实的排名与奖项、人物肖像无授权使用。
- **结尾**：动态类唯一收尾方式是 CTA；文章类是服务转化；新闻类是抒情升华。**不可混用。**
