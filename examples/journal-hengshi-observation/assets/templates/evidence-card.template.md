# evidence/<条目>.md

> 一张卡一条事实。文件名格式：`<outline 编号>-<简短 slug>.md`

```markdown
- 主张: <期刊正文里实际要写的那句话>
- 来源: <机构全称>
- 题目: <文件名 / 稿件名 / 公告名>
- 日期: YYYY-MM-DD
- 链接: <URL>
- 原文摘录: <≤80 字，放在「」里>
- 可信度: 一手 / 二手 / 待验证
- 用于: <outline 编号 + 条目标题>
- 取料层: L1 自有源 / L2 权威原文 / L3 结构化数据 / L4 深度研究
```

---

# 规则

- **一卡一事**：一张卡只支撑一个陈述句。多事实就多卡。
- **`主张` 要写成可直接落稿的句子**，不要写成检索词。
- **`原文摘录` 必须逐字**，包括数字、标点、单位。这是 +check 阶段唯一能用来校的事实锚点。
- **`待验证` 一律不进正文**。
- 来自 L4 研究结果的结论，必须回溯到它引用的原始来源再建卡；不接受「研究报告说」作为最终来源。

# evidence/index.csv

```csv
outline_id,条目标题,证据数,一手,二手,待验证,可动笔
01-01,<标题>,12,12,0,0,是
02-03,<标题>,3,1,0,2,否
```

`可动笔` 判定规则：**待验证数 = 0 且 证据数 ≥ 该 unit 所需的最低条数**。

任何 `可动笔 = 否` 的条目，+draft 禁止硬写：
- 证据能补齐 → 回 +gather 补
- 补不齐 → 移进备选池，并在 `outline.md` 与 `review.md` 里明确标注「本期未采用 + 原因」
