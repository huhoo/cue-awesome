# 关联交易条款速查（本件内部参照）

这一页是出卡时的对照清单，不替代公告与协议原文；判据全集以 `scripts/check_rpt_card.py` 的自测行为准，本页只写人读得懂的形制。

## 一、八项名目与要素

| 项名 | 要读到什么才算取到 |
|---|---|
| 交易对方与关联方身份 | 关联方名称与主体性质、与上市公司的关系类型（控股股东／同一控制下子公司／董监高及其近亲属／持股 5% 以上股东）、认定依据、过去十二个月内是否曾为关联方 |
| 标的与服务内容 | 交易性质（采购、销售、受托或提供劳务、租赁、委托理财、资金往来）、标的名称与范围、是否属日常经营购销 |
| 定价政策与交易价格 | 定价依据（市场价、协议价、成本加成、政府指导价、招标投标或竞价、以评估结果为基础）、交易价格或单价的逐字数值、定价原则调整机制 |
| 交易金额与年度额度 | 本次或本期交易金额、当年预计额度上限、已使用或累计已发生金额、超出额度后的处理（是否需重新审议） |
| 结算安排与资金往来 | 支付方式与结算周期（按月、按季、按年度结清）、账期、保证金或预付款、有无非经营性资金占用及计息安排 |
| 审议程序与回避表决 | 审议机构（董事会或股东大会）、关联董事与关联股东是否回避、回避人数、表决票数与结果、是否经全体非关联董事过半数通过 |
| 独立董事审议安排 | 走的是哪一种形式——独立董事专门会议审议、事前认可意见、还是独立财务顾问出具意见；同意票数与结论性原文（**只登记写了哪种，不判断该当适用哪套规则**） |
| 披露与豁免安排 | 披露时点与所需文件、是否达到应提交股东大会的标准、可否适用豁免（在已审议的年度预计额度内、绝对金额与占比门槛）、后续持续督导与定期披露义务 |

## 二、两格数字的四类顶替写法（都不算给了原值）

1. **空泛指代**：「交易价格以双方最终签订的协议为准」「年度额度另行协商确定」「定价依据届时披露」「按实际发生额结算」——机检按该元素没有落点处理，没取到就写「未检索到」；
2. **参照数冒充**：上年同期价格、历史交易价、近三年平均价、市场均价及其倍数、第三方报价与询价结果、挂牌价与指导价、账面价值与净值、经审计净资产、审计值·审计价·审计数·审计结果、评估值、累计已发生额与已使用额度——这些数各归各的口径，**不顶本格账**；同格另一元素的名词不当参照数（它们都是本格名词，归谁靠最近邻与肯定系词共指判），**别格**元素的数才算参照数（交易金额不顶年度额度的账、交易价格不顶额度上限的账）；
3. **单位与枚举造成的错认**：「每公斤」「每股」「不超过」「合计」是单位与连接词，不是所有者——「定价基准日为 2025 年 12 月 31 日」里的日期先剥掉，不当金额；分年度或分季度枚举里的顿号不算归属边界；
4. **比率与期限不参与归属**：占同类业务比例、占净资产比重、按季结算、N 个月内结清——这些逐字登记在原句里，不拿来顶替价格、金额或额度，也不因它们缺了就判该格没取到（真没写就走「未检索到」）。这一条按量纲收：候选数以 ％·%·倍 收尾即不结算任何元素；带金额量纲而数左紧挨着比率词（占比·比例·上浮·增幅·降幅·增长·折扣）的同样不结算——「本次交易金额较上年上浮 1,200 万元」仍算金额没落定；两元素各自有金额时比率在场不误伤。

**这两格判到哪一层（射程照实写）**：机检吃的是「数与其限定名词在同一短语内的相邻关系，加一次跨短语继承与共指补判」，**不声称覆盖所有自然语言的归属表达**。两类句型属**已知覆盖不到**，按严格式发红，遇到请人工回原句核对，别当成交易没写清：①**同位式共指**——系词跟在两个名词之后，如「交易金额与预计年度额度均为 8,600 万元」（改成系词式「交易金额即为预计年度额度 8,600 万元」就读得到）；②**同段共存式**——「年度额度待定但款项按季度结算」这种金额未定而方式已定的句子按整段未定判（分号或句号切开后读得到）。定价依据那一支按用词认、不要求金额，但用词与空泛语同在一句时不算读到。省略主语指谁属整句语义，机检不解析。

## 三、治理程序那一格读什么（回避表决＋独立董事形式）

- **回避**：读「关联董事 X 名回避表决」「关联股东 X 回避表决」的原文与人数；不写回避情况＝未检索到，不按「按规定应当回避」补；
- **表决**：读同意／反对／弃权的票数与是否经非关联董事过半数通过；本件只登记结果原文，**不判断议案能不能过**；
- **独立董事形式**：公告写「独立董事专门会议审议并通过」就登记专门会议，写「经独立董事事前认可后提交董事会」就登记事前认可，两种都没写＝未检索到；本件**不判断该适用哪一套规则、该走哪种形式**（监管规则适用属人工与律师位）；
- **豁免与股东大会**：读「在已审议的年度预计额度内，免于逐项提交股东大会审议」这类原文与门槛；本件不判断是否满足豁免条件。

## 五、卡面写作六条

1. **每格两元素**：定价依据与交易价格、交易金额与年度额度各自要有落点——num 元素要一枚归自己的候选，term 元素（定价依据）要自己的安排用词且同句无空泛语；只给一枚不算这格取到，真没写就写「未检索到」。
2. **肯定系词才算共指**：「交易金额即为年度额度上限 12,000 万元」这类同值句一枚数可同时满足两元素；带否定形（不是·并非·不视为）时不共指，两元素各要落点；同位式属已知覆盖不到。
3. **形式只登记不代答**：独立董事审议走哪种形式、要不要提交股东大会、能否豁免，一律按公告原文逐字登记，不写「应当」「必须」「可以豁免」这类本件自己的判断。
4. **项名一行起头**：`- 项名：原句逐字 锚：<来源定位>`，八行齐；没取到的写 `- 项名：未检索到（缺数清单已点名）`，不省行、不写「无该项」。
5. **书名号豁免按白名单准入**：作者口吻是开放集（判断·认为·研判·主张·相信·我们看…），列不完，所以判据反过来写——四条准入条件缺一不给豁免：①那行有锚（「原句逐字＋锚」是入场券）；②书名号之外只剩**引用标签**（源名词：公告·报告书·协议·决议·募集说明书…／报道动词：载明·披露·约定·称·据·见…／定位词：第 N 节·页·行／引述标记：原文·摘录·引用·节选·摘自…），或干脆是空的——剥完还剩任何字就是本件自己写的；③书名号内以「短标签：」起头时，那个标签同样得是引用标签；④书名号内出现本件自称（本件·本卡·本速读·笔者）即撤豁免——公告原文里不可能出现写卡人对自己这份卡的称呼，所以这一形不是「引文不可核验」的取舍面，是结构上必然是本件自己写的字；③管带冒号的标签、④管不带冒号的自称，并集不是替代。所以「本件结论：『定价公允』」「我们判断：『定价公允』」「公告原文：『本件认为定价公允』」包进书名号、甚至挂上锚，照样进红线判据域；「发行人：某股份有限公司」这类原文登记照旧豁免。**「说明」「注」不在白名单**——它们是本件自述标签不是引用标签，挂这两个标签的引文按内容判；**「本公司」「本行」「本集团」不在自称表内**（公告主体／银行／集团的自称，原文里真会出现），书名号外的本件自称（「本件不接代办」）是正当自述，两者都照旧绿；**自称按位置认、不按子串认**——`样本件`／`基本件`／`成本件`／`副本件` 这类复合词里「本件」只是尾巴，不算自称；判据看**前邻词性**：前邻不是汉字（句首／标点／引号／数字）或前邻在**有限虚词表**（据·由·按·经·对·以·依·向·在·被·将·把·因·故·但·而·且·并·或·若·如·虽·即·则·从·自·于·给·替·为·跟·同·和·与·及·照·就）内才算自称，实词前邻一律不算——所以「据本件判断」「由本件出具」「按本件结论」照发，「成本件认定」不误伤；**该表是有限白名单，不覆盖自然语言全部虚词**——`通过本件判断`／`围绕本件`／`经过本件`／`凭着本件`／`为了本件`／`跟随本件`／`仍本件认为`／`更本件认为` 这类前邻不在表内的形**机检认不出、照绿**，属**已知覆盖不到**，请人工回原句核对，不当成引文已核验；**空白断字算自称**——`本 件`／`本　件`／`本\t件` 这类断字公告原文里不可能出现，先做空白归一（`\s+` 全删）再扫，与「本件」同类；
6. **层级标明、两处不齐就不判**：决议摘要、独立财务顾问意见、媒体转手件都要在头部申报里写清层级，转手件另注「未与公告原文核对」；只拿到一处披露时口径对照照实写「本次两份未齐，口径不判」，不把公告与协议（或摘要）的数字混成一句。
