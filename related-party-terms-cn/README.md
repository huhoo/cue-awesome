# related-party-terms-cn

**给一份 A 股关联交易公告或协议，产出八项逐字卡：交易对方与关联方身份、标的与服务内容、定价政策与交易价格、交易金额与年度额度、结算安排与资金往来、审议程序与回避表决、独立董事审议安排、披露与豁免安排，每项挂原句＋来源锚；公不公允、有没有利益输送、能不能过会一律 `[待人工]`。**

它只管单笔关联交易的条款怎么写：**一家公司窗口期内有哪些关联交易议案与资金占用事实**在 `dd-checklist`（出固定七列风险事实表），**一笔重组里对方是否关联方**在 `ma-restructuring-terms-cn`（那是重组八项中的一项），**任意合同的条款要点与需盯条款**在 `cn-contract-clauses`（通用形状、不含本域治理字段），公告清单在 `announcement-daily-cn`，事件日期在 `catalyst-calendar`。公告与协议原文是唯一依据——**媒体解读与转手摘要都要标明层级**，这条界线是本件存在的理由。

## 一、打开就干：今天这三步

1. 给一份公告、协议或议案：正文粘贴、披露页定位、摘要件都行；没写的那一项要求它写「未检索到」，不许按「关联交易一般都锁一年额度」这类惯例补。
2. 读前两段：头部申报＋八项逐字速读——这两段只要文件到手就能出，不需要任何通道。
3. 盯两格数字：定价依据与交易价格、交易金额与年度额度必须落在**该项自己的原句**里，且机检先把原句**切成短语、以结构体为主定性**（每枚数只在自己那条短语里找所有者：跳过「每公斤」「不超过」「合计」这类单位与连接词后最近的实义名词属本格族才算，属上年同期价·历史交易价·市场均价·账面值·审计值·累计已发生额这类参照数即剔，哪怕同一短语别处写了本格名词；短语两头都空才继承前序最近一次的本格名词，前序只出现过参照数就不继承；每格两个元素各自要有落点——num 元素要有数、term 元素（定价依据）要有它自己的安排用词，「定价依据为市场公开价格、交易价格待定」仍算缺，只有同短语内「即为·为·是·等于」这类**肯定**系词把两个名词共指到同一枚数时才算两要素齐备，带否定形的「交易金额不是预计年度额度」不算共指、照发；共指只认**系词式**，「交易金额与预计年度额度均为 8,600 万元」这类**同位式**机检不识别、属已知覆盖不到，请人工回原句核对；定价依据那一支按用词认，但用词与「待定·另行约定·届时·协商确定」同句时不算读到——「金额待定但方式已定」的同段共存式同样按未定判、也属已知覆盖不到，分号或句号切开后读得到；比率与期限不参与归属，且这条按量纲收——以 ％·%·倍 收尾的候选与被比率词（占比·上浮·降幅…）紧领着的金额都不结算元素）——「以…为准」「另行签订」「届时公告」不算数，「上年同期价格 12.00 元」「市场均价的 1.2 倍」「账面价值 30,000 万元」「累计已发生 41,000 万元」是参照数不算数，「定价基准日为 2025 年 12 月 31 日」是日期不算数，「本次交易金额占比 10%」「本次交易金额较上年上浮 1,200 万元」是比率不顶金额账；遇到了就让它进缺数清单。另记一条：书名号豁免按**白名单准入**——三条缺一不给：①那行有锚；②书名号之外只剩引用标签（公告·报告书·协议·决议这类源名词，载明·披露·约定·称·据·见这类报道动词，第 N 节·页·行这类定位词，原文·摘录·引用·节选·摘自这类引述标记），或干脆是空的；③书名号内以「短标签：」起头时那个标签也得是引用标签。所以「本件结论：『定价公允』」「我们判断：『定价公允』」这类即便挂了锚也照发，「发行人：某股份有限公司」这类原文登记照旧不误伤；**「说明」「注」不在白名单**——它们是本件自述标签，挂这两个标签的引文按内容判。

## 二、五道机检（零网络）

产物交给 `scripts/check_rpt_card.py` 过闸：五段齐＋八项名目行级在场（每枚名目须占一行，散文里提到不算）／每项原句与锚（书名号内空或只剩一个字算缺原句，「锚：」后面空着也发）／红线断言三道（定式禁词族含评价与预测两支词族、「主题词＋判断语气同段」、「裁定前缀＋效力判断」，只准出现在 `[待人工]` 或明写不接的那一**分句**里——标记与免责都不跨句：「[待人工] 定价是否公允留人工；本次交易一定能过会」后半句照发；「定价很合理」「价格基本公允」与「定价合理」同判（插语不构成豁免），「获批概率大」「过会可能性极低」同判；评价词后接「性·度·论」的名词形（公允性·合理性·审慎度）是被说明的对象、不误红；「X 会」机构名与「会 X」名词（会计·会议·会员…）里的「会」先从语气域洗掉；书名号豁免按白名单准入——行里没「锚：」、书名号之外剥掉引用标签后还剩字（本件自述、第一人称判断语都算）、书名号内以非引用标签的「短标签：」起头、或书名号内出现本件自称（本件·本卡·本速读·笔者；「本公司」「本行」「本集团」不算；「样本件」「基本件」「成本件」「副本件」这类复合词也不算——自称按前邻词性认：前邻非汉字或前邻在**有限虚词表**（据·由·按·经·对·以·依·向·在·被·将·把·因·故·但·而·且·并·或·若·如·虽·即·则·从·自·于·给·替·为·跟·同·和·与·及·照·就）内才算，实词前邻不算；**该表是有限白名单、不覆盖自然语言全部虚词**——「通过本件判断」「围绕本件」「经过本件」「仍本件认为」这类前邻不在表内的形机检认不出、照绿，属**已知覆盖不到**，请人工回原句核对；「本 件」这类空白断字算，先归一空白再扫），书名号内的字都照进判据域；「说明」「注」不在白名单）／齐缺申报恰一枚且与未检索到行数对账（两处互相矛盾的申报同样发）／两格数字以短语结构体为主判（拆字段取该项原句、先剥日期，再按「标点 ∪ 数字边界」切成短语表：每枚候选只在自己那条短语里定档——数左跳过单位取最近实义名词、数左空着看数右、两头都空＝孤立数才继承前序最近一次的本格名词且前序只出现过参照数时不继承；比率与期限不参与——以 ％·%·倍 收尾的候选不结算元素，被比率词紧领的金额同样不结算）：每格两元素各自要有落点，缺任一元素又没写未检索到才发——别格的数、参照数与日期都不顶账）

```bash
python3 scripts/check_rpt_card.py --help                          # 参数说明
python3 scripts/check_rpt_card.py --selftest                       # 好样须过、坏样五道齐发、钉阈按整族各钉一档、对照样不误伤、临时件自清（枚数由自测自报）
```

## 四、首次开通 Cue（三步，可跳过）

本件的取证腿有两条：**原文取数**（找关联交易公告、协议与议案原文，走数据腿）与**附件解析**（协议全文、独立董事专门会议决议、独立财务顾问核查意见与持续督导意见多在附件里，走解析腿）。两条都是可选——不装也能按你直供的文件出卡；代价是附件里的定价与承诺细则只能停在「未检索到」，公告与协议的层级对照也没法自动补，要你人工回原文核。

1. 注册 <https://cuecue.cn>；
2. 在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` 存入本地凭据——**不要贴进聊天**，agent 不经手密钥；
3. 装这两枚：`cue-data-mcp` 走原文取数腿，`cue-omni-reader` 走附件解析腿。一条命令两种写法：
   - 整套：`npx skills add sensedeal/cue-skills`（它会列出该集合公开的各枚 skill，按提示挑要装的）；
   - 单装：`npx skills add sensedeal/cue-skills --skill cue-data-mcp`（把末尾那枚名字换成 `cue-omni-reader` 就只装那一枚）。

配置指路同样只给指针、不复述开通步骤：找原文走数据腿，官方配置页 <https://cuecue.cn/hub/mcp>；长附件与 PDF 走解析腿，官方配置页 <https://cuecue.cn/hub/omni-reader>；取 key 走 <https://cuecue.cn/hub/api-key>。

### 连通自查（各条腿能证到哪一层）

```bash
# 1) 目录可达（匿名）：只证 catalog 能读，不叫「已连」
curl -s "https://cuecue.cn/api/mcp-catalog" | head -c 200

# 2) 域路由现值：从返回里取该域的 routing.url 与 transport，别把域名抄死
# 3) 带 key 实连后发 tools/list——只证该数据腿端点被接受，不证别的入口
curl -s -X POST "$ROUTING_URL" -H "Authorization: Bearer $CUE_API_KEY" \
  -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 400
```

装好 skill ≠ 已配凭据 ≠ 数据腿已连：这一层的判据只管数据腿那一路——带 key 按目标域 `routing` 实连且该端 `tools/list` 有返回，才证那把 key 被接受，也只证数据腿连上；解析腿的连通另按它自己那面的判据读。

## 五、边界与不承诺

- 定价是否公允、是否构成利益输送、是否损害中小股东利益、本次审议能否通过、对当期业绩与股价的影响一律 `[待人工]`；不出「建议参与」「建议投反对票」「稳赚」「零风险」「保证收益」「利好」「一定能过会」「损害中小股东」；
- 不判效力：本次交易是否有效、审议程序是否违规、回避是否充分、豁免是否成立，属人工与监管认定位——写出这类自裁断语会被机检发红；
- 不判规则适用：独立董事该走专门会议审议还是事前认可、该不该提交股东大会，本件只按原文登记写了哪种形式，不代答该用哪套规则；
- 不接代办：不出议案文书、不代客投票或申报、不代拟方案，也不提供任何绕开审议、规避披露或打探内幕信息的路径；
- 两格数字逐字：「以…为准」「另行签订」「届时公告」「上年同期价格」「市场均价」「账面价值」「审计值」「累计已发生额」都不算本格原值，没取到就写「未检索到」；每格两个元素各自要有落点——num 元素要有数、term 元素要有安排用词，只给一枚不算这格取到；
- 数字归属有射程：机检判的是同一短语内的相邻关系，加一次跨短语继承与共指补判，不声称覆盖所有自然语言的归属表达；同位式共指与「金额待定但方式已定」的同段共存式属已知覆盖不到、按严格式发红，这类句型人工回原句核对；判不到又确实没写，`未检索到` 是合法答案；
- 未检索到＝照实写「未检索到」，禁以同类交易的惯例补写，也不写「无该项」顶替；
- 域与工具名以 live catalog 现值为准，本件不列固定清单、不承诺枚数，也不承诺该域是否开放与文件的实时性。

## 六、出错了怎么办

| 症状 | 来路 | 恢复动作 |
|---|---|---|
| 好几项是「未检索到」 | 文件是决议摘要，或定价与承诺细则在协议附件里 | 起附件解析腿补原句；起不动就保留缺数点名，不补写 |
| 数据腿连不上 | 凭据缺位或该域未 live | 按 §四 自查；前两段仍可出，代价见 §四 那一句 |
| 机检发红 | 缺锚／缺原句／两格里没落定的元素／齐缺不符／写了判断句 | 按逐条点名的行号补齐；补不出的进缺数清单，不删行凑数 |
| 判断句被误红 | 那行写的是「股东大会」「董事会」「审计委员会」这类机构名，或引用公告原句 | 原句留在书名号内、锚照常挂；机检把「X 会」这类机构名 token 整体洗掉再判语气，正常登记句不误红 |
| 自裁句包进书名号仍发红 | 那句是本件自己的结论（「本件结论：『定价公允』」「我们判断：『定价公允』」），没有原文可引 | 把判断改写成 `[待人工]` 那一段的留人工说法，或引公告原句并挂锚——豁免按白名单准入：有锚＋书名号外只剩引用标签＋书名号内标签也是引用标签＋书名号内不得出现本件自称（本件·本卡·本速读·笔者；「本公司」「本行」「本集团」不算；「样本件」「基本件」「成本件」「副本件」这类复合词也不算——前邻实词即不算；「本 件」这类空白断字算；前邻不在有限虚词表内的形如「通过本件判断」机检认不出、属已知覆盖不到，请人工回原句核对） |
| 本格数被判成参照数 | 一句里先写了市场均价或账面值、本格名词在更左 | 把该格的数与本格名词写进同一句（照公告原句即可），或该项确未取到就写「未检索到」 |
| 同值句被发红 | 写的是「交易金额与预计年度额度均为…」这类同位式 | 这是机检的已知覆盖不到，人工核对即可；想让它读通，改成系词式「交易金额即为预计年度额度…」 |

## 七、怎么开口（正例与反例）

- 正例：「这笔关联交易的定价依据是什么、价格多少」「今年跟这个关联方要做多少钱、额度还剩多少」「几名关联董事回避表决、要不要开股东大会」「独立董事走的是专门会议审议还是事前认可」「账期多久、有没有非经营性资金占用」「这笔能不能不逐项提交股东大会」。
- 反例：「这个定价贵不贵」「有没有利益输送」「会不会损害中小股东」「这次议案能不能过」「复牌后股价怎么走」——公允性、输送嫌疑、损害判断、成败预测与市场反应不在本件，一律 `[待人工]`。

## 八、能力边界（诚实清单）

行情与资金流类数值不在本件能力内（该域以 live catalog 现值为准，未开放就不承诺）；本件不做公允性测算与可比性分析（可比价、评估、盈利预测由评估机构、独立财务顾问与披露文件定）；不判断交易动机、输送嫌疑与内幕信息可能；不做监管规则适用判断（该走哪种独董审议形式、该不该提交股东大会，只按原文登记）；也不持久存你的文件，卡出完就交还给你。
